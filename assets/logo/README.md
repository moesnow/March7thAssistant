# 应用图标

主题选项位于“设置 → 外观与窗口 → 界面主题”，提供“跟随系统 / 浅色 / 深色”，默认跟随系统；选择即时生效并保存。普通深浅色模式的左上角、任务栏及托盘均使用项目原版白底三月七图标，切换主题不会刷新系统图标。

每次点击左上角 LOGO 都会轻轻晃动。5 秒内点击 5 次，总览问候区的小人会换成眼花姿势，粉色提示缓缓上移并渐隐。提示持续的 5 秒内再点 5 次即可解锁长夜月，程序保存主题偏好，并在首次解锁时播放忆灵动画。之后可到设置切换主题。详见 [交互约定](../app/images/evernight/README.md#交互约定)。

| 图标组 | 使用时机 | 左上角标题栏 | 任务栏、托盘及原生窗口 |
|---|---|---|---|
| 三月七 | 普通深浅色模式，或首次彩蛋动画尚未到中点 | 原版 [March7th.ico](March7th.ico) | 同一原版图标 |
| 长夜月 | 选择“长夜”且首次动画已到中点 | [evernight/icon.ico](evernight/icon.ico)，紫色装饰底 | 同一长夜月图标 |

粉色提示与长夜悬浮效果由 Qt 代码渲染；动画与素材说明见 [彩蛋素材说明](../app/images/evernight/README.md)。

“长夜”主题的窗口控制区、主题选择框和侧边栏“设置”背后分别衬有 2 号、1 号、3 号新绘忆灵图片，下拉框和设置按钮周围允许图片适度越界，保留原有图标、文字、布局和点击区域，选择普通主题后隐藏；这些静态装饰与首次悬浮动画使用不同素材。

LOGO 使用居中的 48×48 点击热区，图标本身的尺寸和位置保持不变；热区内连点和双击不会触发标题栏最大化。

原版 `March7th.ico` 保持不变，不制作深色或闭眼变体。仅当彩蛋角色出现或还原时同步更新图标及 Windows 任务栏标识。

仓库仅保留运行时使用的 ICO，源稿不随应用分发，不在运行时生成或修改文件。两个图标都封装 16、20、24、30、32、36、40、48、60、64、72、80、96、128、256 像素图层，圆角底的大小和位置相同。

长夜月图标由项目作者提供，裁掉了四周多余的透明边；角色和原美术的权利归原权利方所有，不重新声明为项目代码许可证。角色参考来源见 [彩蛋素材说明](../app/images/evernight/README.md)。
