# 백그라운드 실행

> 이 문서는 중국어 간체 원문을 기준으로 AI가 번역했습니다. 마지막 업데이트: 2026-10-31. 차이가 있으면 중국어 간체 원문을 우선해 주세요.

어시스턴트가 작업을 실행하는 동안에도 컴퓨터를 계속 사용하고 싶다면 다음 세 가지 방법 중에서 선택할 수 있습니다.

| 방법 | 대상 | 키보드와 마우스에 미치는 영향 | 설정 난이도 |
|------|------|-----------|---------|
| Windows 백그라운드 모드(권장) | Windows 로컬 게임 | 클릭할 때 마우스를 잠시 빌려 쓰고 끝나면 돌려줌 | 설정에서 전환하면 됨 |
| 클라우드 스타레일 | 클라우드 게임 | 사용하지 않음 | 설정에서 활성화 |
| 원격 로컬 멀티 사용자 데스크톱(고급) | Windows 로컬 게임 | 현재 데스크톱을 사용하지 않음 | 시스템 구성 요소 수정 필요 |

## Windows 백그라운드 모드(권장)

게임 창을 다른 창 뒤에 둔 채로 어시스턴트가 창 메시지로 게임을 조작하므로, 작업이 실행되는 동안에도 컴퓨터를 계속 사용할 수 있습니다. 기본값은 여전히 포그라운드 모드이며 직접 켜야 합니다.

### 켜는 방법

`설정 → 기타 → 로컬 조작 모드`에서 `백그라운드`를 선택하고 표시되는 안내를 읽고 확인하면, 다음에 작업을 시작할 때부터 적용됩니다. 자동 대화는 껐다가 다시 켜야 적용됩니다.

설정 파일을 직접 수정할 수도 있습니다.

```yaml
local_control_mode: background
background_mouse_protection: false
```

클라우드 게임은 자체 입력 방식을 사용하므로 이 설정의 영향을 받지 않습니다.

### 사용 조건

- 게임 창은 다른 창 뒤에 두어도 되지만 **최소화하면 안 됩니다**. 최소화된 창은 캡처할 수 없고 입력도 처리하지 않습니다.
- 실행 중에는 **시스템 잠금을 해제한 상태로 유지**해야 합니다. 잠금 화면이나 UAC 같은 보안 데스크톱이 표시되는 동안에는 커서를 읽거나 움직일 수 없어, 백그라운드 조작이 원인을 알리고 중지됩니다.
- 게임을 관리자 권한으로 실행하는 경우 어시스턴트에도 같은 권한이 필요합니다(정상적으로 실행한 어시스턴트는 자동으로 권한을 요청합니다).
- 백그라운드 모드는 항상 창 캡처를 사용합니다. 창 캡처에 실패하면 인식을 중지하며, 다른 앱이 함께 찍힐 수 있는 데스크톱 스크린샷으로 대체하지 않습니다.

### 마우스와 키보드에 미치는 영향

- **클릭과 드래그**는 실제 커서를 잠시 빌려 쓰고 끝나면 원래 위치로 돌려줍니다. 그동안 마우스를 계속 움직였다면 그 이동분도 함께 돌려주므로, 커서가 클릭 위치에 남지 않고 원래 있던 곳에서 계속 움직입니다. 펜 태블릿, 터치스크린, 원격 데스크톱 같은 절대 좌표 장치가 이미 커서를 손 가까이에 돌려놓은 경우에는 커서를 다시 움직이지 않습니다.
- 조작하기 전에 **마우스가 멈추기를 기다립니다**. 누르기 전에 간섭이 있으면 최대 세 번 다시 시도하고, 그 뒤에는 "마우스 조작이 끝나기를 기다리고 있습니다. 작업은 자동으로 계속됩니다"를 표시하고 기다립니다. 작업은 자동으로 계속되며 평소처럼 일시 정지하거나 중지할 수도 있습니다. 3픽셀 이내의 미세한 흔들림은 간섭으로 보지 않습니다.
- **키 입력**은 앞쪽 창이나 키보드 포커스를 빼앗지 않지만, 게임은 "활성" 상태일 때만 키를 받아들이기 때문에 백그라운드에서 키를 누를 때마다 게임이 잠시 자신이 활성 상태라고 인식하게 합니다. 필드 시점에서는 그동안 게임이 커서를 창 중앙에 고정하고, 키 입력이 끝나면 고정을 해제한 뒤 커서를 돌려줍니다.
- **스크롤**: 게임이 앞쪽에 있지 않으면 "스크롤을 위해 게임을 잠시 앞으로 전환합니다" 배너를 표시하고, 게임을 잠시 앞으로 전환해 스크롤한 뒤 원래 창과 커서를 되돌립니다. 그 사이에 직접 창을 전환하면 해당 단계의 남은 스크롤을 멈추고, 선택한 창을 그대로 유지하며, 이전 창으로 포커스를 다시 가져오지 않습니다. 게임이 이미 앞쪽에 있으면 바로 스크롤합니다.
- **마우스 보호**(선택): "로컬 조작 모드"를 펼치면 "재시도 실패 시 마우스 일시 잠금"을 켤 수 있습니다(기본값 꺼짐). 간섭이 반복될 때만 물리 마우스를 잠시 막고, 키보드와 일시 정지·중지 단축키는 그대로 사용할 수 있습니다. 한 번에 최대 2초이며, 동작이 끝나거나 일시 정지·중지·오류가 생기면 즉시 해제됩니다. 보호 중인 길게 누르기나 드래그가 2초를 넘으면 누른 상태를 해제하고 작업이 화면을 다시 확인합니다.
- 좌표를 지정하지 않은 일반 공격은 필드 시점의 커서 고정을 인식해, 이전 화면의 클릭 위치를 재사용하지 않고 현재 위치에서 바로 누르고 뗍니다.
- 자동 대화는 GUI 안에서 실행됩니다. 마우스를 사용 중이거나 창을 잠시 사용할 수 없을 때는 짧게만 기다리고 다음 검사로 넘기므로 화면이 멈추지 않습니다.

### 창 상태 변화

- **창 전환**: 게임을 앞으로 가져오거나 다른 창으로 전환하는 것은 정상적인 조작이며, 이 때문에 작업이 오류로 끝나지 않습니다. 입력 도중이었다면 그 입력이 누르고 있던 키, 마우스, 임시 보호를 먼저 해제한 뒤 작업이 게임 화면을 다시 인식합니다. 이미 보낸 키, 텍스트, 클릭, 드래그는 자동으로 다시 실행되지 않습니다.
- **최소화 또는 일시적으로 보이지 않음**: 입력을 전혀 보내지 않고, 스크린샷과 입력은 최대 60초 동안 기다리며 게임 창을 복원하라고 안내합니다. 복원하면 자동으로 계속하고(기다리는 동안 보류된 입력은 미완료로 반환되며 나중에 보내지 않습니다), 시간이 초과되면 원인을 밝히고 작업을 중지합니다(로그 예: "游戏窗口已最小化（已等待 60 秒）" = 게임 창이 최소화됨(60초 대기)). 같은 사용 불가 기간에는 한 번만 기다리며, 일시 정지한 시간은 대기 시간에 포함하지 않습니다. 프로그램이 게임 창을 자동으로 복원하거나 활성화하지는 않습니다.
- **게임 프로세스 종료**: 기다리지 않고 바로 "游戏进程已退出"(게임 프로세스가 종료됨)를 보고하며, 창을 복원하라고 안내하지 않습니다. 게임 시작 단계에서는 포그라운드 모드와 마찬가지로 게임을 닫고 다시 시작하며, 작업 도중에는 일반 오류로 종료합니다.
- **프로세스는 있지만 게임 창을 찾을 수 없음**(게임이 시작 중이거나 창을 다시 만드는 중 등): 마찬가지로 최대 60초 기다리고, 시간이 초과되면 일반 오류로 처리합니다.
- **게임이 로딩 중이라 응답하지 않음**: 마우스 메시지가 0.5초 안에 처리되지 않으면 그 입력을 해제하고 미완료로 반환하며, 작업이 화면을 다시 확인합니다. 이 때문에 작업이 끝나지는 않습니다.
- 입력 도중 창이 이동하거나 크기가 바뀌거나 좌표가 게임 화면 밖으로 벗어나도 마찬가지로 입력을 해제하고 미완료로 반환합니다.

"미완료"는 그 입력이 끝까지 전송되지 않았다는 뜻일 뿐입니다. 끝까지 전송된 뒤 마무리 대기 중에 창 전환이나 일시 정지가 있었을 뿐인 조작은 성공으로 반환하므로, 이미 반영된 클릭이나 키 입력을 작업이 다시 실행하지 않습니다.

### 일시 정지와 중지

일시 정지와 중지는 먼저 백엔드가 누르고 있는 키와 마우스를 해제하고 임시 전면 전환을 끝낸 뒤 상태를 알립니다. 일시 정지에서 재개해도 중단된 길게 누르기나 드래그는 다시 실행하지 않으니, 현재 화면을 확인한 뒤 계속하세요. GUI에서 작업을 중지하면 먼저 중지 명령을 보내고 "입력을 해제함" 응답을 기다린 뒤 프로세스를 종료합니다. 제한 시간 안에 응답이 없으면 기존 방식대로 강제 종료하고 로그에 기록합니다. 명령줄의 `--control <실행 ID> stop`도 같은 명령을 사용합니다.

### 알려진 제한

- 런처와 독립적으로 실행되는 토벌, 서드파티 시뮬레이션 우주 등의 프로그램은 백그라운드 기능을 얻지 않으므로, 각 프로그램의 요구에 따라 포그라운드에서 실행해야 합니다.
- 마우스를 계속 사용하는 동안 클릭이 필요한 단계는 마우스가 멈출 때까지 계속 기다립니다. 마우스 보호는 물리 마우스만 막으므로, 계속 조작하는 동안 클릭이 완료된다고 보장할 수 없습니다.
- 텍스트 입력은 같은 활성화 세션 안에서 가장 최근에 위치를 찾은 입력란을 다시 클릭한 뒤 문자를 보냅니다. IME 후보 선택이나 임의의 편집기에 이어 쓰기는 지원하지 않습니다.
- 화폐 전쟁의 보상 구슬은 짧은 구간씩 쓸어 모으며 구간마다 마우스를 뗍니다. 중간 단계가 완료되지 않으면 현재 단계를 유지하고 다음 라운드에서 다시 확인하며, 바로 구매나 출전으로 넘어가지 않습니다.
- 인식이나 조작 이상이 생기면 먼저 포그라운드 모드로 돌아가 문제가 백그라운드 모드와 관련 있는지 확인한 뒤, 로그를 첨부해 제보해 주세요.

## 클라우드 스타레일

`클라우드 스타레일`을 켜면 개척력 소모, 일일 훈련, 화폐 전쟁, 차분 우주 같은 작업은 고정된 창이 필요 없고 백그라운드 실행을 지원하며, 창 없이 실행할 수도 있습니다. 필드 파밍과 시뮬레이션 우주는 여전히 전경 전체 화면이 필요합니다.

클라우드 게임은 로컬 게임 창에 의존하지 않으며 macOS, Linux, [Docker](/assets/docs/Docker.md), [Termux(안드로이드)](/assets/docs/Termux.md)에서도 실행할 수 있습니다. 켜는 방법은 [사용 튜토리얼](/assets/docs/Tutorial_ko_KR.md)을 참고하세요.

## 원격 로컬 멀티 사용자 데스크톱(고급)

> 같은 컴퓨터에서(두 번째 컴퓨터는 필요 없음) 로컬 원격 데스크톱으로 다른 Windows 사용자 세션에 로그인하고, 그 세션에서 게임과 어시스턴트를 포그라운드 모드로 실행합니다. 현재 데스크톱의 키보드와 마우스는 전혀 사용하지 않습니다. 여러 사용자의 동시 로그인을 허용하려면 시스템에 패치를 적용해야 하고, 설정이 복잡하며, 시스템 업데이트 후 패치가 무효가 될 수도 있습니다. 일반적으로는 Windows 백그라운드 모드를 먼저 권장합니다.

 * 에뮬레이터 실행은 끊김과 높은 리소스 소모 등 단점이 많으며, PC에서 직접 실행하는 편이 부담이 더 적습니다
 * Windows에 기본 탑재된 원격 데스크톱 서비스를 사용하는 것을 권장합니다
 * Windows에서 원격 데스크톱 다중 사용자를 켜는 방법(중국어):
   * [자세한 튜토리얼 by_Rin](https://www.bilibili.com/read/cv24286313/)(⭐추천⭐)
   * [RDPWrap 방법](https://blog.sena.moe/win10-multiple-RDP/)
   * [파일 수정 방법](https://www.wyr.me/post/701)
 * [자세한 튜토리얼 by_Rin](https://www.bilibili.com/read/cv24286313/)에서 사용하는 모든 파일: [다운로드 링크](https://github.com/CHNZYX/asu_version_latest/releases/download/RDP/LocalRemoteDesktop1.191_by_lin.zip)
   * 예비 링크
     * [바이두 넷디스크](https://pan.baidu.com/s/13aoll4n1gmKlPT9WwNYeEw?pwd=jbha) 추출 코드: jbha
     * [GitHub 미러](https://github.kotori.top/https://github.com/CHNZYX/asu_version_latest/releases/download/RDP/LocalRemoteDesktop1.191_by_lin.zip)

어시스턴트가 원격 세션에서 실행되는 동안에는 원격 데스크톱 연결을 열어 두고 세션 연결을 끊지 마세요. 기본적으로 원격 데스크톱 창을 최소화하면 원격 세션이 화면 그리기를 멈춰 스크린샷이 실패할 수 있습니다. 최소화해야 한다면 현재 사용자의 레지스트리 `HKEY_CURRENT_USER\Software\Microsoft\Terminal Server Client` 아래에 DWORD 값 `RemoteDesktop_SuppressWhenMinimized`를 만들고 데이터를 `2`로 설정한 뒤 원격 데스크톱 연결을 다시 여세요.

### Windows 11 사용자

[자세한 튜토리얼 by_Rin](https://www.bilibili.com/read/cv24286313/)에서 소개한 `SuperRDP`는 더 이상 작동하지 않을 수 있으므로 대신 [TermsrvPatcher](https://github.com/fabianosrc/TermsrvPatcher)를 권장합니다. 중국 본토에서는 예비 링크 [蓝奏云](https://wwsj.lanzout.com/i4V8u2np8dna)에서도 내려받을 수 있습니다.

**참고:** 이 방법은 [자세한 튜토리얼 by_Rin](https://www.bilibili.com/read/cv24286313/) 중 `4. 多用户同时登陆补丁`(다중 사용자 동시 로그인 패치) 부분만 구현합니다. 나머지 단계는 원래 튜토리얼을 따라 진행하세요.

**사용 방법:**
