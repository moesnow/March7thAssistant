# Windows 后台操作

在 `设置 → 杂项 → 本地操作模式` 中选择“后台”，下次启动任务生效。自动对话关闭后重新开启即可应用。默认仍为前台模式；云游戏使用原有输入方式。

也可以在配置文件设置：

```yaml
local_control_mode: background
background_mouse_protection: false
```

后台模式支持本项目自身的窗口点击、按住和释放、拖动、常用键盘按键及组合、Unicode 文本输入。原有任务和滚轮调用无需改写。游戏使用管理员权限运行时，小助手也需要相应权限。

点击和拖动会短暂使用真实光标。操作前等待鼠标空闲；按下前遇到干扰时最多重试三次，再显示提示等待空闲，任务会自动继续，也可以正常暂停或停止。纯按键不会因为鼠标移动而失败。不会将用户已经移动过的光标拉回旧位置。

大世界视角会把光标锁定在窗口中心。不带坐标的普通攻击会识别这种状态，直接在当前点按下、释放，不复用上一张 UI 的点击位置，也不反复定位光标。可定位界面的点击仍保留坐标守卫。空闲后仍无法稳定定位时，本次输入返回未完成，交给任务重新确认界面；同一次等待不重复显示相同提示。

鼠标按下、移动和正常释放按顺序等待游戏处理，并设有超时；按住期间的连续移动带有节奏和插值，避免瞬间扫过目标或旧移动消息回写光标。位置异常的日志会记录预期与实际坐标，不据此认定用户移动了鼠标。

切换到游戏前台或其他窗口是正常操作，不会因此报错结束任务或保存错误截图。若恰好处于输入过程中，会先释放本次按键、鼠标及临时保护，再交给任务继续识别游戏画面；已经发出的按键、文本、点击和拖动不会自动重放。下一次输入采用新的前台状态。

展开“本地操作模式”，可以开启“重试失败时短暂锁定鼠标”，下次启动任务生效。此选项默认关闭；开启后只在反复冲突时临时保护鼠标，保留键盘及暂停、停止热键。每次保护最多两秒，动作结束、取消、暂停或异常时立即释放。无法建立保护或用户正按住鼠标时，继续等待空闲。

已经点击或开始拖动后发生干扰，会先释放输入并返回未完成结果，交给原有界面检测决定后续操作，不自动重放整段动作。连续发生的冲突会累计，允许后续重试启用鼠标保护。受保护的长按、拖动如果超过两秒，会释放按住状态，请重新确认界面后继续。持续使用鼠标时不能保证点击完成，建议按需要开启保护。

货币战争的奖励球使用短段扫动，每段结束释放鼠标；某一步未完成时保留当前阶段，下一轮重新检查，不直接进入购买或出战。取消、暂停和异常同样会释放按住状态。

按键、鼠标释放及文本发送后会留出处理间隔，再让游戏失活，避免后台 ESC 等操作尚未处理就结束会话。

需要滚轮、而游戏不在前台时，会显示“滚轮操作需临时切换游戏到前台”横幅，切到游戏后同步激活状态，使用正常滚轮，并等待游戏处理后再恢复此前窗口和光标。窗口切换会等待实际完成，避免把切换中的短暂空窗口误判为失败。相邻滚动复用横幅，不反复创建弹窗。游戏已在前台时直接滚动。

滚轮期间遇到鼠标干扰，会先恢复窗口状态，再只重试尚未发送的滚轮次数。如果用户主动切窗，本轮剩余滚动停止，由任务重新检查界面；即使用户随后切回游戏，也不会再把焦点拉回旧窗口。用户主动把游戏切到前台时，不会误认为是脚本取得了前台。原窗口已关闭或系统不允许恢复时，不强行激活其他窗口。程序不会自动恢复最小化的游戏。

暂停、停止和输入异常会先尝试释放后端持有的按键和鼠标、结束临时前台操作。暂停恢复后不重放已经中断的长按或拖动，请确认当前界面再继续。图形界面停止任务时会先请求子进程清理；未在限时内收到回执时，仍会使用原有强制结束方式并记录日志。

后台输入强制使用窗口截图；窗口截图失败时停止识别，不回退到可能包含其他应用的桌面截图。启动器继续使用前台输入。独立运行的锄大地、第三方模拟宇宙等程序不会因此获得后台能力，应按这些程序的前台要求运行。

文本输入会在同一激活会话中重新点击最近定位的输入框，再发送字符。有些游戏输入框会在点击时全选已有内容，任务应一次写入完整文字；这不等于支持输入法候选或任意编辑器的追加输入。

实机对照已验证 ESC、每日实训进入和查询、选角色界面的上下滚轮及窗口恢复、货币战争整批奖励球的后台收取，以及差分宇宙视角锁定下的后台普通攻击入战。未运行完整差分宇宙流程。鼠标重试、短时保护及设置改动通过替身接口和自动化回归；物理鼠标拦截及其他任务流程仍需单独验收。
