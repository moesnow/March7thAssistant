# Windows 后台操作

在 `设置 → 杂项 → 本地操作模式` 中选择“后台”，下次启动任务生效。自动对话关闭后重新开启即可应用。默认仍为前台模式；云游戏使用原有输入方式。

也可以在配置文件设置：

```yaml
local_control_mode: background
background_mouse_protection: false
```

后台模式支持本项目自身的窗口点击、按住和释放、拖动、常用键盘按键及组合、Unicode 文本输入。原有任务和滚轮调用无需改写。启动器继续使用前台输入；独立运行的锄大地、第三方模拟宇宙等程序不会因此获得后台能力，应按这些程序的前台要求运行。

## 使用前提

- 游戏窗口可以留在其他窗口之后，但**不能最小化**：最小化的窗口无法截图，也不会处理输入。
- 运行期间需要**保持系统解锁**：锁屏或 UAC 等安全桌面显示时无法读写光标，后台操作会停止并说明原因。
- 游戏使用管理员权限运行时，小助手也需要相应权限（正常启动的小助手会自动申请）。
- 后台模式强制使用窗口截图；窗口截图失败时停止识别，不回退到可能包含其他应用的桌面截图。

## 对鼠标和键盘的影响

- 点击和拖动会短暂使用真实光标，完成后把光标恢复到原位置；用户中途移动过的光标不会被拉回。操作前等待鼠标空闲：按下前遇到干扰时最多重试三次，之后显示“等待鼠标空闲，任务将自动继续”并等待，任务会自动继续，也可以正常暂停或停止。光标在 3 像素以内的轻微抖动不算干扰。
- 游戏只在“激活”状态下接受按键，因此每次后台按键都会让游戏短暂认为自己处于激活状态，不会抢占前台窗口和键盘焦点。在大世界视角下，游戏会在这段时间把光标锁定在窗口中央，按键结束后解除，并把光标恢复到原位置。
- 不带坐标的普通攻击会识别大世界视角的光标锁定，直接在当前点按下、释放，不复用上一张界面的点击位置。
- 需要滚轮、而游戏不在前台时，会显示“滚轮操作需临时切换游戏到前台”横幅，临时把游戏切到前台滚动，完成后恢复此前的窗口和光标。期间如果你主动切换窗口，本轮剩余滚动停止，脚本保留你的窗口选择，不会再把焦点拉回旧窗口。游戏已在前台时直接滚动。
- 展开“本地操作模式”，可以开启“重试失败时短暂锁定鼠标”（默认关闭）：只在反复冲突时临时屏蔽物理鼠标，保留键盘及暂停、停止热键；每次最多两秒，动作结束、暂停、停止或异常时立即释放。受保护的长按、拖动超过两秒时会释放按住状态，由任务重新确认界面。
- 自动对话在图形界面中运行：鼠标正被使用时只短暂等待，未空闲就留到下一轮检测，不会让界面卡住。

## 窗口状态变化

- **切换窗口**：把游戏切到前台或切到其他窗口都是正常操作，不会报错结束任务。若恰好处于输入过程中，会先释放本次按键、鼠标及临时保护，再交给任务重新识别游戏画面；已经发出的按键、文本、点击和拖动不会自动重放。
- **最小化或暂时不可见**：不发送任何输入，截图时最多等待 60 秒并提示还原游戏窗口；还原后自动继续，超时则停止任务并写明原因（例如“游戏窗口已最小化（已等待 60 秒）”）。程序不会自动还原或激活游戏窗口。暂停期间不计入等待时间。
- **游戏进程退出**：立即报告“游戏进程已退出”，不再等待，也不会提示“请恢复窗口”。在启动游戏阶段与前台模式一样关闭游戏后重启；任务进行中按普通错误结束。
- **找不到游戏窗口但进程仍在**（例如游戏正在启动或重建窗口）：同样等待最多 60 秒，超时按普通错误处理。
- **游戏忙于加载**：鼠标消息在 0.5 秒内未被游戏处理时，释放本次输入并按未完成返回，由任务重新确认界面，不会因此结束任务。
- 输入过程中窗口移动、改变大小或坐标超出游戏画面时，同样释放输入并按未完成返回。

“未完成”只表示本次输入没有完整发出；已经完整发出、只是在收尾等待时遇到切窗或暂停的操作仍按成功返回，避免任务把已经生效的点击或按键再执行一次。

## 暂停与停止

暂停、停止会先释放后端持有的按键和鼠标、结束临时前台操作，再回执状态。暂停恢复后不重放已经中断的长按或拖动，请确认当前界面再继续。图形界面停止任务时先发送停止指令并等待“已释放输入”的回执，再结束进程；未在限时内收到回执时，仍使用原有强制结束方式并记录日志。命令行 `--control <运行编号> stop` 使用同一套指令。

## 其他说明

- 货币战争的奖励球使用短段扫动，每段结束释放鼠标；某一步未完成时保留当前阶段，下一轮重新检查，不直接进入购买或出战。
- 按键、鼠标释放及文本发送后会留出处理间隔，再让游戏失活，避免后台 ESC 等操作尚未处理就结束会话。
- 文本输入会在同一激活会话中重新点击最近定位的输入框，再发送字符。有些游戏输入框会在点击时全选已有内容，任务应一次写入完整文字；这不等于支持输入法候选或任意编辑器的追加输入。

## 实机验证范围

已在实际游戏中验证：ESC、每日实训进入和查询、选角色界面的上下滚轮及窗口恢复、货币战争整批奖励球的后台收取、差分宇宙视角锁定下的后台普通攻击入战；主界面经手机菜单进入星际和平指南-生存索引并返回（前台窗口与光标保持不变）、截图等待期间最小化后还原自动继续、最小化期间输入不发送、最小化超时的报错原因、暂停与停止时释放按住的按键、用户移动鼠标时等待空闲。

尚未在实机验证：完整差分宇宙流程、锁屏状态下的表现、加载画面中的鼠标超时（由替身测试覆盖）、游戏在任务中途退出的端到端流程、物理鼠标拦截（鼠标保护）。
