# Shizuku 激活教程

这篇教程写给从没接触过开发者选项、USB 调试和 ADB 的手机用户：从第一次打开手机设置开始，一步步启动 Shizuku，最后让三月七小助手获得授权。[安卓版使用教程](/assets/docs/Android.md)里的「第二步：完成授权」是简要版，照着做卡住了，再回到这里按自己的手机品牌和遇到的现象对照。

本教程优先介绍小米 / Redmi 的 HyperOS、vivo / iQOO 的 OriginOS、OPPO / 一加 / 真我的 ColorOS 系，以及荣耀 MagicOS、华为 HarmonyOS / EMUI；后面补充联想、努比亚 / 红魔、三星等设备。

你不需要先学编程。先找到自己的手机品牌，只做对应的准备，再跟着一种启动方法操作即可。

> **最后要看到两个结果：**
>
> 1. Shizuku 首页显示“正在运行”或“Shizuku 正在运行”。
> 2. 三月七小助手的权限引导显示“权限已就绪”。
>
> 只看到“安装完成”或者“配对成功”，还没有做完。

## 1. 先判断自己走哪条路线

先在手机桌面找到齿轮图标的“设置”，进入“关于手机 / 关于本机 / 我的设备”。平板可能叫“关于平板”。

**先确认设备：** 小助手安卓版要求 Android 10 或更新版本、64 位手机或平板。Android 9 或更旧的设备，即使能运行某些版本的 Shizuku，也不满足小助手当前的使用要求，详见安卓版使用教程的[使用前准备](/assets/docs/Android.md#使用前准备)。

这里可能同时显示两个名字：

- **厂商系统名称**：例如 HyperOS、OriginOS、ColorOS、MagicOS。
- **Android 版本**：例如 Android 12、Android 15、Android 16。

它们是两回事。不要把“HyperOS 3”理解成“Android 3”。如果首页没写 Android 版本，继续点“版本信息”或“全部参数与信息”。

| 你的实际情况 | 选择什么方法 | 要准备什么 |
| --- | --- | --- |
| Android 11 或更新，并且开发者选项里有“无线调试” | **方法 A：只用手机** | 一部手机、一个能连接的 Wi-Fi |
| Android 10 | **方法 B：电脑 USB** | 手机、支持传输数据的线、电脑 |
| Android 11 或更新，但系统没有“无线调试” | **方法 B：电脑 USB** | 同上 |
| 无线配对一直失败，已经按排错步骤检查过 | **方法 B：电脑 USB** | 同上；不必继续反复配对 |
| 华为 HarmonyOS 2～4.3 / 部分 EMUI | **优先按华为专章走电脑 USB** | 这些系统通常没有标准无线调试入口 |
| 华为 HarmonyOS NEXT / HarmonyOS 5 及以上原生系统 | [先看华为适用范围](#_35-华为：先分清-harmonyos-emui-的两种情况) | 本文没有可直接套用的原生 Shizuku 激活流程 |
| 手机已经 Root，且你知道自己使用的 Root 管理器 | 小助手可以直接用 Root 授权；想用 Shizuku 见 [已有 Root 的路线](#_9-已经-root-的手机) | 已有的 Root 权限 |

**只选一条启动路线。** 无线方法成功以后，不用再做电脑方法；电脑方法成功以后，也不用再做无线配对。

Android 无线调试的版本前提见 [Android 官方文档][S2]；华为缺少无线调试的适用系统范围见 [华为官方说明][S15]。

## 2. 准备：看懂几个词，安装 Shizuku

### 2.1 这几个词到底是什么意思

| 词 | 在本教程里的意思 |
| --- | --- |
| Shizuku | 手机上另装的一款工具。它启动后，可以让你授权的应用使用 Android 调试权限 |
| 激活 / 启动服务 | 让 Shizuku 真正开始工作；不是付钱，也不是输入注册码 |
| 开发者选项 | 手机设置里一组默认隐藏的调试设置，本教程会教你把它显示出来 |
| USB 调试 | 允许经过你确认的调试连接，是本教程会用到的开关 |
| 无线调试 | 通过 Wi-Fi 完成调试连接；普通无线方案需要 Android 11 或以上，并且厂商保留了这个入口 |
| 配对 | 让手机认出 Shizuku，通常只需首次完成 |
| 配对码 | 无线调试临时生成的一般为 6 位的数字；不是锁屏密码，也不是 Wi-Fi 密码 |
| 授权 | 在 Shizuku 已运行之后，允许“三月七小助手”使用它 |
| ADB / adb | 电脑与 Android 手机通信的小工具，电脑路线会教你下载和使用 |
| 后台 | 你切到别的应用时，原来那款应用继续工作的状态 |

可以把整个流程记成：**先把工具装好 → 让工具开始工作 → 允许小助手使用工具。**

### 2.2 第一次操作前准备好这些

1. 给手机留足电量，操作期间保持解锁。
2. 记得这部手机的锁屏密码。有些系统开启开发者选项时会验证它。
3. 无线方案先准备一个 Wi-Fi。家里的路由器可以，另一部手机开的热点也可以；**是这部手机去连接另一部手机的热点**。
4. 电脑方案准备一条能传输数据的 USB 线。能充电的线不一定能传数据。
5. 给自己留几分钟，先按顺序做完一条路线，不用同时修改其他设置。

无线调试使用本地网络。下载软件需要联网；配对本身不靠购买流量、扫码付费或远程客服。用家庭 Wi-Fi 最容易操作。

### 2.3 优先用小助手内置的安装包

小助手自带 Shizuku 官方安装包，不用另外去找：

1. 打开“三月七小助手”。
2. 在首页找到“先完成授权”，点击“去完成授权”。
3. 进入“权限引导”后，选择 **Shizuku**。
4. 在“安装 Shizuku”这一步，点击“离线安装”。
5. 如果系统提示需要授权，进入系统的权限页面，只允许**三月七小助手**安装未知应用，然后返回小助手，再点一次“离线安装”。
6. 在系统的安装界面点击“安装”，等到安装完成。
7. 打开 Shizuku。第一次首页显示尚未运行是正常的，下一章才开始激活。

已经装有官方 Shizuku 的用户，可以直接打开它继续。

### 2.4 也可以从 Shizuku 官方下载

离线安装失败，或者想自己下载时，可以点权限引导里的“官方发布页”，或者用下面的官方入口：

- [Shizuku 官方网站][S5]
- [Shizuku 官方 GitHub 发布页][S6]

手机操作方法：

1. 用浏览器打开上面的官方入口。
2. 在下载入口选择 GitHub；进入发布页后找到 **Assets**，点开它。
3. 下载文件名以 **`.apk`** 结尾的 Shizuku 安装包。
4. 不要选“Source code (zip)”或“Source code (tar.gz)”，那是给开发者看的源码。
5. 下载完成后点安装包。找不到时，打开浏览器的“下载”记录，或手机“文件管理 → 下载”。
6. 如果系统提示不允许安装未知应用，只允许当前用于安装的浏览器或文件管理器，然后返回继续。
7. 完成后打开 Shizuku。

**版本选择：** 使用三月七内置包，或 Shizuku 官方发布页提供的版本。已有能正常工作的版本，可以先按本文完成设置；不要因为别人的旧教程写了某个版本，就先卸载重装。电脑启动指令必须以**你当前安装的 Shizuku**显示的为准，详见 [5.6 节](#_56-在自己手机里取得这台手机专用的启动指令)。

## 3. 按品牌打开开发者选项

**这一章只读自己的品牌。** 做完后，按提示跳到方法 A 或方法 B。

下面的“连点 7 次”是指：对着**同一行版本文字**连续点几下，看到“已开启开发者模式”“您已处于开发者模式”等提示就停。部分系统需要的次数略有不同，以屏幕提示为准。

如果系统问密码，输入平时解锁这部手机的密码。不是让你新注册开发者账号。

### 3.1 小米 / Redmi / POCO：HyperOS、MIUI

#### 第一步：把开发者选项显示出来

1. 打开“设置”。
2. 点击“我的设备”或“关于手机”。
3. 如果页面直接有“OS 版本”，连续点击这一行；如果没有，先进入“全部参数与信息”。
4. 找到 **“OS 版本”**，连续点击直到出现已进入开发者模式的提示。
5. 旧 MIUI 的对应位置可能叫“全部参数 → MIUI 版本”，点击的是 **MIUI 版本**。
6. 返回设置最外层。
7. 点击“更多设置”。
8. 向下找到“开发者选项”，点击进入。
9. 如果顶部总开关关闭，把它打开。

找不到时，在设置顶部搜索“开发者选项”。如果仍没有结果，回去确认刚才点的是 **OS / MIUI 版本**；“Android 版本”那一行可能只会打开彩蛋。

路径依据 [小米官方开发者选项说明][S7]，也可对照 [视频教程 02:23～02:32][V2]。

#### 第二步：打开调试开关

1. 在开发者选项里向下找到“调试”一组。
2. 打开 **“USB 调试”**。
3. 出现警告倒计时，就等倒计时结束，阅读后确认。
4. 三月七需要模拟点按：继续检查 **“USB 调试（安全设置）”**，本机有这一项时将它打开，并完成系统要求的确认。
5. 如果系统要求登录小米账号、联网验证或插入 SIM 卡，按这台设备实际显示的要求完成；并不是每个版本的验证条件都一样。
6. Android 11 或以上继续找“无线调试”。找到了就进入 [方法 A](#_4-方法-a：只用手机，通过无线调试激活)；Android 10 或找不到该入口，进入 [方法 B](#_5-方法-b：通过电脑和-usb-数据线激活)。

**“USB 调试”和“USB 调试（安全设置）”是两个开关。** 前一个已打开，并不等于后一个也打开了。额外安全设置与模拟点按的关系见 [Shizuku 手册][S1] 和安卓版使用教程的[运行期间的注意事项](/assets/docs/Android.md#运行期间的注意事项)。

#### 小米用户最容易遇到的两个问题

- **Shizuku 一直搜索不到配对服务：** 按 [后台设置](#_73-只有切到后台就失败、搜索不到服务或经常掉线时，再检查这些设置) 把 Shizuku 的省电策略改为“无限制”，再试。
- **一点通知里的“输入配对码”就失败：** 老 MIUI 可检查“通知管理 → 通知显示设置 → 原生样式”。有这项就切换后重新配对；没有这项的 HyperOS 跳过，改用电脑路线即可。见 [Shizuku 手册][S1]。

激活 Shizuku 不需要解锁 Bootloader（引导加载程序，也称 BL 锁），也不需要开启“OEM 解锁”。**操作时仍需正常解开手机锁屏。** 不要把其他品牌的“禁用系统优化”方法照搬到小米。

### 3.2 vivo / iQOO：OriginOS、Funtouch OS

#### 第一步：打开开发者选项

1. 打开“设置”。
2. 点“关于手机”。平板可能叫“关于平板电脑”。
3. 进入“版本信息”。
4. 找 **“软件版本号”**，连续点击约 7 次，直到出现开发者模式已开启的提示。
5. 返回设置主页。
6. 进入“系统管理与升级”，找到“开发者选项”。
7. 部分旧系统把这一组放在“系统管理”或“更多设置”；也可以在设置搜索“开发者选项”。
8. 保持顶部总开关开启，找到并打开“USB 调试”。

上面较新的入口依据 [vivo X200 官方使用手册][S8]。旧机如果没有“关于手机 → 版本信息”，再检查“我的设备 → 更多参数 → 软件版本号”。

国际版 Funtouch OS 的英文界面常见对应名称是：

**Settings → About phone → Software information → Build number**；开发者选项在 **System → Developer options**。具体以本机菜单为准。见 [vivo 国际版使用手册][S9]。

#### 第二步：选择启动方法

1. 在开发者选项里找“无线调试”。
2. 找到了，先连接 Wi-Fi，再进入 [方法 A](#_4-方法-a：只用手机，通过无线调试激活)。
3. Android 10 或没有该入口，进入 [方法 B](#_5-方法-b：通过电脑和-usb-数据线激活)。

#### vivo 用户需要额外留意

- 配对时切去设置后一直搜不到服务，优先给 Shizuku 开“允许后台高耗电 / 允许后台运行”，具体操作见 [后台设置](#_73-只有切到后台就失败、搜索不到服务或经常掉线时，再检查这些设置)。
- **“USB 模拟点击”解决的是之后的点击权限问题。** 只有 Shizuku 已运行、小助手已授权，但仍提示无法模拟点按时，再检查开发者选项里是否有它；有则开启并重试。这个选项只在部分 vivo 设备上有，见 [网易 Airtest 官方问题说明][S11]。
- 没有“USB 模拟点击”就跳过，不必为寻找它去改安全键盘、支付保护等无关设置。

### 3.3 OPPO / 一加 / 真我：ColorOS、OxygenOS、realme UI

#### 第一步：打开开发者选项

1. 打开“设置”。
2. 点“关于本机”或“关于手机”。
3. 进入“版本信息”或“版本”。
4. 找 **“版本号”**，对着这一行连续点约 7 次。
5. 英文界面可能写 **Build number、Version number 或 Version No.**，通常旁边是一长串数字、字母。
6. 按提示输入锁屏密码，等到出现开发者模式开启的提示。
7. 返回设置主页，进入“系统与更新 → 开发者选项”。
8. 旧版可能在“其他设置”或“系统设置”里。找不到时，直接搜索“开发者选项”。
9. 保持顶部总开关开启，打开“USB 调试”。

OPPO 官方对新旧系统给了不同入口，见 [开发者选项说明][S12] 和 [USB 调试说明][S13]；真我对应入口见 [realme 官方支持][S14]。

#### 第二步：先按通用流程配对、启动

在开发者选项里找到“无线调试”，按 [方法 A](#_4-方法-a：只用手机，通过无线调试激活) 做。没有“无线调试”就走 [方法 B](#_5-方法-b：通过电脑和-usb-数据线激活)。

**如果已经显示正在运行，也没有 ADB 权限受限等警告，先去给小助手授权，不用为了凑齐教程开关而继续改系统。**

#### 第三步：遇到“ADB 权限受限 / 制造商限制了权限”时，按开关全名处理

ColorOS 系最容易在这一步看反。请看手机显示的**完整名称**：

| 你看到的名字 | 应该怎样设 |
| --- | --- |
| 权限监控 / Permission monitoring | **关闭** |
| 禁止权限监控 / 停用权限监控 / Disable permission monitoring | **开启** |
| 禁用系统优化 / Disable system optimization / Disable system optimisation | **开启**，只用于出现对应权限问题、并提供此选项的固件 |

“禁止权限监控”前面已经带了“禁止”二字，所以要把这个开关**打开**，才能停止额外的权限拦截。不是看见“监控”两个字就一律关掉。

旧界面可对照 [MAA 官方的实机演示视频 02:10～02:19][M1]；新界面和改名情况有 [Shizuku 原始问题记录 #2149][S16] 交叉支持。

#### 找不到“禁止权限监控”，怎么办

按这个顺序检查：

1. 先在开发者选项里找“禁用系统优化”或相近的完整名称。
2. 找到了，就按上表处理，不必换语言。
3. **确实找不到，而且 Shizuku 正在提示相关权限错误**，才尝试临时切换英文。
4. 切换前，先在设置搜索“语言”，找到当前的“语言与地区”页面，记住如何回来。
5. 将系统显示语言改为 **English**。有些系统要先“添加语言”，再把英语设为系统语言或移到第一位。
6. 返回 **Settings**，搜索 **Developer options**。也可能在 **System & update**、**System & updates** 或 **Additional settings** 下。
7. 向下找 **Disable system optimization / Disable system optimisation**，将其开启。
8. 系统可能显示影响耗电、功能和安全保护的提示。阅读后确认；找不到准确名称就停止这一分支，保留报错信息，不去打开名字相似的其他开关。
9. 回到语言页面 **Language & region** 或 **Languages & region**，把显示语言改回“简体中文”。
10. 回 Shizuku 重试启动；如果服务原来已运行但权限仍旧，按 [7.5 节](#_75-教程让你重新启动-shizuku-服务时，具体怎么点)“停止 Shizuku → 重新启动”，然后回小助手重新检查授权。

此方法在一加 Ace 6 / ColorOS 16.0.7 等具体固件的原始报告中出现，MAA 官方的实机演示视频里也有切英文的操作。较新 ColorOS 的部分版本已能直接显示对应选项，因此**不要求所有人都切英文**。见 [Shizuku 问题 #2149][S16]、[#374][S17] 和 [MAA 演示视频 03:08～03:53][M2]。

这个系统级开关与“只给 Shizuku 取消电池优化”是不同的东西。能正常启动时，优先保留原设置。

### 3.4 荣耀：MagicOS、Magic UI

1. 打开“设置”。
2. 进入“关于手机”；平板进入“关于平板电脑”。
3. 找到“版本号”，连续点击约 7 次。
4. 按提示输入锁屏密码，看到开发者模式已开启的提示后返回。
5. 进入“系统和更新”。
6. 点击 **“开发人员选项”**。荣耀常用“开发人员”这几个字，和“开发者选项”是同类入口。
7. 保持总开关开启，打开“USB 调试”。
8. 在页面中找“无线调试”：有则按 [方法 A](#_4-方法-a：只用手机，通过无线调试激活)；没有则按 [方法 B](#_5-方法-b：通过电脑和-usb-数据线激活)。

以上开发者入口依据 [荣耀官方支持][S18]。

**需要区分的两个名字：**

- 本文使用的是 **USB 调试 / 无线调试 / ADB**。
- **HDB** 是手机助理使用的另一种连接功能。打开 HDB 不等于 Shizuku 已启动，也不用专门为了无线配对去装荣耀手机助理。

如果 Shizuku 配对时经常消失，或切到设置就搜不到服务，按 [后台设置](#_73-只有切到后台就失败、搜索不到服务或经常掉线时，再检查这些设置) 为它关闭“自动管理”、允许后台活动。

如果 USB 方式下调试开关会关闭、仅充电时连接不上，检查本机是否提供“‘仅充电’模式下允许 ADB 调试”。存在且符合这个症状时再开启；无线配对不必为了寻找它卡住。参考 [荣耀社区答复][S19]。

### 3.5 华为：先分清 HarmonyOS / EMUI 的两种情况

#### 情况一：HarmonyOS 2～4.3 / 支持原生 Android 应用的 EMUI

[华为官方说明][S15]指出：这些系统没有无线调试设置项，建议使用有线 USB 调试。

所以，找不到“无线调试”时，**直接走电脑 USB 路线**，不用一直搜索这个不存在的菜单。

1. 打开“设置 → 关于手机 / 关于平板”。
2. 连续点击“版本号”；HarmonyOS 的部分界面显示为“HarmonyOS 版本 / HarmonyOS 版本号”，看到开发者模式开启提示就停。
3. 如需密码验证，输入本机锁屏密码。
4. 返回设置，进入“系统和更新 → 开发人员选项”。
5. 打开“USB 调试”。
6. 找到 **“‘仅充电’模式下允许 ADB 调试”**，本机有这一项时开启。它有助于避免充电模式下调试被关闭。
7. 进入 [方法 B：电脑 USB](#_5-方法-b：通过电脑和-usb-数据线激活)。

如果 USB 调试开关不能开启，先确认当前是机主的主空间，再检查数据线和连接模式。厂商管理模式限制应由设备所有者或管理员处理，不用跟着不明教程绕开管理。见 [华为 USB 调试排障][S20]、[开发者选项入口][S21]。

#### 情况二：HarmonyOS NEXT / HarmonyOS 5 及以上原生系统

**本教程的原版 Shizuku + Android ADB 路线不适用于它的原生环境。**

部分系统现在能通过“卓易通”等兼容环境运行某些 APK，但这是另一层运行环境；装进兼容环境的 Android 应用，不等于已经给原生手机系统取得了 Shizuku 权限。见 [华为官方说明][S22]。

目前没有已核实、可供新手照做的原生 Shizuku 激活方法，小助手安卓版也暂时无法在这类系统上使用。请改用满足[安卓版要求](/assets/docs/Android.md#使用前准备)的其他设备，或者使用[电脑版](/assets/docs/Tutorial.md)；不要为了本教程去降级、刷机。

## 4. 方法 A：只用手机，通过无线调试激活

**适用：Android 11 或更新，且本机提供“无线调试”。**

先完成自己品牌的开发者选项准备。下面所有操作，都在**要运行小助手的同一部手机**上完成。

本章把官方配对流程和当前原版中文界面拆成小步骤；相关入口可对照 [Shizuku 中文界面源码][S27]、[官方手册][S1]，整段流程也可以看 [视频教程 03:28～05:23][V1]。

### 4.1 确认手机已经连上 Wi-Fi

1. 打开“设置 → WLAN / Wi-Fi”。
2. 点自己要用的网络，输入 Wi-Fi 密码连接。
3. 等网络名称旁出现“已连接”。
4. 暂时不要在配对期间换网络。

状态栏只有“4G / 5G”不算连了 Wi-Fi。家里没有路由器，可以让另一部手机开热点，再让当前手机去连接。

### 4.2 先在 Shizuku 里点“配对”

1. 打开 **Shizuku**。可以从手机桌面打开，也可以点小助手权限引导里的“打开 Shizuku”。
2. 找到标题为“通过无线调试启动”的卡片。
3. 点击卡片里的 **“配对”**。
4. 如果系统询问是否允许 Shizuku 发送通知，选“允许”。
5. 如果页面提示通知被禁用，点击“通知设置”，开启“允许通知”，然后返回配对引导页。

**通知权限要开。** 普通手机上的原版 Shizuku，是通过通知里的输入框接收配对码。不是给它“读取全部通知”的权限，也不是去打开“通知使用权”。

### 4.3 进入手机系统的“无线调试”

1. 在 Shizuku 配对引导里点“开发者选项”；也可以手动回到自己的系统设置入口。
2. 确认“USB 调试”处于开启状态。
3. 向下找到 **“无线调试”**。
4. 打开它右边的开关。
5. 如果问“要允许通过此网络进行无线调试吗？”，点击“允许”。这是你熟悉的家庭 Wi-Fi 时，可以勾选“始终允许通过此网络进行调试”。
6. **再点“无线调试”这四个字所在的那一行，进入详情页。**

这一步有两个不同动作：**右边的小开关负责打开功能，左边的文字负责进入下一页。** 如果你只看到了一个开关，没有看到配对按钮，通常是还没点进去。

### 4.4 打开六位配对码窗口

1. 在无线调试详情页找到 **“使用配对码配对设备”**，点击。
2. 不选“使用二维码配对设备”。
3. 屏幕会弹出一个窗口，显示“Wi-Fi 配对码 / WLAN 配对码”等字样，下面一般是 **6 位数字**。
4. 记住这 6 位数字，或者先抄在纸上。
5. **保持这个窗口开着。现在不要按返回，不要点取消，也不要回桌面。**

窗口里还可能显示 IP 地址和端口，例如 `192.168.x.x:12345`。普通通知配对这一步用的是**六位配对码**，不是冒号后面的端口数字。

配对码只对当前这一轮有效。不要输入视频里的数字，也不要输入上次截图上的旧码。

### 4.5 保持配对窗口开着，下拉通知输入数字

1. 手指放在屏幕**最上边缘**，向下滑，拉出通知栏。
2. 如果拉出来的只有 Wi-Fi、蓝牙、亮度等按钮，没有通知，先收回，再从屏幕另一侧的顶部下拉。有些系统把控制中心和通知分在两边。
3. 找到来自 **Shizuku** 的通知。
4. 它可能先显示“正在搜索配对服务”；找到后会出现 **“输入配对码”**。
5. 如果通知只显示一行，点右侧的小箭头或展开按钮。
6. 点击“输入配对码”，输入刚刚记下的 6 位数字。
7. 点输入框旁边的发送箭头 / 确认按钮。
8. 等通知显示“配对成功”。

**不要为了填码，先切回 Shizuku 首页找输入框。** 留在系统的配对码窗口上方，下拉通知输入，最不容易中途丢掉这一轮配对。

如果点开输入框就失败，或者通知一直找不到配对服务，跳到 [配对问题排查](#_82-没有-shizuku-配对通知、找不到输入框)，不需要重装软件。

### 4.6 配对成功后，还要真正启动

1. 看到“配对成功”后，现在可以关闭配对码窗口。
2. 返回 Shizuku 首页。
3. 在 **“通过无线调试启动”** 卡片里点击 **“启动”**。
4. 屏幕可能出现很多英文和数字，那是启动日志。先等它完成，不用输入任何东西。
5. 回到首页，确认顶部显示 **“Shizuku 正在运行”** 或相近的运行状态。

“已配对设备”列表中出现 `shizuku`，只表示配对关系已经建立。**首页显示运行中，才表示服务启动成功。**

### 4.7 现在去给小助手授权

Shizuku 显示运行中后，直接进入 [第 6 章：给三月七小助手授权](#_6-最后一步：允许三月七小助手使用-shizuku)。

不用再做下面的电脑路线。

## 5. 方法 B：通过电脑和 USB 数据线激活

**适用：Android 10、没有无线调试的设备、无线方案反复失败的设备。**

这条路线用电脑帮手机启动一次 Shizuku。完成后，小助手仍然在手机上运行；不是让电脑版小助手一直控制手机。

准备：

- 你自己的或可信任的 Windows / Mac / Linux 电脑。
- 一条支持数据传输的 USB 线。
- 手机上的 Shizuku 已安装。
- 本机开发者选项和 USB 调试已打开。

### 5.1 Windows：下载并解压工具

1. **在电脑浏览器**打开 [Google 官方 SDK Platform-Tools 下载页][S28]。
2. 点击“下载适用于 Windows 的 SDK Platform-Tools”（英文页面写作 **Download SDK Platform-Tools for Windows**）。
3. 如出现条款窗口，阅读并确认后下载。
4. 找到下载好的 ZIP 文件。浏览器下载记录旁通常有“在文件夹中显示”。
5. 右键 ZIP，选择“全部解压缩”，再点击“解压缩”。
6. 打开解压出来的文件夹，继续进入 **`platform-tools`**。
7. 确认里面能看到 **`adb.exe`**。如果系统隐藏了扩展名，可能只显示 `adb`，类型是应用程序。

**不需要下载整套 Android Studio，也不需要双击 adb.exe。** 双击它可能只会闪一下黑窗口，本教程接下来会在命令窗口中运行它。

### 5.2 Windows：在正确的文件夹打开 PowerShell

1. 保持刚才含有 `adb.exe` 的文件夹打开。
2. 点击文件管理器**上方显示文件夹路径的地址栏**，不是右边的搜索框。
3. 把地址栏里原来的内容删掉，输入 `powershell`。
4. 按键盘 **Enter（回车）**。
5. 一个命令窗口会打开。后文说的“电脑窗口”，就是它，暂时不要关。
6. 复制下面一行，粘贴到窗口里，再按 Enter：

```powershell
.\adb.exe version
```

看到 **Android Debug Bridge version** 及版本号，说明位置正确，工具也能运行。

如果提示“找不到 `.\adb.exe`”，回上一节检查：要在真正包含 `adb.exe` 的那层文件夹里打开窗口，而不是外面的 ZIP 或下载目录。

### 5.3 Mac：下载工具并打开终端

Windows 用户直接跳到 [5.4 节](#_54-连接手机，让电脑认出它)。

1. 在 Mac 上打开 [官方 Platform-Tools 下载页][S28]，选择 Mac 版本。
2. 下载后双击 ZIP，解压出 `platform-tools` 文件夹。
3. 按 **Command + 空格**，搜索“终端”，打开。
4. 在终端输入 `cd `，注意字母后面有**一个空格**，先不要回车。
5. 把 Finder 里的 `platform-tools` 文件夹拖进终端。窗口里会自动补全文件夹路径。
6. 按 Enter，进入这个文件夹。
7. 输入下面一行，按 Enter：

```bash
./adb version
```

看到 **Android Debug Bridge version** 就可以继续。

后文 Windows 命令开头的 `.\adb.exe`，在 Mac 中对应 **`./adb`**。

Linux 用户同样下载官方 Linux 版、解压，在 `platform-tools` 里打开终端，使用 `./adb`。若出现 `no permissions`，看 [Linux USB 权限排查](#_87-linux-提示-no-permissions)。

### 5.4 连接手机，让电脑认出它

1. 手机保持解锁。
2. 确认“开发者选项”和“USB 调试”已经打开。
3. 用数据线把手机连到电脑。
4. 手机上如果出现“USB 用途”菜单，先保持当前模式；若后面电脑认不出，尝试“文件传输 / 传输文件”。
5. 在电脑刚才的窗口执行对应命令：

Windows：

```powershell
.\adb.exe devices
```

Mac / Linux：

```bash
./adb devices
```

6. **马上看手机屏幕。** 第一次通常会出现“允许 USB 调试吗？”的窗口。
7. 确认是你刚接上的电脑，点击“允许 / 确定”。这是自己的可信电脑时，可以勾选“一律允许使用这台计算机进行调试”。
8. 再在电脑执行一次同样的 `devices` 命令。

成功时，输出类似：

```text
List of devices attached
示例设备编号    device
```

前面那串设备编号每台手机不同，不用和示例一样。**关键看后面是 `device`。**

### 5.5 先确认设备状态，不要跳过

| 电脑输出 | 意思 | 接下来怎么做 |
| --- | --- | --- |
| 编号后面是 `device` | 连接已经可用 | 继续下一节启动 Shizuku |
| `unauthorized` | 手机还没有允许这台电脑调试 | 看手机弹窗，允许后再次执行 `devices` |
| `offline` | 发现了设备，但连接还没有正常工作 | 解锁手机、重新插拔数据线，再试 |
| 只有标题，下面空白 | 电脑还没认出手机 | 换数据线 / USB 接口，确认 USB 调试；必要时看驱动排查 |
| `more than one device/emulator` | 同时连接了多个设备或模拟器 | 先退出模拟器、拔掉其他设备，只保留当前手机 |

`device` 只说明电脑已经能与手机通信，**还不是 Shizuku 已启动**。下一节才是启动动作。

连接确认与授权机制依据 [Google ADB 文档][S2]。

### 5.6 在自己手机里取得“这台手机专用”的启动指令

1. 手机打开 **Shizuku**。
2. 找到 **“通过连接电脑启动”**，有的版本后面还写着“使用 adb”。
3. 点击 **“查看指令”**。
4. 点击“复制”或“发送”，取得窗口中显示的**完整一行指令**。
5. 把这行文字传到自己的电脑。可以用自己的文件传输助手、同步笔记等方式，电脑端再复制。
6. 不要复制别人截图上的路径；里面有些目录与**这台手机的这次安装**有关。
7. 电脑上只修改开头：

| 电脑系统 | 手机指令最前面的 `adb` 改成 |
| --- | --- |
| Windows PowerShell | `.\adb.exe` |
| Mac / Linux 终端 | `./adb` |

**其余部分原样保留，包括空格、斜杠、大小写。**

例如，较早版本手机显示这一行时：

```text
adb shell sh /sdcard/Android/data/moe.shizuku.privileged.api/start.sh
```

Windows 中对应：

```powershell
.\adb.exe shell sh /sdcard/Android/data/moe.shizuku.privileged.api/start.sh
```

**上面只是较早版本的示例。手机实际显示不同指令，就用手机显示的。**

Shizuku 13.6.0 已改用安装目录中的 `libshizuku.so`，与旧版 `start.sh` 不同。官方旧网页仍保留旧指令，所以“自己手机 → 查看指令”比照抄网上固定的一行更可靠。[13.6.0 发布说明][S3] [13.6.0 启动源码][S29] [13.5.4 启动源码][S30]

### 5.7 执行指令，检查手机

1. 把改好开头的完整指令，粘贴到电脑的同一个窗口。
2. 按 Enter。
3. 等输出结束，期间保持手机连接。
4. 看手机的 Shizuku 首页。
5. 显示 **“Shizuku 正在运行”** 就成功了。
6. 这时可以尝试拔掉数据线，再看一次是否仍显示运行中。
7. 正常运行就进入 [给三月七授权](#_6-最后一步：允许三月七小助手使用-shizuku)。

如果拔线后立即停止，查看华为 / 荣耀的“仅充电”调试开关，以及 [服务停止排查](#_74-服务启动后很快停止)。不需要重新安装小助手。

**Android 10 普通无 Root 设备：每次重启手机后，需要再连接电脑启动一次；不用重新下载工具。**

## 6. 最后一步：允许三月七小助手使用 Shizuku

前提：Shizuku 首页已经显示正在运行。

1. 回到“三月七小助手”。
2. 首页点击“去完成授权”。
3. 在权限引导中，确认选的是 **Shizuku**。
4. 安装和服务两项已经就绪后，在允许小助手使用 Shizuku 这一步点击 **“授权”**。
5. 弹出 Shizuku 授权窗口时，确认请求的应用是“三月七小助手”。
6. 点击 **“始终允许”**。
7. 回到小助手，看到 **“权限已就绪”**。
8. 点击“回到首页”。

如果没有弹窗：

1. 打开 Shizuku。
2. 点击首页显示“已授权 X 个应用”的那一栏，进入“应用管理”。
3. 找到“三月七小助手”，打开它旁边的开关。
4. 回小助手重新查看权限状态。
5. 列表里没有三月七时，先回三月七点击一次“授权”，让它发起请求，再检查列表。

### 完成检查

- Shizuku 首页显示正在运行。
- Shizuku 里三月七小助手已经获得授权。
- 三月七的权限引导显示“权限已就绪”。

这三项都完成，**Shizuku 激活与授权部分就做完了**。

如果此后游戏没登录、游戏版本不对、虚拟屏卡住，继续看三月七自己的运行说明或日志；这些问题要按具体报错处理，不用返回开头重复配对。

## 7. 以后再用、重启手机、避免后台失效

### 7.1 第二次使用，到底要不要从头再来

先打开 Shizuku 看首页，再决定怎么做。

| 你现在看到的情况 | 该做什么 |
| --- | --- |
| Shizuku 仍在运行，三月七也已授权 | 直接使用小助手 |
| Shizuku 没在运行，之前用无线调试启动过 | 连接 Wi-Fi，确认无线调试已打开，回 Shizuku 点“启动” |
| Shizuku 没在运行，之前用电脑 USB 启动 | 连接电脑，确认 `devices` 是 `device`，重新执行本机 Shizuku 的启动指令 |
| 点击无线启动后要求重新配对，或配对记录已经被删除 | 再做一次 [4.2～4.6 节的配对步骤](#_4-方法-a：只用手机，通过无线调试激活) |
| Shizuku 在运行，三月七仍提示未授权 | 去 [第 6 章](#_6-最后一步：允许三月七小助手使用-shizuku)，检查三月七的授权开关 |

**重新启动服务、重新配对、重新安装，是三件不同的事。** 普通重启手机后，通常不需要重装 Shizuku，也不必先删掉原有配对。

#### 为什么有人重启后会自动恢复，有人不会

Shizuku v13.6.0 的发布说明加入了 **Android 13 及以上，在受信任 Wi-Fi 环境下无 Root 自动启动**的支持；实际能否恢复，还受此前的启动方式、系统权限、机主用户和厂商后台行为影响。因此，本文统一采用“**重启后先看首页；没运行再启动**”的做法。[版本说明][S3] [启动逻辑][S39]

不要把设置里的“允许后台自启动”理解成“一定能永久自动激活 Shizuku”。它们解决的问题不同。使用旧版 Shizuku 的普通无 Root 设备、Android 10 的普通无 Root 设备，以及未满足新版条件的设备，仍需手动启动。

### 7.2 用完能不能拔线、换网络、关调试

- **电脑 USB 启动成功后，一般可以拔线。** 以拔线后 Shizuku 首页仍显示运行中为准。
- **换 Wi-Fi 或离开 Wi-Fi 后，系统可能关闭无线调试。** 再次需要无线启动时，重新连接 Wi-Fi，并检查开关。
- **无线调试连接结束，不必然等于 Shizuku 服务已经停止。** 判断依据仍然是 Shizuku 首页；不要只看系统通知就重新安装。
- **需要继续使用 Shizuku 时，保留开发者选项与 USB 调试。** 某些系统关闭这些开关会导致服务停止。
- **如果以后不再使用，** 可以在 Shizuku 首页点“已授权 X 个应用”，在“应用管理”里撤销三月七授权，再关闭不需要的调试开关。

调试连接、网络变化和服务停止的区别依据 [Shizuku 使用手册][S1] 与 [当前界面提示][S27]。

### 7.3 只有切到后台就失败、搜索不到服务或经常掉线时，再检查这些设置

以下操作的目的，是让手机不要在你切换到设置页面时，立刻限制 Shizuku。已经能稳定使用，可以跳过。

**先学会打开“应用信息”：**

1. 回到手机桌面，找到 Shizuku 图标。
2. 手指按住图标，先别松开。
3. 出现小菜单后，点“应用信息”“应用详情”，或圆圈里的 `i`。
4. 如果这个菜单没有入口，打开“设置 → 应用 / 应用管理”，在列表中找到 Shizuku。

后面提到应用电池设置、通知设置，很多都能从这里进入。

#### 小米 / Redmi：取消 Shizuku 的后台省电限制

1. 在设置搜索“电池”，进入 Shizuku 对应的应用耗电设置；部分机型可从 Shizuku 的应用信息进入。
2. 在“省电策略 / 电池使用”中，选择 **“无限制”**，英文可能显示 `No restrictions`。
3. 在设置搜索“自启动”或“后台自启动”。
4. 在应用列表中，只给 Shizuku 开启允许自启动。
5. 回到 Shizuku，重新进行刚才失败的配对或启动。

常见自启动路径是“设置 → 应用 / 应用设置 → 权限 / 权限管理 → 后台自启动”。菜单随机型变化。参考 [小米后台自启动说明][S31]、[小米后台网络与省电说明][S32]。

#### vivo / iQOO：允许 Shizuku 后台运行

1. 打开“设置 → 电池”。
2. 找到“后台耗电管理”或“后台高耗电”。
3. 找到 Shizuku，选择 **“允许后台高耗电 / 允许后台运行”**。
4. 如果设置里有“应用与权限 → 权限管理 → 权限 → 自启动”，给 Shizuku 开启；也可以直接搜索“自启动”。
5. 回 Shizuku 重试。

“允许后台高耗电”这个名字是在问是否允许它留在后台工作，不是要求你把手机电量耗光。这组路径来自 vivo 官方客服的后台管理说明，较新系统可能改名；找不到时从应用信息查看电池管理。[vivo 官方说明][S10]

#### OPPO / 一加 / 真我：允许后台活动

1. 进入 Shizuku 的“应用信息”。
2. 找“耗电管理 / 电池使用情况”。
3. 打开 **“允许后台活动”**；部分版本可能使用其他“允许后台运行”的表述。
4. 如果同页有“允许自启动 / 允许自动启动”，也为 Shizuku 开启。
5. 若应用信息里没有，在设置搜索“应用耗电管理”，找到 Shizuku 后设置。

部分真我机型的路径是“设置 → 电池 → 应用耗电管理”。参考 [realme 官方后台管理说明][S34] 与 [OPPO 应用后台设置示例][S38]；后者是华为为其应用提供的 OPPO 适配文档，本文只借用系统菜单路径，选择的应用仍是 Shizuku。

#### 荣耀：关闭 Shizuku 的“自动管理”，改为手动允许

1. 在设置顶部搜索 **“应用启动管理”**。
2. 进入后找到 Shizuku。
3. 关闭 Shizuku 旁边的 **“自动管理”**。
4. 在随后出现的手动管理窗口里，打开 **“允许后台活动”**。
5. 如同一窗口有“允许自启动”“允许关联启动”，也打开，再点“确定”。

这里关闭“自动管理”，是让你自己决定它能否运行，**不是关闭 Shizuku**。

如果仍被省电策略限制：

1. 在设置搜索“电池优化”。
2. 将列表筛选切换为“所有应用”，再找 Shizuku。
3. 进入后选择 **“不允许”**。

请看清标题：这里的“不允许”是 **不允许系统对 Shizuku 进行电池优化**，不是不允许 Shizuku 工作。参考 [荣耀后台运行说明][S33]、[荣耀启动管理说明][S40]。

#### 其他品牌

先从 Shizuku 的应用信息寻找“电池”“后台运行”“不受限制”等选项。如果手机支持多任务卡片加锁，可把 Shizuku 卡片锁住，避免“一键清理”误关；不同系统可能通过长按卡片、卡片菜单或向下滑动实现。

**后台锁不是保证永远运行的开关。** 仍需通过首页状态确认。

三月七自身运行任务时，也可能需要后台权限。可以进入小助手“设置”中的“后台运行与省电”，按应用内说明处理；如果是游戏被清理，再针对该游戏检查，不用把手机所有应用都改成无限制。见安卓版使用教程的[运行期间的注意事项](/assets/docs/Android.md#运行期间的注意事项)。

### 7.4 服务启动后很快停止

按这个顺序检查：

1. 先确认没有误关“开发者选项”总开关或“USB 调试”。
2. 看看停止是否总发生在锁屏、切后台或一键清理之后。如果是，按 [7.3 节](#_73-只有切到后台就失败、搜索不到服务或经常掉线时，再检查这些设置)处理 Shizuku 的后台限制。
3. 如果是华为 / 荣耀拔掉数据线后停止，回对应品牌章节检查“仅充电模式下允许 ADB 调试”这类开关；只在本机存在时设置。
4. 如果是长时间不用后调试授权反复失效，在开发者选项里查找 **“停用 ADB 授权超时功能 / 停用 adb 授权超时”**。存在这个选项时，可开启后再观察。它影响已信任调试连接的授权有效期，不是每台设备首次激活的必做项。
5. 重复启动一次 Shizuku，返回小助手检查授权是否恢复。

如果 Shizuku 一直显示运行中，只有三月七任务停止，则继续看小助手的日志与后台设置；这与 Shizuku 服务被停止是两个排查方向。[Shizuku 排障说明][S1]

### 7.5 教程让你“重新启动 Shizuku 服务”时，具体怎么点

这是重新启动 Shizuku 自己的服务，不是让你重启整部手机。

1. 如果小助手正在执行任务，先停止任务。
2. 打开 **Shizuku 首页**。
3. 点击右上角 **`⋮`（三个点 / 更多菜单）**。
4. 点击 **“停止 Shizuku”**。
5. 出现“Shizuku 服务将被停止”等确认提示时，点“确定”。
6. 确认首页变为未运行，再按原来的方法启动：无线用户回到无线调试卡片点“启动”；电脑用户重新连接电脑执行本机启动指令。
7. 看到正在运行后，回三月七检查授权状态。

如果首页本来就显示未运行，直接做第 6 步即可。不用清除应用数据，也不用卸载 Shizuku。

“停止 Shizuku”的菜单位置和确认动作已经对照原版界面与源码核对。[菜单定义][S42] [首页动作][S41] [中文名称][S27]

## 8. 遇到问题：按现象查

**先找你屏幕上的现象，不用把下面全部做一遍。** 一次只改一个相关设置，再重试刚才失败的步骤。

### 8.1 找不到开发者选项，或没有无线调试

| 现象 | 先做什么 |
| --- | --- |
| 连点后出现 Android 图案或彩蛋 | 点错了位置；回品牌章节，点击 OS / 软件 / 编译版本号 |
| 显示“您已处于开发者模式” | 已经开启；返回设置搜索“开发者选项”，不用继续连点 |
| 无线调试开关是灰色 | 先连接 Wi-Fi，检查开发者选项总开关是否开启 |
| Android 10 找不到无线调试 | 属于正常情况，走 [电脑 USB 方法](#_5-方法-b：通过电脑和-usb-数据线激活) |
| 华为 HarmonyOS 2～4.3 / EMUI 没有无线调试 | 走 [华为专章](#_35-华为：先分清-harmonyos-emui-的两种情况)与电脑 USB 方法 |
| Android 11 以上仍没有无线调试 | 系统版本号满足条件，也不代表厂商一定提供入口；搜索确认后走电脑 USB |
| 开关显示由管理员限制 | 检查是否在工作资料、儿童模式、访客或非机主空间；使用有权限管理的机主空间，受单位管理的设备联系管理者 |

无线调试的系统前提及厂商差异参考 [Android 官方文档][S2]、[华为官方说明][S15]。华为开发者选项还可能受机主 / 主空间状态影响。[华为 USB 调试排障][S20]

### 8.2 没有 Shizuku 配对通知、找不到输入框

#### 情况 A：通知栏里完全没有 Shizuku

1. 回到 Shizuku，在“通过无线调试启动”区域点一次“配对”。
2. 如果出现“通知设置 / 允许通知”提示，点击进入并允许。
3. 没有弹窗时，进入 Shizuku 的“应用信息 → 通知管理”，开启“允许通知”；如果有单独的“无线调试配对”通知类别，也开启。
4. 回 Shizuku，再点“配对”。
5. 切到开发者选项，重新打开“使用配对码配对设备”窗口。
6. 保持六位码窗口不关闭，再从屏幕顶部下拉查看通知。

这里需要的是 **允许 Shizuku 发通知**。不需要去开启“读取全部通知 / 通知使用权”这种特殊权限。[当前配对界面文案][S27]

#### 情况 B：看到了通知，但不能输入数字

1. 如果通知只有一行，点击右侧小箭头，把整张通知展开。
2. 点击“输入配对码”按钮或输入区域。
3. 输入当前六位数字，再点发送箭头 / 提交。
4. 如果下拉后只看到 Wi-Fi、蓝牙等大按钮，当前打开的是控制中心；收回后从屏幕顶部另一侧下拉，找到通知中心。
5. 旧 MIUI 若仍不能输入，按 [小米章节](#_31-小米-redmi-poco：hyperos、miui)检查原生通知样式。

不要退出配对码窗口，跑到 Shizuku 首页寻找一个通用“IP + 端口”输入框。本文采用官方原版常规手机界面的 **通知配对方式**。

#### 情况 C：一直显示“正在搜索配对服务”

1. 确认手机已连接 Wi-Fi。
2. 确认系统的 **“使用配对码配对设备”** 小窗口仍在屏幕上。只有打开“无线调试”大页面，通常还不够。
3. 允许 Shizuku 后台运行，尤其是从它切换到设置时会被限制的手机，见 [7.3 节](#_73-只有切到后台就失败、搜索不到服务或经常掉线时，再检查这些设置)。
4. 仍无结果，关闭六位码窗口，关闭再打开“无线调试”，然后重新打开六位码窗口。
5. 回到通知，使用这一轮的新配对码；不要继续输入上一次记下来的旧码。
6. 如果在公司、校园等受限网络，换成自己的家庭 Wi-Fi 或另一部手机的热点再试。
7. 仍失败就使用 [电脑 USB 方法](#_5-方法-b：通过电脑和-usb-数据线激活)。这一方法不需要先把无线配对做成功。

以上顺序结合 Shizuku 对后台发现服务的说明，以及 Android 对无线网络发现限制的说明。[Shizuku 手册][S1] [Android 无线调试][S2]

#### 情况 D：输入后立刻“配对失败”，或者输入键盘一弹出窗口就消失

1. 确认输的是本次 **六位配对码**，不是端口号。
2. 关闭旧配对窗口，再重新生成一次；新旧配对码不能混用。
3. 保持系统配对窗口存在，用通知直接输入，不在中间打开别的全屏应用。
4. 小米旧版系统检查通知样式；其他系统先检查通知和后台权限。
5. 某些系统可用小窗让配对窗口留在屏幕上；参考视频的 ColorOS 段演示了小窗辅助。但小窗入口随系统变化，这不是所有手机必须操作的一步。
6. 如果系统始终让输入与配对窗口互相打断，直接走电脑 USB，避免在同一步无限重试。

### 8.3 已经显示“配对成功”，Shizuku 为什么还是没运行

“配对成功”只说明它获得了建立调试连接的资格。接下来还要：

1. 关闭系统的配对码小窗口。
2. 回到 Shizuku 首页。
3. 在“通过无线调试启动”区域点击 **“启动”**。
4. 等待启动日志完成。
5. 返回首页，看是否出现“正在运行”。

如果启动阶段一直搜索：

1. 此时去检查的是 **无线调试总开关**是否仍打开、手机是否仍连接 Wi-Fi。
2. 已配对设备还在时，可以先直接再点“启动”；不必先删配对。
3. 只有连接明确报配对 / 认证失败，或配对记录丢失，再重新配对。
4. 持续无法启动可改用电脑 USB。

配对后的下一步也写在原版 Shizuku 自己的成功提示中。[界面文案][S27]

### 8.4 已运行却提示权限受限，或小助手不能点击屏幕

先分两层检查：

1. 在 Shizuku 首页点“已授权 X 个应用”，在“应用管理”里确认三月七的开关已打开。
2. 再按品牌检查与报错相符的额外调试权限：

| 品牌 | 要检查的开关 |
| --- | --- |
| 小米 / Redmi / POCO | “USB 调试”之外，还有 **“USB 调试（安全设置）”** |
| OPPO / 一加 / 真我 | 按 [3.3 节的开关对照表](#第三步：遇到adb-权限受限-制造商限制了权限时，按开关全名处理)，识别“权限监控”与“禁止权限监控”的相反方向 |
| 新版 ColorOS 系 | 仅在对应权限限制仍存在时，检查“禁用系统优化 / Disable system optimization”；需要时按正文切换语言查找 |

### 8.5 电脑 USB 方法失败

#### “adb 不是内部或外部命令” / “无法将 adb 识别为命令”

1. Windows 按 [5.2 节](#_5-方法-b：通过电脑和-usb-数据线激活)重新从 **包含 `adb.exe` 的 platform-tools 文件夹**打开 PowerShell。
2. 输入的是 `.\adb.exe devices`，不要漏掉开头的 `.\`。
3. Mac / Linux 输入 `./adb devices`，并确认终端已进入解压后的 platform-tools 文件夹。
4. 先让“查询设备”这一步能运行，再粘贴 Shizuku 启动指令。

#### 只有“List of devices attached”，下面是空白

1. 解锁手机屏幕，确认“USB 调试”已开。
2. 拔掉数据线，重新插上。
3. 留意手机上的 USB 调试授权弹窗，出现后点允许。
4. 换一条确定能传输文件的数据线，再换电脑上的 USB 插口；优先直接连电脑，先不经过扩展坞。
5. 如果手机只有充电提示，可点 USB 通知，试着切到“传输文件 / 文件传输”模式。这是排查连接的办法，不代表 ADB 永远必须使用这个模式。
6. Windows 仍识别不到时，在开始按钮上点鼠标右键，打开“设备管理器”，看看是否有带黄色叹号的 Android 或未知设备。
7. 需要驱动时，从手机厂商官方支持渠道或 [Google 的 OEM 驱动索引][S36]找该品牌驱动。安装后重新连接，运行 `devices`。

不要把 Google USB Driver 当成所有手机通用的驱动；它与各品牌自己的驱动不是一回事。Mac 通常不需要厂商 USB 驱动，Linux 的 USB 权限问题见下方专节。[官方 USB 连接说明][S37] [OEM 驱动说明][S36]

#### 设备后面显示 unauthorized

1. 保持手机亮屏解锁。
2. 查看“允许 USB 调试？”窗口，确认连接的是自己的电脑，点击允许。
3. 没有窗口时，拔插一次线，再观察。
4. 仍然不出现，可以在手机开发者选项点击“撤销 USB 调试授权”，再重新连接并允许。注意：这会让此前信任的电脑也需要重新确认；无线配对也可能需要重新做。
5. 电脑再执行一次 `devices`，直到设备后面变成 `device`。

#### 设备后面显示 offline

先解锁、拔插、重新打开 USB 调试。仍不行时，在原来的终端中一行一行执行：

Windows：

```powershell
.\adb.exe kill-server
.\adb.exe start-server
.\adb.exe devices
```

Mac / Linux：

```bash
./adb kill-server
./adb start-server
./adb devices
```

每输入一行按一次回车。这里重启的是电脑上的 ADB 连接服务，不会删除手机内容；其他正在使用这个 ADB 服务的工具会暂时断开。

#### 提示 more than one device/emulator

电脑同时连着多个手机、模拟器，或者同一手机还连着另一条调试连接。先关闭模拟器、拔掉其他手机，再查询。

如果列表仍有同一手机的无线连接，想让本次启动明确走 USB，可以在执行启动指令时加 `-d`。例如 Windows 将指令开头的 `.\adb.exe shell` 改成 `.\adb.exe -d shell`，Mac / Linux 将 `./adb shell` 改成 `./adb -d shell`；后面仍保留手机自己显示的完整内容。`-d` 表示选择 USB 连接。它用于选择执行命令的目标，`devices` 列表里仍可能显示其他连接。

#### 提示找不到 start.sh / libshizuku.so / No such file or directory

1. 回到手机当前安装的 Shizuku。
2. 再点一次“通过电脑连接启动 → 查看指令”。
3. 重新完整复制，尤其是中间很长的路径。
4. 按电脑系统只替换开头的 `adb`；不要手工改路径。
5. 如果你刚更新、重装 Shizuku，旧路径可能已经变化，旧笔记里的指令就不能继续用。

不要从别人手机上复制 `/data/app/…` 的路径。它不是每个人都一样。[当前版本生成指令的源码][S29]

### 8.6 三星提示“自动拦截器”阻止安装或 USB 操作

只在你明确遇到这个提示时处理：

1. 确认安装包来自 Shizuku 官方或三月七内置入口，电脑也是自己的。
2. 打开“设置 → 安全和隐私”。
3. 找到“自动拦截器 / Auto Blocker”。
4. 查看页面说明；如果确认就是它阻止了当前安装或 USB 调试操作，按系统提示暂时关闭，再重试。
5. 之后若重新开启，某些安装或 USB 命令可能再次受限；不能承诺“开回去以后所有调试都完全不受影响”。

三星官方明确列出了该功能对未知来源应用安装与 USB 命令的限制；并不是所有三星设备都需要改这个选项。[三星官方说明][S35]

### 8.7 Linux 提示 no permissions

这表示电脑已经发现 USB 设备，但当前 Linux 用户没有访问它的权限。不是 Shizuku 配对码错误。

**Ubuntu / 使用 apt 的相近系统**可参考 Android 官方要求，检查 `plugdev` 用户组与 Android 设备的 `udev` 规则。以下命令只用于这类系统：

```bash
sudo usermod -aG plugdev "$LOGNAME"
sudo apt-get install android-sdk-platform-tools-common
```

1. 按顺序执行。提示密码时输入 Linux 电脑的登录密码；终端输入密码时可能不显示星号，这是正常的。
2. 安装询问是否继续时，阅读包名并确认。
3. 退出 Linux 当前登录会话，再重新登录，让用户组变化生效；仅关闭终端通常不够。
4. 拔插手机，重新进入 platform-tools 文件夹执行 `./adb devices`。

其他发行版使用自己的 Android USB / udev 配置方式，不要照抄 Ubuntu 的包管理命令。也不要为了绕过设备权限，把日常所有 ADB 操作都改成 `sudo adb`。[Android 官方 Linux 配置说明][S37]

### 8.8 还是失败，怎样把问题说清楚

到 [GitHub Issues](https://github.com/moesnow/March7thAssistant/issues) 反馈时，把下面这段复制到求助消息中，能填多少填多少：

```text
手机品牌和型号：
系统名称和完整版本号：
Android 版本：
Shizuku 版本：
三月七小助手版本：
使用的方法：无线 / Windows USB / Mac USB / Linux USB / 已有 Root
卡住的阶段：安装 / 开发者选项 / 配对 / 启动 / 小助手授权 / 任务运行
Shizuku 首页当前显示：
完整报错文字：

```

最好附“Shizuku 首页”和“报错窗口”两张截图。只写“不能用”或“我的也是某某品牌”，很难判断是哪一步。问题出在小助手运行任务时，再到小助手“日志”页点“导出”，把日志文件一起附上。

截图中可以遮住手机号、账号、设备序列号和与问题无关的通知内容；求助不需要提供锁屏密码或当次配对码。

## 9. 已经 Root 的手机

**这一章只给已经完成 Root 的用户。** 不知道 Root 是什么，就继续使用前面的无线或电脑方法。

已经 Root 的手机可以在小助手权限引导的顶部直接选 **Root**，不需要 Shizuku，步骤见安卓版使用教程的[方式二：Root](/assets/docs/Android.md#方式二：root)。Root 方式遇到问题、想改用 Shizuku 时，可以用 Root 启动 Shizuku：

1. 打开 Shizuku。
2. 找到“启动（针对已 root 设备）”这一栏，点击“启动”。
3. 手机现有的 Root 管理器弹出授权窗口时，确认请求者是 Shizuku，然后允许。
4. 等 Shizuku 首页显示正在运行。
5. 继续 [第 6 章](#_6-最后一步：允许三月七小助手使用-shizuku)，给三月七授权。

原版 Shizuku 的设置里还有“开机启动（root）”选项。它面向已有 Root 的设备；不要把这个选项误认为普通无 Root 手机的万能开机激活按钮。[官方使用手册][S1] [当前设置文案][S27]
