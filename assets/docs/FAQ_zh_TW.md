### Q：小助手總是更新失敗/下載速度緩慢 怎麼辦？

A：March7thAssistant 接入了第三方服務 [Mirror醬](https://mirrorchyan.com/?source=m7a-faq)（一個給開源社群做有償內容分發的平臺）。

它為我們提供了免費的檢查更新介面，但它的下載是有償的，需要使用者付費使用。

不過，即使不購買 Mirror 醬的下載服務，你也可以在檢測到更新後，在設定裡選擇從海外源（GitHub）下載~

如果你購買並填寫了 CDK，更新時就再也不用和自己的網路環境鬥智鬥勇咯，下載更快更穩定！

同時 CDK 也可以用於其他接入 Mirror醬 的專案，例如 MAA 等。

[首次下載可點我前往 Mirror醬 高速下載](https://mirrorchyan.com/zh/download?rid=March7thAssistant&os=&arch=&channel=stable&source=m7a-faq)

### Q：小助手啟動慢/未找到執行檔/程序啟動失敗/總是被防毒軟體刪除 怎麼辦？

A：請將`小助手資料夾`加入防毒軟體排除項/白名單/信任區，然後重新解壓覆蓋一次。

Windows Defender：`病毒和威脅防護` → `管理設定` → `新增或刪除排除項` 可以參考 [#373](https://github.com/moesnow/March7thAssistant/issues/373) 圖示操作

（注意：可能還需要將 `應用和瀏覽器控制` → `智慧應用控制設定` → `切換為關閉` ）

火絨安全軟體：`主介面` → `右上角選單` → `信任區` 可以參考 [教程](https://cs.xunyou.com/html/282/15252.shtml) 圖示操作

### Q：開了濾鏡、幀率顯示或效能檢測軟體後，為什麼總是識別失敗/提示切換到介面失敗？

A：這類軟體會在遊戲畫面上疊加額外文字或特效，導致小助手的影像識別和 OCR 判斷失敗。

常見影響項包括：`N 卡遊戲濾鏡`、`HDR`、`幀率監控 HUD`、`微星小飛機 / Afterburner`、`RTSS`、`遊戲加加`，

以及各種會顯示 `FPS / CPU / GPU` 的懸浮窗。

另外，部分筆記本/主機板廠商自帶軟體也會提供類似的功能，例如 `護眼模式`、`鮮豔模式`、`遊戲增強`、`色彩最佳化`、`場景模式` 等，

這些功能即使沒有明顯懸浮窗，也可能直接改變畫面的顏色、亮度、對比度。

請先完全關閉這些濾鏡、硬體監控和效能檢測軟體後再重試。

有些濾鏡或畫面增強因為你自己已經看習慣了，反而最不容易發現；

如果沒有看到大量其他使用者同時報同樣的錯誤，通常優先按你自己電腦上的環境問題排查。

如果日誌裡出現了類似 `檢測到疑似監控懸浮窗文字` 的提示，基本就是這個問題。

你也可以開啟小助手 `工具箱 → 遊戲截圖`，檢查程式實際獲取到的畫面是否乾淨、是否被懸浮窗遮擋。

### Q：差分宇宙/模擬宇宙/飾品提取怎麼不會選擇角色/自動選擇 XXX 角色，如何更換角色？

A：以上功能使用遊戲內自動記憶的配隊，如果檢測到缺少角色，會自動嘗試選擇 “隊伍1”。

如需更換角色，可以手動配置好隊伍後，進入一次對應的介面，隨後退出檢查遊戲內記憶的配隊是否更新即可。

### Q：為什麼不會自動戰鬥/不會互動隨意門/角色在亂跑？

A：這類問題大多是 `按鍵設定和小助手預設假設不一致` 導致的，可以按下面順序排查：

1. 先檢查你是否修改過遊戲內預設按鍵，重點看：自動戰鬥、互動（`F`）、角色詳細（`C`）、角色移動（`WASD`）。如果改過自動戰鬥鍵，可以在小助手 `設定 → 雜項 → 修改按鍵` 中同步修改。注意：互動（`F`）和角色詳細（`C`）不能修改，必須保持遊戲預設設定，否則會導致識別失敗。其他按鍵也建議保持預設。

2. 再檢查小助手 `設定 → 雜項 → 啟用自動戰鬥和二倍速檢測` 是否已經開啟。

3. 如果問題只出在自動戰鬥，再檢查遊戲內 `設定 → 戰鬥功能 → 是否沿用自動戰鬥設定` 是否為“是”；必要時可以先手動開啟一次自動戰鬥後再試。

### Q：開始執行後就不能移動鍵盤滑鼠和切換到後臺了嗎

A：本地遊戲模式下，大多數自動化仍然依賴當前桌面畫面和輸入狀態，執行時不建議搶佔鍵盤滑鼠，也不建議切到後臺。

如果你需要後臺執行，優先考慮使用 `雲·星穹鐵道`：目前清體力、每日實訓、貨幣戰爭、差分宇宙等任務支援後臺執行；

鋤大地和模擬宇宙仍需要前臺全屏。

如果你需要本地模式後臺掛機，也可以嘗試 [遠端本地多使用者桌面](https://m7a.top/#/assets/docs/Background)。

### Q：完整執行的作用是什麼

A：`完整執行` 會根據你當前的開關和重新整理狀態，自動處理已啟用的內容，通常包括：

兌換碼、每日實訓、活動、歷戰餘響、清體力、貨幣戰爭積分獎勵、差分宇宙積分獎勵、

鋤大地、模擬宇宙 / 差分宇宙、混沌回憶、虛構敘事、末日幻影，以及最後的領取獎勵。

已經完成或尚未重新整理的內容會自動跳過。預設日常重新整理時間為每天凌晨 4 點，周常重新整理時間一般為每週一凌晨 4 點。

### Q：提示視窗找不到怎麼辦

A：請檢查是否將遊戲內語言設定為簡體中文。

### Q：缺少新增加的副本？逐光撿金缺少新角色？

A：首先確保是最新版本，如果仍然缺少副本，編輯 `assets\config\instance_names.json` 檔案手動新增。

如果 `混沌回憶 / 虛構敘事 / 末日幻影 / 支援` 中缺少新角色，

可以在對應介面裡用小助手工具箱中的`捕獲截圖`功能，勾選角色頭像，點選`儲存所選截圖`後，

放入 `assets\images\share\character` ，並修改 `assets\config\character_names.json` 檔案。

同時歡迎用`未壓縮`的方式上傳到 [Issue](https://github.com/moesnow/March7thAssistant/issues)，比如壓縮包，或者 [PR](https://github.com/moesnow/March7thAssistant/pulls) 也可以。

### Q：執行過程中記憶體佔用持續升高 / 遊戲突然無響應或閃退 / 系統崩潰重啟怎麼辦？

A：如果出現記憶體佔用異常偏高、程式無故閃退，或執行途中游戲畫面出現異常，優先排查 OCR 加速模式的相容性。

小助手預設在 Windows 10 18362 及以上使用 ONNXRuntime DirectML GPU 加速；

在不支援 DirectML 的環境（如 Linux、部分 ARM 裝置）下，若檢測到 OpenVINO 則自動使用 OpenVINO CPU 推理。

**當前版本已針對 OpenVINO CPU runtime cache 問題應用臨時規避方案**，一般不再需要通過定期重建引擎來壓制記憶體增長，

並在可用實體記憶體低於 1GB 時自動切換到 ONNXRuntime CPU；但如果機器本身記憶體極小或系統負載過高，仍可能出現明顯波動。

**建議先將 OCR 加速模式手動切換為 `CPU (ONNXRuntime)`**（設定 → 雜項 → OCR 加速模式），

切換後重新執行，觀察記憶體和穩定性是否改善。如果問題消失，說明原模式與當前環境存在相容問題，保持 ONNXRuntime CPU 即可。

如果使用 DirectML GPU 加速時出現閃退或識別異常，同樣建議先回退到 `CPU (ONNXRuntime)` 排查。

### Q：雙擊啟動後窗口一閃而過 / 圖形介面根本打不開 / 終端裡執行命令時視窗一閃而過怎麼辦？

A：這幾種現象通常可以放在一起排查。

如果你是直接雙擊 `March7th Launcher.exe` 或其他執行檔後，發現終端視窗一閃而過、圖形介面根本沒有開啟，

建議改用終端手動啟動，這樣更容易看到具體報錯資訊。

請使用`管理員模式`開啟 PowerShell、Windows Terminal 或 CMD 後，再進入小助手目錄執行對應命令。

例如可以先嚐試：

PowerShell 使用：

```powershell
& '.\March7th Launcher.exe' -S
```

CMD 使用：

```cmd
"March7th Launcher.exe" -S
```

如果你的系統支援 [Sudo for Windows](https://learn.microsoft.com/zh-cn/windows/advanced-settings/sudo/)，也可以直接使用 `sudo`。

根據微軟文件，`Sudo for Windows` 僅在 Windows 11 版本 24H2 或更高版本中可用，使用前還需要先在系統設定中啟用。

如果改用終端啟動後能看到報錯，請優先根據報錯內容排查；

常見原因仍然是許可權不足、防毒軟體誤刪檔案、依賴被攔截，或者工作目錄不正確。
