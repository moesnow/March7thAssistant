桌面分身会在这台电脑上用你的 Windows 账户再登录一个独立的桌面，让游戏和小助手在里面运行，画面显示在一个窗口中。小助手在分身里操作游戏，不会占用你的鼠标、键盘和当前窗口，任务运行时可以照常使用电脑。

> 这是实验性功能，基于 Windows 自带的“本地子会话”（与 Power Automate 的画中画模式、BetterGI 的桌面分身是同一项系统技术）。遇到问题欢迎附上日志[反馈](https://github.com/moesnow/March7thAssistant/issues)。其他不占用键鼠的方式见[后台运行](/assets/docs/Background.md)。

## 使用前提

- Windows 10 或 Windows 11 的**专业版、企业版**。微软不支持在家庭版上使用本地子会话，家庭版即使能用，出了问题也难以排查。
- 当前 Windows 账户需要**设置登录密码**。主桌面可以继续用 PIN 或 Windows Hello。分身使用账户密码验证，可在分身窗口保存后复用。
- 首次使用需要以管理员身份开启 Windows 的本地子会话功能。正常启动的小助手会自动申请管理员权限，不需要额外操作。
- 游戏使用本地客户端并“直接启动”：在「设置 → 运行方式 → 游戏路径」中选好 `StarRail.exe`，展开后的「游戏启动方式」选“直接启动”。分身暂不支持通过 Epic 启动，也不使用云·星穹铁道。
- 远程桌面、UAC、多用户等系统组件没有被精简或修改过。打过多用户远程桌面补丁（例如 RDPWrap）的系统可能无法使用。
- 一台电脑同一时间只能开启一个分身。

## 开始使用

1. 打开小助手，进入「工具箱 → 桌面分身」，点「打开」。也可以从托盘菜单打开。
2. 阅读说明后点「启动分身」。
   - 主桌面的小助手正在运行任务（包括命令行发起的任务、正在启动游戏、等待执行的完成后操作）时不能启动，等任务结束或先停止任务。
   - 先关闭主桌面里的游戏。游戏同一时间只能在一个桌面运行。
3. 第一次使用会询问是否「开启本地子会话」，点「开启」。这是一项 Windows 系统设置，开启后会一直保留，注销分身也不会还原。
4. Windows 可能会要求验证身份，输入当前账户的密码。第一次登录分身需要准备新桌面，可能要等一会儿。
5. 登录完成后，窗口中会显示分身桌面，分身里的小助手会自动打开，标题栏带有「桌面分身」标记。
6. 之后和平时一样，在分身窗口里点击小助手运行任务，小助手会在分身里启动游戏并完成任务。

分身桌面的分辨率固定为 1920×1080，拖动窗口边缘或四角可以按 16:9 缩放。窗口可以最小化和最大化，最大化时画面保持 16:9；窗口足够宽时（例如在 16:9 屏幕上最大化），底部的按钮会竖排到画面右侧，让画面更大。隐藏或最小化窗口时，分身会自动静音。重新显示窗口后，声音回到隐藏前的状态。

## 窗口上的按钮

| 按钮 | 作用 |
| --- | --- |
| 打开小助手 | 在分身中打开小助手，已经打开时切换到它 |
| 声音开启 / 声音关闭 | 新分身默认显示「声音开启」。点击切换为「声音关闭」，再次点击恢复。隐藏或最小化后重新打开窗口，会保留手动选择 |
| 隐藏 | 隐藏窗口并静音分身，分身和其中的任务继续运行 |
| 注销分身 | 分身里的小助手先停止任务并退出，随后注销分身，其中的游戏和应用都会关闭 |
| 重新连接 | 连接意外断开后出现。控制窗口被强制结束后，重新打开桌面分身也可尝试连回原来的分身 |
| 使用文档 | 打开本页 |

隐藏后可以从这些地方重新打开分身窗口：托盘菜单的「桌面分身（运行中）」、「工具箱 → 桌面分身」，或者主界面顶部提示条上的「打开分身窗口」。

直接关闭分身窗口时，会询问要「注销分身」还是「隐藏窗口」。

> 在分身桌面里手动双击小助手不会打开新的小助手，请使用分身窗口上的「打开小助手」按钮。

## 分身运行期间

### 主桌面的小助手

分身运行期间，任务、定时任务和设置都交给分身里的小助手。为了避免两边同时修改同一份配置、操作同一个游戏，主桌面小助手的页面会暂停操作（显示为灰色），顶部提示“桌面分身运行中”。注销分身后自动恢复，在分身里修改的设置也会同步回来。

- 定时任务由分身里的小助手按时运行，注销分身后回到主桌面运行。
- 通过快捷方式等方式要求主界面运行任务时，会提示“主界面暂停期间无法启动任务”。
- 分身里有任务在运行时，主桌面的命令行（包括 [AI 助手](/assets/docs/Agent.md)）不能再启动任务，`--force` 也无法越过。
- 退出主桌面的小助手前，需要先注销分身。
- 安装小助手更新前，需要先注销分身。

### 分身里的小助手

分身里的小助手和主桌面使用同一份配置，但为了不影响主桌面，会自动改用以下设置，配置文件本身不会因此改变：

- 本地操作模式固定为前台。分身里的键鼠操作本来就不影响你，不需要后台模式。
- 使用本地游戏，不使用云·星穹铁道，不通过启动器更新游戏。
- 不临时降低画质，不修改分辨率和自动 HDR，也不自动配置游戏路径。这些操作会改动和主桌面共用的游戏设置。
- 不在启动游戏前改写自动战斗和二倍速。这两项同样会改动和主桌面共用的游戏设置，分身里改由战斗中的检测补开。
- 战斗中的自动战斗检测照常生效：检测到没有开启自动战斗时会按 V 补开，清体力等战斗还会补开二倍速。也可以先在游戏里把它设成默认开启。
- 任务完成后不执行关机、睡眠、注销等系统操作。
- 不自动检查小助手更新，也不能在分身里安装更新。

### 连接断开时

分身连接意外断开后，分身里正在运行的任务会被停止。窗口会显示“分身连接已断开”，点「重新连接」可以回到原来的分身，里面的游戏和小助手仍然保留。

如果控制窗口被强制结束，重新打开「桌面分身」后也可以点「重新连接」。连回原桌面后，小助手会在分身里重新打开。连不上时可点「注销分身」关闭分身里的游戏和应用，等 Windows 注销完成后再点「启动分身」。

## 注意事项

- 分身打开期间，Windows 无法重启或关机，请先注销分身。
- 登录分身时，设置了开机自启的软件也会在分身里再启动一份，可能和主桌面里的同一软件冲突（小助手自己已经处理了这种情况）。不需要的话，可以在任务管理器的「启动应用」里关掉它们的开机自启。
- 部分软件不能在两个桌面同时运行，例如游戏本身、米哈游启动器，以及使用同一个用户配置的浏览器。分身运行游戏时，主桌面不能再打开游戏。
- 第一次登录分身较慢。需要多次运行任务时，可以保持分身开启、只隐藏窗口，省去每次重新登录。

## 常见问题

### 启动或连接时的提示

| 提示 | 处理方法 |
| --- | --- |
| 请先结束主桌面的任务再连接分身 | 主桌面的小助手或命令行正在运行任务、启动游戏，或者在等待执行完成后操作。等它结束或先停止任务 |
| 另一个小助手正在使用桌面分身 | 其他位置安装的小助手，或其他 Windows 账户里的小助手已经开启了分身。一台电脑同时只能有一个分身，先在那边注销 |
| 请以管理员身份运行小助手 | 开启本地子会话需要管理员权限，请以管理员身份重新打开小助手 |
| 会话 N 已占用桌面分身。请先注销该会话后重试 | 小助手无法确认该会话可重新连接。先在原来的控制窗口注销分身。如果原窗口已退出，可在任务管理器的「用户」页核对会话 ID，确认是分身后再注销 |
| 请用当前桌面的登录账户启动小助手 | 小助手是用其他账户启动的（例如“以其他用户身份运行”）。请用当前登录 Windows 的账户启动 |
| 分身与主桌面的登录账户不同 | 登录分身时用了其他账户，请使用当前账户登录 |
| 分身连接失败（RDP 516） | [排查本机子会话的连接](#rdp-516) |
| 分身连接失败（其他 RDP 错误码） | 数字是 Windows 给出的错误码，反馈时请一并附上。先重开小助手，仍然失败就重启电脑后再试。若已出现登录框并提示凭据错误，参照下文的「输入密码后提示不正确」 |
| 连接分身超时 | 90 秒内没有完成登录。第一次登录较慢，可以再试一次；如果弹出了输入密码的窗口，看看它是不是被其他窗口挡住了 |
| 等待分身中的小助手启动超时 | 点「打开小助手」再试一次 |
| 会话身份已变化，请在 Windows 中检查分身 | 分身已在别处被注销或替换（例如在任务管理器中注销）。关闭分身窗口后重新启动 |
| 等待分身注销超时 | Windows 没能在 20 秒内注销分身。再点一次「注销分身」，或者在任务管理器的「用户」页注销 |

### RDP 516

516（0x204）表示 Windows 无法建立到本机子会话的 RDP 连接。先完全退出小助手并重新打开，仍然失败时重启 Windows 再试一次。详见 [微软的 RDP 错误码说明](https://learn.microsoft.com/en-us/windows/win32/termserv/imstscaxevents-ondisconnected)。

在 PowerShell 中运行以下命令，查看远程桌面服务状态及其加载的 DLL。

```powershell
Get-Service TermService | Select-Object Status, StartType
Get-ItemPropertyValue 'HKLM:\SYSTEM\CurrentControlSet\Services\TermService\Parameters' ServiceDll
```

- 如果 `ServiceDll` 指向第三方 DLL，或系统装过 SuperRDP、RDP Wrapper 等多用户远程桌面补丁，优先排查补丁冲突。可以通过原工具的卸载或恢复功能还原 Windows 原生远程桌面服务，重启后再试。参见 [BetterGI 的 SuperRDP 复现记录](https://github.com/babalae/better-genshin-impact/issues/3409#issuecomment-5220177847)。
- 如果找不到 `TermService`，或启动类型是 `Disabled`，检查系统精简或优化工具是否移除或停用了「远程桌面服务」，尝试恢复该工具修改前的系统配置。

仍然报错时，请反馈小助手版本、`winver` 显示的 Windows 版本和内部版本号、上述命令的输出，以及是否装过多用户远程桌面补丁。可以同时附上事件查看器「应用程序和服务日志 → Microsoft → Windows → TerminalServices-RDPClient → Operational」中报错时间附近的事件 226 和 1026。

### 运行任务时的提示

| 提示 | 处理方法 |
| --- | --- |
| 桌面分身需要直接启动本地游戏 | 在「设置 → 运行方式 → 游戏路径」展开「游戏启动方式」，选择“直接启动” |
| 请先在设置中填写本地游戏路径 | 在「设置 → 运行方式 → 游戏路径」中选择 `StarRail.exe` |
| 请先关闭其他桌面会话中的游戏 | 主桌面里的游戏还开着，关掉后再在分身里运行任务 |
| 请先关闭桌面分身再安装更新 | 注销分身后再安装更新 |

### 每次连接都要输入密码

在分身说明页底栏点「自动登录」，核对 Windows 账户名。如果账户名为空或需要纠正，可在输入框中填写系统登录框显示的完整账户名。输入账户密码并点「保存密码」。以后点「启动分身」会使用这条凭据，主桌面可以继续使用 PIN。密码保存在本机 Windows 凭据管理器中，以当前 Windows 用户身份运行的其他程序也可能读取它。

已保存密码时，每次打开「自动登录」都会显示「已保存分身密码」，账户输入框为只读。点「删除密码」会立即删除这条本机凭据，原窗口随即恢复可编辑的账户和密码输入框。需要换密码时，可直接输入新密码并保存。未保存密码时，直接点「启动分身」，按 Windows 提示登录即可。

如果 Windows 仍要求输入账户密码，可以保持分身开启、只隐藏窗口，之后在同一会话里继续运行任务。

### 输入密码后提示不正确

如果 Windows 反复提示“你的凭据不工作”“登录没有成功”，先点密码框中的「取消」，回到小助手的分身窗口。取消后可能显示「分身连接失败（RDP 1）」。

当 Windows 使用“仅来宾”验证方式时，小助手会在错误提示旁显示「调整并重试」。阅读提示中的影响后点击，小助手会将验证方式改为“经典”，按实际账户身份验证，并自动重新连接分身。

这项设置也会影响本机共享文件夹等资源的访问方式。小助手会保存原值；需要撤销时，在未连接分身的说明页点击「恢复原验证设置」。恢复后，分身可能再次无法连接。若修改时提示权限不足，请以管理员身份重新打开小助手；如果设置受组织管理，请联系管理员。

旧版小助手没有此按钮时，可以按 `Win + R`，输入 `secpol.msc`，在「本地策略 → 安全选项」中找到「网络访问：本地帐户的共享和安全模型」。如果当前为“仅来宾”，将其改为“经典”，然后完全退出小助手并重新打开，再试一次。

如果没有检测到“仅来宾”模式，继续检查 Windows 账户：

- 使用 Microsoft 账户时，在「设置 → 账户 → 登录选项」中关闭“仅允许使用 Windows Hello 登录 Microsoft 帐户”一项（具体名称以系统为准），重启电脑后再试。
- 在网页上改过 Microsoft 账户密码后，本机可能还没同步新密码。可以在命令提示符中运行 `runas /u:MicrosoftAccount\你的账户邮箱 cmd`，按提示输入新密码同步一次。
- 仍然不行的话，可以改用本地账户登录 Windows。

### 不想用了怎么办

点「注销分身」即可，分身里的一切都会关闭，主桌面的小助手自动恢复。开启过的本地子会话是 Windows 的一项系统设置，会继续保留，不影响平时使用。
