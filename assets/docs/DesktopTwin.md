桌面分身会在这台电脑上用你的 Windows 账户再登录一个独立的桌面，让游戏和小助手在里面运行，画面显示在一个窗口中。小助手在分身里操作游戏，不会占用你的鼠标、键盘和当前窗口，任务运行时可以照常使用电脑。

> 这是实验性功能，基于 Windows 自带的“本地子会话”（与 Power Automate 的画中画模式、BetterGI 的桌面分身是同一项系统技术）。遇到问题欢迎附上日志[反馈](https://github.com/moesnow/March7thAssistant/issues)。其他不占用键鼠的方式见[后台运行](/assets/docs/Background.md)。

## 使用前提

- Windows 10 或 Windows 11 的**专业版、企业版**。微软不支持在家庭版上使用本地子会话，家庭版即使能用，出了问题也难以排查。
- 当前 Windows 账户需要**设置登录密码**。平时用 PIN 或 Windows Hello 登录的话，连接分身时需要输入账户密码（Microsoft 账户就是它的账户密码），不能用 PIN 代替。
- 首次使用需要以管理员身份开启 Windows 的本地子会话功能。正常启动的小助手会自动申请管理员权限，不需要额外操作。
- 游戏使用本地客户端并“直接启动”：在「设置 → 程序 → 游戏路径」中选好 `StarRail.exe`，展开后的「游戏启动方式」选“直接启动”。分身暂不支持通过 Epic 启动，也不使用云·星穹铁道。
- 远程桌面、UAC、多用户等系统组件没有被精简或修改过。打过多用户远程桌面补丁（例如 RDPWrap）的系统可能无法使用。
- 一台电脑同一时间只能开启一个分身。

## 开始使用

1. 打开小助手，进入「工具箱 → 桌面分身」，点「打开」。也可以从托盘菜单打开。
2. 阅读说明后点「启动分身」。
   - 主桌面的小助手正在运行任务（包括命令行发起的任务、正在启动游戏、等待执行的完成后操作）时不能启动，等任务结束或先停止任务。
   - 先关闭主桌面里的游戏。游戏同一时间只能在一个桌面运行。
3. 第一次使用会询问是否「开启本地子会话」，点「开启」。这是一项 Windows 系统设置，开启后会一直保留，注销分身也不会还原。
4. Windows 可能会要求验证身份，输入当前账户的密码。第一次登录分身需要准备新桌面，可能要等一会儿。
5. 登录完成后，窗口中会显示分身桌面，分身里的小助手会自动打开，标题栏带有「桌面分身」标记。
6. 之后和平时一样，在分身窗口里点击小助手运行任务，小助手会在分身里启动游戏并完成任务。

分身桌面的分辨率固定为 1920×1080，拖动窗口边缘或四角可以按 16:9 缩放。窗口可以最小化和最大化，最大化时画面保持 16:9 居中显示；最小化时和隐藏一样会静音分身，恢复显示后自动恢复声音。

## 窗口上的按钮

| 按钮 | 作用 |
| --- | --- |
| 打开小助手 | 在分身中打开小助手，已经打开时切换到它 |
| 隐藏 | 隐藏窗口并静音分身，分身和其中的任务继续运行；重新打开窗口后恢复声音 |
| 注销分身 | 分身里的小助手先停止任务并退出，随后注销分身，其中的游戏和应用都会关闭 |
| 重新连接 | 连接意外断开后出现，重新连回原来的分身 |
| 使用文档 | 打开本页 |

隐藏后可以从这些地方重新打开分身窗口：托盘菜单的「桌面分身（运行中）」、「工具箱 → 桌面分身」，或者主界面顶部提示条上的「打开分身窗口」。

直接关闭分身窗口时，会询问要「注销分身」还是「隐藏窗口」。

> 在分身桌面里手动双击小助手不会打开新的小助手，请使用分身窗口底部的「打开小助手」。

## 分身运行期间

### 主桌面的小助手

分身运行期间，任务、定时任务和设置都交给分身里的小助手。为了避免两边同时修改同一份配置、操作同一个游戏，主桌面小助手的页面会暂停操作（显示为灰色），顶部提示“桌面分身运行中”。注销分身后自动恢复，在分身里修改的设置也会同步回来。

- 定时任务由分身里的小助手按时运行，注销分身后回到主桌面运行。
- 通过快捷方式等方式要求主界面运行任务时，会提示“主界面暂停期间无法启动任务”。
- 分身里有任务在运行时，主桌面的命令行（包括 [AI 助手](/assets/docs/Agent.md)）不能再启动任务，`--force` 也无法越过。
- 退出主桌面的小助手前，需要先注销分身。
- 安装小助手更新前，需要先注销分身。

### 分身里的小助手

分身里的小助手和主桌面使用同一份配置，但为了不影响主桌面，会自动改用以下设置，配置文件本身不会因此改变：

- 本地操作模式固定为前台。分身里的键鼠操作本来就不影响你，不需要后台模式。
- 使用本地游戏，不使用云·星穹铁道，不通过启动器更新游戏。
- 不临时降低画质，不修改分辨率和自动 HDR，也不自动配置游戏路径。这些操作会改动和主桌面共用的游戏设置。
- 不在启动游戏前改写自动战斗和二倍速，也不在战斗中检测并保持自动战斗。需要的话，请先在游戏里开好自动战斗和二倍速。
- 任务完成后不执行关机、睡眠、注销等系统操作。
- 不自动检查小助手更新，也不能在分身里安装更新。

### 连接断开时

分身连接意外断开后，分身里正在运行的任务会被停止。窗口会显示“分身连接已断开”，点「重新连接」可以回到原来的分身，里面的游戏和小助手仍然保留。

## 注意事项

- 分身打开期间，Windows 无法重启或关机，请先注销分身。
- 登录分身时，设置了开机自启的软件也会在分身里再启动一份，可能和主桌面里的同一软件冲突（小助手自己已经处理了这种情况）。不需要的话，可以在任务管理器的「启动应用」里关掉它们的开机自启。
- 部分软件不能在两个桌面同时运行，例如游戏本身、米哈游启动器，以及使用同一个用户配置的浏览器。分身运行游戏时，主桌面不能再打开游戏。
- 第一次登录分身较慢。需要多次运行任务时，可以保持分身开启、只隐藏窗口，省去每次重新登录。

## 常见问题

### 启动或连接时的提示

| 提示 | 处理方法 |
| --- | --- |
| 请先结束主桌面的任务再连接分身 | 主桌面的小助手或命令行正在运行任务、启动游戏，或者在等待执行完成后操作。等它结束或先停止任务 |
| 另一个小助手正在使用桌面分身 | 其他位置安装的小助手，或其他 Windows 账户里的小助手已经开启了分身。一台电脑同时只能有一个分身，先在那边注销 |
| 请以管理员身份运行小助手 | 开启本地子会话需要管理员权限，请以管理员身份重新打开小助手 |
| 会话 N 已占用桌面分身。请先注销该会话后重试 | 上次的分身没有正常注销（例如小助手被强制结束）。打开任务管理器的「用户」页，找到和你同名、进程较少的那一项，右键选择「注销」后重试 |
| 请用当前桌面的登录账户启动小助手 | 小助手是用其他账户启动的（例如“以其他用户身份运行”）。请用当前登录 Windows 的账户启动 |
| 分身与主桌面的登录账户不同 | 登录分身时用了其他账户，请使用当前账户登录 |
| 分身连接失败（RDP 加一串数字） | 远程桌面连接被拒绝或中断，数字是 Windows 给出的错误码，反馈时请一并附上。常见原因有密码不正确、系统组件被精简、第三方安全软件拦截、打过多用户远程桌面补丁。先重启小助手再试，仍然失败就重启电脑后再试 |
| 连接分身超时 | 90 秒内没有完成登录。第一次登录较慢，可以再试一次；如果弹出了输入密码的窗口，看看它是不是被其他窗口挡住了 |
| 等待分身中的小助手启动超时 | 点「打开小助手」再试一次 |
| 会话身份已变化，请在 Windows 中检查分身 | 分身已在别处被注销或替换（例如在任务管理器中注销）。关闭分身窗口后重新启动 |
| 等待分身注销超时 | Windows 没能在 20 秒内注销分身。再点一次「注销分身」，或者在任务管理器的「用户」页注销 |

### 运行任务时的提示

| 提示 | 处理方法 |
| --- | --- |
| 桌面分身需要直接启动本地游戏 | 在「设置 → 程序 → 游戏路径」展开「游戏启动方式」，选择“直接启动” |
| 请先在设置中填写本地游戏路径 | 在「设置 → 程序 → 游戏路径」中选择 `StarRail.exe` |
| 请先关闭其他桌面会话中的游戏 | 主桌面里的游戏还开着，关掉后再在分身里运行任务 |
| 请先关闭桌面分身再安装更新 | 注销分身后再安装更新 |

### 每次连接都要输入密码

这是 Windows 的安全策略：用 PIN 或 Windows Hello 登录 Windows 时，只有第一次连接分身可以用 PIN 验证，之后都要输入账户密码；组策略「允许分配默认凭据」被禁用时也会每次询问。需要多次运行任务时，可以保持分身开启、只隐藏窗口。

### 输入密码后提示不正确

- 使用 Microsoft 账户时，在「设置 → 账户 → 登录选项」中关闭“仅允许使用 Windows Hello 登录 Microsoft 帐户”一项（具体名称以系统为准），重启电脑后再试。
- 在网页上改过 Microsoft 账户密码后，本机可能还没同步新密码。可以在命令提示符中运行 `runas /u:MicrosoftAccount\你的账户邮箱 cmd`，按提示输入新密码同步一次。
- 仍然不行的话，可以改用本地账户登录 Windows。

### 不想用了怎么办

点「注销分身」即可，分身里的一切都会关闭，主桌面的小助手自动恢复。开启过的本地子会话是 Windows 的一项系统设置，会继续保留，不影响平时使用。
