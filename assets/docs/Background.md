# 后台运行

想在小助手运行任务时继续使用电脑，可以从下面三种方式中选择：

| 方式 | 适用 | 对你的键鼠 | 配置难度 |
|------|------|-----------|---------|
| Windows 后台模式（推荐） | Windows 本地游戏 | 点击时短暂借用鼠标，完成后归还 | 设置里切换即可 |
| 云·星穹铁道 | 云游戏 | 不占用 | 设置里开启 |
| 远程本地多用户桌面（进阶） | Windows 本地游戏 | 不占用当前桌面 | 需要修改系统组件 |

## Windows 后台模式（推荐）

游戏窗口留在其他窗口后面，小助手通过窗口消息操作游戏，任务运行时你可以继续使用电脑。默认仍为前台模式，需要手动开启。

### 开启方式

在 `设置 → 杂项 → 本地操作模式` 中选择“后台”，阅读并确认弹出的说明后，下次启动任务时生效。自动对话需要关闭后重新开启才会应用。

也可以直接修改配置文件：

```yaml
local_control_mode: background
background_mouse_protection: false
```

云游戏使用自己的输入方式，不受此设置影响。

### 使用前提

- 游戏窗口可以留在其他窗口之后，但**不能最小化**：最小化的窗口无法截图，也不会处理输入。
- 运行期间需要**保持系统解锁**：锁屏或 UAC 等安全桌面显示时无法读写光标，后台操作会停止并说明原因。
- 游戏使用管理员权限运行时，小助手也需要相应权限（正常启动的小助手会自动申请）。
- 后台模式强制使用窗口截图；窗口截图失败时停止识别，不回退到可能包含其他应用的桌面截图。

### 对鼠标和键盘的影响

- **点击和拖动**会短暂借用真实光标，完成后归还到原位置。如果期间你仍在移动鼠标，归还时会带上这段移动，光标回到你原来的区域继续移动，不会留在点击处；手写板、触屏、远程桌面等绝对定位设备已把光标放回你手边时，不再移动光标。
- 操作前会**等待鼠标空闲**：按下前遇到干扰时最多重试三次，之后显示“等待鼠标空闲，任务将自动继续”并等待，任务会自动继续，也可以正常暂停或停止。光标在 3 像素以内的轻微抖动不算干扰。
- **按键**不会抢占前台窗口和键盘焦点，但游戏只在“激活”状态下接受按键，每次后台按键都会让游戏短暂认为自己处于激活状态。在大世界视角下，游戏会在这段时间把光标锁定在窗口中央，按键结束后解除并归还光标。
- **滚轮**：游戏不在前台时，会显示“滚轮操作需临时切换游戏到前台”横幅，临时把游戏切到前台滚动，完成后恢复此前的窗口和光标。期间如果你主动切换窗口，本轮剩余滚动停止，脚本保留你的窗口选择，不会再把焦点拉回旧窗口。游戏已在前台时直接滚动。
- **鼠标保护**（可选）：展开“本地操作模式”，可以开启“重试失败时短暂锁定鼠标”（默认关闭）。它只在反复冲突时临时屏蔽物理鼠标，保留键盘及暂停、停止热键；每次最多两秒，动作结束、暂停、停止或异常时立即释放。受保护的长按、拖动超过两秒时会释放按住状态，由任务重新确认界面。
- 不带坐标的普通攻击会识别大世界视角的光标锁定，直接在当前点按下、释放，不复用上一张界面的点击位置。
- 自动对话在图形界面中运行：鼠标正被使用或窗口暂时不可用时只短暂等待，交给下一轮检测，不会让界面卡住。

### 窗口状态变化

- **切换窗口**：把游戏切到前台或切到其他窗口都是正常操作，不会报错结束任务。若恰好处于输入过程中，会先释放本次按键、鼠标及临时保护，再交给任务重新识别游戏画面；已经发出的按键、文本、点击和拖动不会自动重放。
- **最小化或暂时不可见**：不发送任何输入，截图和输入最多等待 60 秒并提示还原游戏窗口；还原后自动继续（等待期间被搁置的那次输入按未完成返回，不会补发），超时则停止任务并写明原因（例如“游戏窗口已最小化（已等待 60 秒）”）。同一段不可用期间只等待一次，暂停期间不计入等待时间。程序不会自动还原或激活游戏窗口。
- **游戏进程退出**：立即报告“游戏进程已退出”，不再等待，也不会提示“请恢复窗口”。在启动游戏阶段与前台模式一样关闭游戏后重启；任务进行中按普通错误结束。
- **找不到游戏窗口但进程仍在**（例如游戏正在启动或重建窗口）：同样等待最多 60 秒，超时按普通错误处理。
- **游戏忙于加载**：鼠标消息在 0.5 秒内未被游戏处理时，释放本次输入并按未完成返回，由任务重新确认界面，不会因此结束任务。
- 输入过程中窗口移动、改变大小或坐标超出游戏画面时，同样释放输入并按未完成返回。

“未完成”只表示本次输入没有完整发出；已经完整发出、只是在收尾等待时遇到切窗或暂停的操作仍按成功返回，避免任务把已经生效的点击或按键再执行一次。

### 暂停与停止

暂停、停止会先释放后端持有的按键和鼠标、结束临时前台操作，再回执状态。暂停恢复后不重放已经中断的长按或拖动，请确认当前界面再继续。图形界面停止任务时先发送停止指令并等待“已释放输入”的回执，再结束进程；未在限时内收到回执时，仍使用原有强制结束方式并记录日志。命令行 `--control <运行编号> stop` 使用同一套指令。

### 已知限制

- 启动器以及独立运行的锄大地、第三方模拟宇宙等程序不会因此获得后台能力，仍需按这些程序的要求在前台运行。
- 你持续使用鼠标时，需要点击的步骤会一直等待鼠标空闲；鼠标保护只拦截物理鼠标，不能保证在你持续操作时完成点击。
- 文本输入会在同一激活会话中重新点击最近定位的输入框，再发送字符；不支持输入法候选，也不支持在任意编辑器中追加输入。
- 货币战争的奖励球使用短段扫动，每段结束释放鼠标；某一步未完成时保留当前阶段，下一轮重新检查，不直接进入购买或出战。
- 遇到识别或操作异常时，可以先切回前台模式确认问题是否与后台模式有关，再附上日志反馈。

## 云·星穹铁道

开启 `云·星穹铁道` 后，清体力、每日实训、货币战争、差分宇宙等任务不再要求固定窗口，支持后台运行，也可以开启无窗口模式；锄大地和模拟宇宙仍需要保持前台全屏。

云游戏不依赖本机游戏窗口，也可以在 macOS、Linux、[Docker](/assets/docs/Docker.md) 和 [Termux 安卓](/assets/docs/Termux.md) 上运行，开启方式见 [使用教程](/assets/docs/Tutorial.md)。

## 远程本地多用户桌面（进阶）

> 在同一台电脑上（不需要第二台电脑）通过本机远程桌面再登录一个 Windows 用户会话，让游戏和小助手在那个会话里以前台模式运行，完全不占用你当前桌面的键鼠。需要给系统打补丁以允许多用户同时登录，配置较复杂，系统更新后补丁也可能失效。一般情况下建议优先使用 Windows 后台模式。

 * 模拟器运行拥有卡顿，性能消耗大等诸多缺点，在电脑上直接运行的性能消耗要小于模拟器
 * 我们推荐使用 Windows 自带的远程桌面服务
 * Windows 开启远程桌面多用户教程：
   * [详细教程 by_Rin](https://www.bilibili.com/read/cv24286313/)（⭐推荐⭐）
   * [RDPWrap 方法](https://blog.sena.moe/win10-multiple-RDP/)
   * [修改文件方法](https://www.wyr.me/post/701)
 * [详细教程 by_Rin](https://www.bilibili.com/read/cv24286313/) 中所有相关文件：[下载链接](https://github.com/CHNZYX/asu_version_latest/releases/download/RDP/LocalRemoteDesktop1.191_by_lin.zip)
   * 备用链接
     * [百度网盘](https://pan.baidu.com/s/13aoll4n1gmKlPT9WwNYeEw?pwd=jbha) 提取码：jbha
     * [GitHub镜像](https://github.kotori.top/https://github.com/CHNZYX/asu_version_latest/releases/download/RDP/LocalRemoteDesktop1.191_by_lin.zip)

小助手在远程会话里运行时，请保持远程桌面连接，不要断开会话。默认情况下，远程桌面窗口最小化后远程会话会停止绘制画面，可能导致截图失败；需要最小化时，可在你当前用户的注册表 `HKEY_CURRENT_USER\Software\Microsoft\Terminal Server Client` 下新建 DWORD 值 `RemoteDesktop_SuppressWhenMinimized`，数据设为 `2`，然后重新打开远程桌面连接。

### 对于 Windows 11 用户

在 [详细教程 by_Rin](https://www.bilibili.com/read/cv24286313/) 中提到的 `SuperRDP` 软件可能已无法使用，建议改用 [TermsrvPatcher](https://github.com/fabianosrc/TermsrvPatcher)。如果你在国内使用，可以通过备用链接下载：[蓝奏云](https://wwsj.lanzout.com/i4V8u2np8dna)。

**注意：** 此方法仅实现了[详细教程 by_Rin](https://www.bilibili.com/read/cv24286313/)中`4. 多用户同时登陆补丁`的功能，其余步骤请继续按照原教程进行。

**使用方法：**

1. 使用 `git clone` 克隆仓库，或直接下载压缩包。
2. 下载完成后，解压压缩包，找到 `TermsrvPatcher.ps1` 文件，右键点击选择“运行”，脚本将自动完成所有操作。

此外，如果你希望手动修改文件，可以参考博客文章：[修改文件方法](https://www.wyr.me/post/701)。不过需要注意的是，该博客中的部分操作在 Windows 11 上可能不适用，具体如下：

- **在 Windows 11 中需搜索的字符串（正则）：**
   `39 81 3C 06 00 00 0F (?:[0-9A-F]{2} ){4}00`（实际操作中，仅需搜索`39 81 3C 06 00 00 0F`即可，剩下的两个16进制数符合正则表达式再进行修改）
- **替换为的字符串：**
   `8B 81 38 06 00 00 39 81 3C 06 00 00 75`
