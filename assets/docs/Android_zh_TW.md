三月七小助手安卓版直接安裝在手機上。開始任務後，遊戲會在一塊**看不見的後臺虛擬屏**裡執行，小助手替你完成日常、每日實訓和清體力，這期間手機可以照常聊天、刷影片。

整個過程只有三步：**安裝 App → 按引導授權（只需一次）→ 選任務點開始**。第一次設定大約需要 5～10 分鐘，之後每次點一下「開始」就行。

> 安卓版還在完善中，執行時可能遇到問題，我們會通過後續更新逐步改善。遇到問題歡迎在「日誌」頁匯出日誌，到 [GitHub Issues](https://github.com/moesnow/March7thAssistant/issues) 反饋。

## 能做什麼

- **日常**（推薦）：一次做完歷戰餘響 → 清體力 → 領取獎勵 → 每日實訓。某一步沒完成，後面的照常繼續。
- **每日實訓**：補做還沒完成的實訓任務，領取活躍度和禮盒。
- **清體力**：把開拓力用在你選的副本上，可以搭配體力計劃、後備開拓力、燃料和支援角色。

「領取獎勵」包括委託、郵件、支援、每日實訓、無名勳禮和簡訊，可以在設定裡逐項開關。

兌換碼、貨幣戰爭、差分宇宙、鋤大地、逐光撿金等其他任務，以及定時自動執行、推送到 QQ / 微信等功能，目前只有[電腦版](/assets/docs/Tutorial.md)支援。安卓版每次需要你手動點「開始」。

## 使用前準備

先對照下面幾條，都滿足再往下看：

- **Android 10 或更高版本**，64 位的手機或平板（近幾年的手機基本都是 64 位）。系統版本可以在「設定 → 關於手機」裡檢視。
  - 華為「純血鴻蒙」（HarmonyOS NEXT）不能安裝安卓應用，暫時無法使用。
- **已安裝國服《崩壞：星穹鐵道》官服**，並且手動開啟過一次：登入好賬號、下載完資源，能進到遊戲裡操作角色。B 服（用 B 站賬號登入的版本）和國際服暫不支援。
- **能用 Shizuku 或 Root 授權**（二選一）。小助手要藉助它們才能在後臺啟動遊戲、替你點按：
  - **Android 11 及以上**：用 Shizuku 的「無線除錯」啟動，**全程只用手機**，需要連著 Wi‑Fi。
  - **Android 10**：系統沒有無線除錯，啟動 Shizuku 時要用資料線連一次電腦，而且**每次重啟手機後都要重新連電腦啟動**。
  - 已經 Root 的手機（Magisk、KernelSU 等）可以直接用 Root，不需要 Shizuku。
- 留出約 **150 MB** 儲存空間安裝小助手。

> **Shizuku 是什麼？** 一個免費開源的工具，藉助安卓系統自帶的除錯功能，讓普通應用獲得比平時更高的許可權，**不需要 Root，也不會修改系統**。小助手內建了 Shizuku 官方安裝包，按引導點幾下就能裝好。

## 第一步：下載並安裝

1. 用手機瀏覽器開啟[官網下載頁](https://m7a.top/#download)，選「安卓手機」，任選一個渠道下載安裝包（APK，約 150 MB）：
   - **Mirror醬**：國內高速下載，需要購買 CDK，收入與開發者分成。
   - **GitHub**：免費，檔名是 `March7thAssistant_full_android.apk`。中國大陸訪問可能很慢，甚至無法連線。
2. 下載完成後點開安裝包。如果系統提示“禁止安裝未知應用”，按提示允許瀏覽器（或檔案管理）安裝應用，返回後再點一次安裝。
3. 部分手機會提示“風險應用”“未經檢測”，或者被“純淨模式”攔截，這是因為小助手不是從應用商店下載的。確認安裝包來自官網或 GitHub 後，按系統提示允許安裝即可。

> 三月七小助手完全免費，如果你是付費買到的，請立即退款並舉報商家。

## 第二步：完成授權

第一次開啟小助手，首頁會提示「先完成授權」。點下方的「去完成授權」進入「許可權引導」，在頂部選擇授權方式：**沒有 Root 就選 Shizuku**，已經 Root 的可以選 Root。

### 方式一：Shizuku（不需要 Root，推薦）

引導頁會帶你依次完成三件事，做完一步會自動進入下一步。

#### 1. 安裝 Shizuku

點「離線安裝」，使用小助手內建的 Shizuku 官方安裝包。如果系統要求授權，允許小助手“安裝未知應用”，返回後再點一次「離線安裝」。也可以點「官方釋出頁」自己下載安裝。

#### 2. 啟動 Shizuku 服務

引導頁會按你手機的系統版本（「本機是 Android ××，按下面的方式啟動」）顯示對應的方法。

**Android 11 及以上（只用手機）：**

1. **開啟開發者選項。** 進入「設定 → 關於手機」，連續點「版本號」7 次，直到提示已進入開發者模式。不同品牌的位置略有不同：小米 / Redmi 在「設定 → 我的裝置 → 全部引數與資訊」裡點「OS 版本」（舊系統是「MIUI 版本」）。找不到時，可以在設定頂部的搜尋框裡搜“版本號”。
2. **開啟無線除錯。** 連上 Wi‑Fi，進入「開發者選項」（常見位置是「設定 → 系統 → 開發者選項」，小米在「設定 → 更多設定 → 開發者選項」），開啟「無線除錯」。
3. **在 Shizuku 裡開始配對。** 點引導頁上的「開啟 Shizuku」，在「通過無線除錯啟動」裡點「配對」。Shizuku 要求通知許可權時請允許，配對碼要在它的通知裡輸入。
4. **獲取配對碼。** 回到「開發者選項 → 無線除錯」，點「使用配對碼配對裝置」，螢幕上會出現一串 6 位數字的配對碼。
5. **輸入配對碼。** 從螢幕頂部下拉通知欄，在 Shizuku 的通知裡輸入這 6 位數字。提示配對成功就可以了。
6. **啟動服務。** 回到 Shizuku 點「啟動」，看到「正在執行」就成功了。

配對只需要做一次。**重啟手機後 Shizuku 會停止**，到時開啟 Shizuku 再點一次「啟動」即可；如果提示無線除錯沒有開啟，先連上 Wi‑Fi，到開發者選項裡開啟「無線除錯」再啟動。

**Android 10（需要電腦）：**

1. 開啟開發者選項（方法同上），在「開發者選項」裡開啟「USB 除錯」。
2. 用資料線把手機連到電腦，手機上彈出“允許 USB 除錯嗎？”時，勾選“一律允許”後點“確定”。
3. 電腦上需要有 adb：沒有的話從 [Android 官網](https://developer.android.google.cn/tools/releases/platform-tools?hl=zh-cn) 下載 SDK Platform-Tools 並解壓（Windows 電腦選適用於 Windows 的版本）。
4. 開啟 Shizuku，在「通過連線電腦啟動」裡點「檢視指令」，在電腦上 Platform-Tools 所在的資料夾裡開啟命令列，執行顯示的那條命令。
5. Shizuku 顯示「正在執行」後就可以拔掉資料線。

Android 10 沒有無線除錯，**每次重啟手機後都要連電腦重新執行一次**。

#### 3. 允許小助手使用 Shizuku

回到小助手，點「授權」，在彈出的窗口裡選「始終允許」。沒有彈窗的話，開啟 Shizuku 的「已授權應用」，手動開啟三月七小助手的開關。

看到「許可權已就緒」就完成了，點「回到首頁」。

### 方式二：Root

點「檢查 Root」，在 Root 管理應用（如 Magisk、KernelSU）彈出的窗口裡允許三月七小助手使用超級使用者許可權，提示「已獲得 Root 許可權」即可。沒有反應時，到 Root 管理應用裡手動允許，再點一次「檢查 Root」。遇到問題請改用 Shizuku。

## 第三步：選任務，開始執行

1. 點底部的「任務」，選一個要執行的任務。第一次用推薦選「日常」。
2. 在下方的「設定」裡調整要做的事，比如清體力刷什麼副本（「副本型別」和「副本名稱」）、要不要使用後備開拓力。這些設定三個任務共用，改一次就行。
3. 回到「首頁」點「開始日常」（按鈕文字隨所選任務變化）。Android 13 及以上第一次開始時會詢問是否允許通知，建議允許，這樣可以在通知欄看到進度並隨時停止。
4. 接下來交給三月七：
   - 先準備執行環境，通常只要幾秒。
   - 然後啟動遊戲，大約需要一到兩分鐘。期間**遊戲畫面會在手機螢幕上閃現幾秒**，這是登入介面造成的正常現象，先別碰螢幕，它會自動回到後臺。
   - 遊戲回到後臺虛擬屏後開始執行任務，這時手機可以照常使用。想看看遊戲裡在做什麼，可以展開首頁的「遊戲畫面」。
5. 完成後首頁顯示「日常已完成」，每一步的結果在「本輪結果」裡，活躍度和獎勵明細在「日誌」頁。

想中途停止，點首頁的「停止」或通知欄裡的「停止」。小助手會做完手頭這一步再停下，然後釋放虛擬屏。

> 如果遊戲停在登入介面等你輸入賬號，首頁會提示「遊戲正在等待登入」。在手機螢幕上完成登入即可；登入不了就先點「停止」，手動開啟遊戲登入好再重新開始。

## 執行期間的注意事項

- **保持解鎖，不要按電源鍵。** 鎖屏或息屏後點按到不了遊戲，任務會卡住。想省電的話，在「設定」裡開啟「遊戲就緒後關閉螢幕」：只關閉螢幕顯示，任務照常執行，結束後自動點亮。
- **不要在最近任務裡「一鍵清理」**，它會把後臺的遊戲一起結束。
- **把小助手和遊戲的省電策略設為「無限制」並允許自啟動**，避免被系統中途結束。在小助手的「設定 → 後臺執行與省電」可以直接開啟小助手的系統設定頁。
- **小米、Redmi 手機（MIUI / HyperOS）**：在「開發者選項」裡開啟「USB 除錯（安全設定）」，否則系統會攔截小助手的模擬點按。開啟時系統會要求登入小米賬號並插入 SIM 卡。
- **執行期間不要在別的裝置登入同一個賬號**，否則會被擠下線。
- 不想聽到遊戲聲音，可以在「設定」裡開啟「執行時靜音遊戲」，只靜音遊戲，不影響其他應用。
- 執行時比較耗電，手機也會發熱，建議邊充電邊執行。

## 遇到問題怎麼辦

任務沒完成時，首頁會顯示原因和處理辦法，照著做完再重新開始；「日誌」頁的「常見問題」裡也列出了各種錯誤的處理步驟。最常見的幾種：

- **裝置端服務沒有啟動成功**：開啟 Shizuku，確認它顯示「正在執行」（手機重啟過就要重新啟動），再回到許可權引導確認狀態是「已就緒」。
- **系統攔截了模擬點按**：小米、Redmi 手機在開發者選項裡開啟「USB 除錯（安全設定）」，重新啟動 Shizuku 服務後再開始。
- **手機處於鎖屏狀態 / 手機已經息屏**：解鎖後重新開始，執行期間不要鎖屏；想關屏省電，用「遊戲就緒後關閉螢幕」。
- **需要你先登入遊戲**：在手機上開啟遊戲完成登入，進到能操作角色的介面，再回到小助手重新開始。
- **沒有找到遊戲**：先安裝國服《崩壞：星穹鐵道》官服，手動開啟一次，完成登入和資源下載。
- **等待遊戲就緒超時**：開啟遊戲看看是否需要登入或更新。榮耀手機如果一直卡在啟動介面，在系統設定裡搜尋並關閉「智慧解析度」。
- **上次執行意外中止**：小助手被系統結束了。把小助手和遊戲的省電策略設為「無限制」並允許自啟動，不要在最近任務裡一鍵清理。
- **上一輪還沒有完全退出**：等十幾秒再開始；還不行就在 Shizuku 裡停止服務後重新啟動，或者重啟手機。

還是解決不了的話，在「日誌」頁點「匯出」儲存日誌檔案，連同截圖一起發到 [GitHub Issues](https://github.com/moesnow/March7thAssistant/issues) 反饋。

## 更新

有新版本時，首頁頂部會出現「有新版本」，點它就能進入更新頁。也可以在「設定」最下方的「關於」裡點「應用更新」，再點「檢查更新」：

- 下載來源可以選 **GitHub**（免費）或 **Mirror醬**（國內高速，需要填寫 CDK），兩個渠道是同一份安裝包。
- 下載完成後點「安裝更新」，在系統安裝器裡確認即可，原來的設定會保留。任務執行期間不能安裝，等任務結束再裝。
- 「版本渠道」預設是「正式版」，一般不用改。

## 常見問題

### Q：安卓版和電腦版有什麼區別？

安卓版目前支援日常、每日實訓和清體力，每次需要手動點開始。電腦版功能更全：貨幣戰爭、差分宇宙、鋤大地、逐光撿金、兌換碼等都能做，還支援定時自動執行和訊息推送。兩邊可以搭配使用，電腦版下載見[官網](https://m7a.top/#download)。

### Q：一定要用電腦嗎？

Android 11 及以上不需要，用 Shizuku 的無線除錯在手機上就能完成授權。Android 10 啟動 Shizuku 時需要連一次電腦，之後每次重啟手機都要再連一次。

### Q：執行的時候手機能幹別的嗎？

可以。遊戲在後臺虛擬屏裡執行，手機螢幕照常使用，刷影片、聊天都沒問題。只是不要鎖屏、不要按電源鍵，也不要在最近任務裡一鍵清理。手機效能有限，同時玩別的大型遊戲可能會卡。

### Q：使用小助手有風險嗎？

有。《崩壞：星穹鐵道》的公平遊戲宣言禁止使用指令碼等第三方工具，違規可能導致扣除收益乃至封禁賬號。安卓版同樣是通過識別遊戲畫面、模擬點按來完成任務，請了解風險後自行決定是否使用。

### Q：B 服、國際服或者電腦上的模擬器能用嗎？

安卓版目前只支援國服官服，B 服和國際服暫不支援。電腦上的模擬器可以用電腦版的「安卓裝置（ADB）」模式連線，見下一節。

### Q：會收集我的資料嗎？

安卓版預設開啟「匿名使用資料收集」，用隨機生成的安裝標識統計活躍度。上報的內容是 App 版本、系統版本、廠商機型和 CPU 架構，以及任務型別、許可權方式、結果、耗時和出錯的步驟等統計，不包含遊戲賬號；日誌和截圖只有你主動反饋時才會傳送。不想參與的話，可以在「設定 → 關於」裡關閉，關閉後會清除還沒傳送的資料。

## 另一種方式：用電腦控制手機或模擬器

如果你有 Windows 電腦，也可以讓[電腦版](/assets/docs/Tutorial.md)小助手通過 ADB 連線手機或模擬器（如 MuMu）來執行日常、每日實訓和清體力，手機上不需要安裝 Shizuku，還可以配合電腦版的定時任務使用。

1. **準備裝置。**
   - 手機：在開發者選項裡開啟「USB 除錯」，用資料線連線電腦，手機上彈出“允許 USB 除錯嗎？”時勾選“一律允許”後點“確定”。小米、Redmi 還要開啟「USB 除錯（安全設定）」。
   - 模擬器：建議在模擬器設定裡把解析度設為 1280×720（橫屏、240 DPI），重啟模擬器。
2. 開啟電腦版小助手，進入「設定 → 執行方式」，選擇「安卓裝置」。
3. 在「Android 裝置」裡點「重新整理」找到裝置；電腦上沒有 adb 時點「下載 adb」。模擬器點「手動連線」輸入地址，MuMu 預設是 `127.0.0.1:16384`。
4. 在「環境檢查」裡點「開始檢查」，按提示處理沒通過的檢查項。全部通過後，就可以在首頁執行任務了。

喜歡折騰的話，還可以在 Termux 裡用雲遊戲模式執行小助手，見 [Termux 安卓部署](/assets/docs/Termux.md)。這種方式需要一定的 Linux 基礎，不推薦新手使用。
