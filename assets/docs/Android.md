三月七小助手安卓版直接安装在手机上。开始任务后，游戏会在一块**看不见的后台虚拟屏**里运行，小助手替你完成日常、每日实训和清体力，这期间手机可以照常聊天、刷视频。

整个过程只有三步：**安装 App → 按引导授权（只需一次）→ 选任务点开始**。第一次设置大约需要 5～10 分钟，之后每次点一下「开始」就行。

> 安卓版还在完善中，运行时可能遇到问题，我们会通过后续更新逐步改善。遇到问题欢迎在「日志」页导出日志，到 [GitHub Issues](https://github.com/moesnow/March7thAssistant/issues) 反馈。

## 能做什么

- **日常**（推荐）：一次做完历战余响 → 清体力 → 领取奖励 → 每日实训。某一步没完成，后面的照常继续。
- **每日实训**：补做还没完成的实训任务，领取活跃度和礼盒。
- **清体力**：把开拓力用在你选的副本上，可以搭配体力计划、后备开拓力、燃料和支援角色。

「领取奖励」包括委托、邮件、支援、每日实训、无名勋礼和短信，可以在设置里逐项开关。

兑换码、货币战争、差分宇宙、锄大地、逐光捡金等其他任务，以及定时自动运行、推送到 QQ / 微信等功能，目前只有[电脑版](/assets/docs/Tutorial.md)支持。安卓版每次需要你手动点「开始」。

## 使用前准备

先对照下面几条，都满足再往下看：

- **Android 10 或更高版本**，64 位的手机或平板（近几年的手机基本都是 64 位）。系统版本可以在「设置 → 关于手机」里查看。
  - 华为「纯血鸿蒙」（HarmonyOS NEXT）不能安装安卓应用，暂时无法使用。
- **已安装国服《崩坏：星穹铁道》官服**，并且手动打开过一次：登录好账号、下载完资源，能进到游戏里操作角色。B 服（用 B 站账号登录的版本）和国际服暂不支持。
- **能用 Shizuku 或 Root 授权**（二选一）。小助手要借助它们才能在后台启动游戏、替你点按：
  - **Android 11 及以上**：用 Shizuku 的「无线调试」启动，**全程只用手机**，需要连着 Wi‑Fi。
  - **Android 10**：系统没有无线调试，启动 Shizuku 时要用数据线连一次电脑，而且**每次重启手机后都要重新连电脑启动**。
  - 已经 Root 的手机（Magisk、KernelSU 等）可以直接用 Root，不需要 Shizuku。
- 留出约 **150 MB** 存储空间安装小助手。

> **Shizuku 是什么？** 一个免费开源的工具，借助安卓系统自带的调试功能，让普通应用获得比平时更高的权限，**不需要 Root，也不会修改系统**。小助手内置了 Shizuku 官方安装包，按引导点几下就能装好。

## 第一步：下载并安装

1. 用手机浏览器打开[官网下载页](https://m7a.top/#download)，选「安卓手机」，任选一个渠道下载安装包（APK，约 150 MB）：
   - **Mirror酱**：国内高速下载，需要购买 CDK，收入与开发者分成。
   - **GitHub**：免费，文件名是 `March7thAssistant_full_android.apk`。中国大陆访问可能很慢，甚至无法连接。
2. 下载完成后点开安装包。如果系统提示“禁止安装未知应用”，按提示允许浏览器（或文件管理）安装应用，返回后再点一次安装。
3. 部分手机会提示“风险应用”“未经检测”，或者被“纯净模式”拦截，这是因为小助手不是从应用商店下载的。确认安装包来自官网或 GitHub 后，按系统提示允许安装即可。

> 三月七小助手完全免费，如果你是付费买到的，请立即退款并举报商家。

## 第二步：完成授权

第一次打开小助手，首页会提示「先完成授权」。点下方的「去完成授权」进入「权限引导」，在顶部选择授权方式：**没有 Root 就选 Shizuku**，已经 Root 的可以选 Root。

### 方式一：Shizuku（不需要 Root，推荐）

引导页会带你依次完成三件事，做完一步会自动进入下一步。

#### 1. 安装 Shizuku

点「离线安装」，使用小助手内置的 Shizuku 官方安装包。如果系统要求授权，允许小助手“安装未知应用”，返回后再点一次「离线安装」。也可以点「官方发布页」自己下载安装。

#### 2. 启动 Shizuku 服务

引导页会按你手机的系统版本（「本机是 Android ××，按下面的方式启动」）显示对应的方法。

**Android 11 及以上（只用手机）：**

1. **打开开发者选项。** 进入「设置 → 关于手机」，连续点「版本号」7 次，直到提示已进入开发者模式。不同品牌的位置略有不同：小米 / Redmi 在「设置 → 我的设备 → 全部参数与信息」里点「OS 版本」（旧系统是「MIUI 版本」）。找不到时，可以在设置顶部的搜索框里搜“版本号”。
2. **打开无线调试。** 连上 Wi‑Fi，进入「开发者选项」（常见位置是「设置 → 系统 → 开发者选项」，小米在「设置 → 更多设置 → 开发者选项」），打开「无线调试」。
3. **在 Shizuku 里开始配对。** 点引导页上的「打开 Shizuku」，在「通过无线调试启动」里点「配对」。Shizuku 要求通知权限时请允许，配对码要在它的通知里输入。
4. **获取配对码。** 回到「开发者选项 → 无线调试」，点「使用配对码配对设备」，屏幕上会出现一串 6 位数字的配对码。
5. **输入配对码。** 从屏幕顶部下拉通知栏，在 Shizuku 的通知里输入这 6 位数字。提示配对成功就可以了。
6. **启动服务。** 回到 Shizuku 点「启动」，看到「正在运行」就成功了。

配对只需要做一次。**重启手机后 Shizuku 会停止**，到时打开 Shizuku 再点一次「启动」即可；如果提示无线调试没有打开，先连上 Wi‑Fi，到开发者选项里打开「无线调试」再启动。

**Android 10（需要电脑）：**

1. 打开开发者选项（方法同上），在「开发者选项」里打开「USB 调试」。
2. 用数据线把手机连到电脑，手机上弹出“允许 USB 调试吗？”时，勾选“一律允许”后点“确定”。
3. 电脑上需要有 adb：没有的话从 [Android 官网](https://developer.android.google.cn/tools/releases/platform-tools?hl=zh-cn) 下载 SDK Platform-Tools 并解压（Windows 电脑选适用于 Windows 的版本）。
4. 打开 Shizuku，在「通过连接电脑启动」里点「查看指令」，在电脑上 Platform-Tools 所在的文件夹里打开命令行，执行显示的那条命令。
5. Shizuku 显示「正在运行」后就可以拔掉数据线。

Android 10 没有无线调试，**每次重启手机后都要连电脑重新执行一次**。

#### 3. 允许小助手使用 Shizuku

回到小助手，点「授权」，在弹出的窗口里选「始终允许」。没有弹窗的话，打开 Shizuku 的「已授权应用」，手动打开三月七小助手的开关。

看到「权限已就绪」就完成了，点「回到首页」。

### 方式二：Root

点「检查 Root」，在 Root 管理应用（如 Magisk、KernelSU）弹出的窗口里允许三月七小助手使用超级用户权限，提示「已获得 Root 权限」即可。没有反应时，到 Root 管理应用里手动允许，再点一次「检查 Root」。遇到问题请改用 Shizuku。

## 第三步：选任务，开始运行

1. 点底部的「任务」，选一个要执行的任务。第一次用推荐选「日常」。
2. 在下方的「设置」里调整要做的事，比如清体力刷什么副本（「副本类型」和「副本名称」）、要不要使用后备开拓力。这些设置三个任务共用，改一次就行。
3. 回到「首页」点「开始日常」（按钮文字随所选任务变化）。Android 13 及以上第一次开始时会询问是否允许通知，建议允许，这样可以在通知栏看到进度并随时停止。
4. 接下来交给三月七：
   - 先准备运行环境，通常只要几秒。
   - 然后启动游戏，大约需要一到两分钟。期间**游戏画面会在手机屏幕上闪现几秒**，这是登录界面造成的正常现象，先别碰屏幕，它会自动回到后台。
   - 游戏回到后台虚拟屏后开始执行任务，这时手机可以照常使用。想看看游戏里在做什么，可以展开首页的「游戏画面」。
5. 完成后首页显示「日常已完成」，每一步的结果在「本轮结果」里，活跃度和奖励明细在「日志」页。

想中途停止，点首页的「停止」或通知栏里的「停止」。小助手会做完手头这一步再停下，然后释放虚拟屏。

> 如果游戏停在登录界面等你输入账号，首页会提示「游戏正在等待登录」。在手机屏幕上完成登录即可；登录不了就先点「停止」，手动打开游戏登录好再重新开始。

## 运行期间的注意事项

- **保持解锁，不要按电源键。** 锁屏或息屏后点按到不了游戏，任务会卡住。想省电的话，在「设置」里打开「游戏就绪后关闭屏幕」：只关闭屏幕显示，任务照常运行，结束后自动点亮。
- **不要在最近任务里「一键清理」**，它会把后台的游戏一起结束。
- **把小助手和游戏的省电策略设为「无限制」并允许自启动**，避免被系统中途结束。在小助手的「设置 → 后台运行与省电」可以直接打开小助手的系统设置页。
- **小米、Redmi 手机（MIUI / HyperOS）**：在「开发者选项」里打开「USB 调试（安全设置）」，否则系统会拦截小助手的模拟点按。打开时系统会要求登录小米账号并插入 SIM 卡。
- **运行期间不要在别的设备登录同一个账号**，否则会被挤下线。
- 不想听到游戏声音，可以在「设置」里打开「运行时静音游戏」，只静音游戏，不影响其他应用。
- 运行时比较耗电，手机也会发热，建议边充电边运行。

## 遇到问题怎么办

任务没完成时，首页会显示原因和处理办法，照着做完再重新开始；「日志」页的「常见问题」里也列出了各种错误的处理步骤。最常见的几种：

- **设备端服务没有启动成功**：打开 Shizuku，确认它显示「正在运行」（手机重启过就要重新启动），再回到权限引导确认状态是「已就绪」。
- **系统拦截了模拟点按**：小米、Redmi 手机在开发者选项里打开「USB 调试（安全设置）」，重新启动 Shizuku 服务后再开始。
- **手机处于锁屏状态 / 手机已经息屏**：解锁后重新开始，运行期间不要锁屏；想关屏省电，用「游戏就绪后关闭屏幕」。
- **需要你先登录游戏**：在手机上打开游戏完成登录，进到能操作角色的界面，再回到小助手重新开始。
- **没有找到游戏**：先安装国服《崩坏：星穹铁道》官服，手动打开一次，完成登录和资源下载。
- **等待游戏就绪超时**：打开游戏看看是否需要登录或更新。荣耀手机如果一直卡在启动界面，在系统设置里搜索并关闭「智能分辨率」。
- **上次运行意外中止**：小助手被系统结束了。把小助手和游戏的省电策略设为「无限制」并允许自启动，不要在最近任务里一键清理。
- **上一轮还没有完全退出**：等十几秒再开始；还不行就在 Shizuku 里停止服务后重新启动，或者重启手机。

还是解决不了的话，在「日志」页点「导出」保存日志文件，连同截图一起发到 [GitHub Issues](https://github.com/moesnow/March7thAssistant/issues) 反馈。

## 更新

有新版本时，首页顶部会出现「有新版本」，点它就能进入更新页。也可以在「设置」最下方的「关于」里点「应用更新」，再点「检查更新」：

- 下载来源可以选 **GitHub**（免费）或 **Mirror酱**（国内高速，需要填写 CDK），两个渠道是同一份安装包。
- 下载完成后点「安装更新」，在系统安装器里确认即可，原来的设置会保留。任务运行期间不能安装，等任务结束再装。
- 「版本渠道」默认是「正式版」，一般不用改。

## 常见问题

### Q：安卓版和电脑版有什么区别？

安卓版目前支持日常、每日实训和清体力，每次需要手动点开始。电脑版功能更全：货币战争、差分宇宙、锄大地、逐光捡金、兑换码等都能做，还支持定时自动运行和消息推送。两边可以搭配使用，电脑版下载见[官网](https://m7a.top/#download)。

### Q：一定要用电脑吗？

Android 11 及以上不需要，用 Shizuku 的无线调试在手机上就能完成授权。Android 10 启动 Shizuku 时需要连一次电脑，之后每次重启手机都要再连一次。

### Q：运行的时候手机能干别的吗？

可以。游戏在后台虚拟屏里运行，手机屏幕照常使用，刷视频、聊天都没问题。只是不要锁屏、不要按电源键，也不要在最近任务里一键清理。手机性能有限，同时玩别的大型游戏可能会卡。

### Q：使用小助手有风险吗？

有。《崩坏：星穹铁道》的公平游戏宣言禁止使用脚本等第三方工具，违规可能导致扣除收益乃至封禁账号。安卓版同样是通过识别游戏画面、模拟点按来完成任务，请了解风险后自行决定是否使用。

### Q：B 服、国际服或者电脑上的模拟器能用吗？

安卓版目前只支持国服官服，B 服和国际服暂不支持。电脑上的模拟器可以用电脑版的「安卓设备（ADB）」模式连接，见下一节。

### Q：会收集我的数据吗？

安卓版默认开启「匿名使用数据收集」，用随机生成的安装标识统计活跃度。上报的内容是 App 版本、系统版本、厂商机型和 CPU 架构，以及任务类型、权限方式、结果、耗时和出错的步骤等统计，不包含游戏账号；日志和截图只有你主动反馈时才会发送。不想参与的话，可以在「设置 → 关于」里关闭，关闭后会清除还没发送的数据。

## 另一种方式：用电脑控制手机或模拟器

如果你有 Windows 电脑，也可以让[电脑版](/assets/docs/Tutorial.md)小助手通过 ADB 连接手机或模拟器（如 MuMu）来运行日常、每日实训和清体力，手机上不需要安装 Shizuku，还可以配合电脑版的定时任务使用。

1. **准备设备。**
   - 手机：在开发者选项里打开「USB 调试」，用数据线连接电脑，手机上弹出“允许 USB 调试吗？”时勾选“一律允许”后点“确定”。小米、Redmi 还要打开「USB 调试（安全设置）」。
   - 模拟器：建议在模拟器设置里把分辨率设为 1280×720（横屏、240 DPI），重启模拟器。
2. 打开电脑版小助手，进入「设置 → 运行方式」，选择「安卓设备」。
3. 在「Android 设备」里点「刷新」找到设备；电脑上没有 adb 时点「下载 adb」。模拟器点「手动连接」输入地址，MuMu 默认是 `127.0.0.1:16384`。
4. 在「环境检查」里点「开始检查」，按提示处理没通过的检查项。全部通过后，就可以在首页运行任务了。

喜欢折腾的话，还可以在 Termux 里用云游戏模式运行小助手，见 [Termux 安卓部署](/assets/docs/Termux.md)。这种方式需要一定的 Linux 基础，不推荐新手使用。
