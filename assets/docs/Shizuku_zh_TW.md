# Shizuku 啟用教程

> 本文件由簡體中文版經 OpenCC 簡繁轉換產生，用語以台灣習慣為準；內容如有差異，請以簡體中文版為準。

這篇教程寫給從沒接觸過開發者選項、USB 除錯和 ADB 的手機使用者：從第一次開啟手機設定開始，一步步啟動 Shizuku，最後讓三月七小助手獲得授權。[安卓版使用教程](/assets/docs/Android.md)裡的「第二步：完成授權」是簡要版，照著做卡住了，再回到這裡按自己的手機品牌和遇到的現象對照。

本教程優先介紹小米 / Redmi 的 HyperOS、vivo / iQOO 的 OriginOS、OPPO / 一加 / 真我的 ColorOS 系，以及榮耀 MagicOS、華為 HarmonyOS / EMUI；後面補充聯想、努比亞 / 紅魔、三星等裝置。

你不需要先學程式設計。先找到自己的手機品牌，只做對應的準備，再跟著一種啟動方法操作即可。

> **最後要看到兩個結果：**
>
> 1. Shizuku 首頁顯示“正在執行”或“Shizuku 正在執行”。
> 2. 三月七小助手的許可權引導顯示“許可權已就緒”。
>
> 只看到“安裝完成”或者“配對成功”，還沒有做完。

## 1. 先判斷自己走哪條路線

先在手機桌面找到齒輪圖示的“設定”，進入“關於手機 / 關於本機 / 我的裝置”。平板可能叫“關於平板”。

**先確認裝置：** 小助手安卓版要求 Android 10 或更新版本、64 位手機或平板。Android 9 或更舊的裝置，即使能執行某些版本的 Shizuku，也不滿足小助手當前的使用要求，詳見安卓版使用教程的[使用前準備](/assets/docs/Android.md#使用前準備)。

這裡可能同時顯示兩個名字：

- **廠商系統名稱**：例如 HyperOS、OriginOS、ColorOS、MagicOS。
- **Android 版本**：例如 Android 12、Android 15、Android 16。

它們是兩回事。不要把“HyperOS 3”理解成“Android 3”。如果首頁沒寫 Android 版本，繼續點“版本資訊”或“全部引數與資訊”。

| 你的實際情況 | 選擇什麼方法 | 要準備什麼 |
| --- | --- | --- |
| Android 11 或更新，並且開發者選項裡有“無線除錯” | **方法 A：只用手機** | 一部手機、一個能連線的 Wi-Fi |
| Android 10 | **方法 B：電腦 USB** | 手機、支援傳輸資料的線、電腦 |
| Android 11 或更新，但系統沒有“無線除錯” | **方法 B：電腦 USB** | 同上 |
| 無線配對一直失敗，已經按排錯步驟檢查過 | **方法 B：電腦 USB** | 同上；不必繼續反覆配對 |
| 華為 HarmonyOS 2～4.3 / 部分 EMUI | **優先按華為專章走電腦 USB** | 這些系統通常沒有標準無線除錯入口 |
| 華為 HarmonyOS NEXT / HarmonyOS 5 及以上原生系統 | [先看華為適用範圍](#_35-華為：先分清-harmonyos-emui-的兩種情況) | 本文沒有可直接套用的原生 Shizuku 啟用流程 |
| 手機已經 Root，且你知道自己使用的 Root 管理器 | 小助手可以直接用 Root 授權；想用 Shizuku 見 [已有 Root 的路線](#_9-已經-root-的手機) | 已有的 Root 許可權 |

**只選一條啟動路線。** 無線方法成功以後，不用再做電腦方法；電腦方法成功以後，也不用再做無線配對。

Android 無線除錯的版本前提見 [Android 官方文件][S2]；華為缺少無線除錯的適用系統範圍見 [華為官方說明][S15]。

## 2. 準備：看懂幾個詞，安裝 Shizuku

### 2.1 這幾個詞到底是什麼意思

| 詞 | 在本教程裡的意思 |
| --- | --- |
| Shizuku | 手機上另裝的一款工具。它啟動後，可以讓你授權的應用使用 Android 除錯許可權 |
| 啟用 / 啟動服務 | 讓 Shizuku 真正開始工作；不是付錢，也不是輸入註冊碼 |
| 開發者選項 | 手機設定裡一組預設隱藏的除錯設定，本教程會教你把它顯示出來 |
| USB 除錯 | 允許經過你確認的除錯連線，是本教程會用到的開關 |
| 無線除錯 | 通過 Wi-Fi 完成除錯連線；普通無線方案需要 Android 11 或以上，並且廠商保留了這個入口 |
| 配對 | 讓手機認出 Shizuku，通常只需首次完成 |
| 配對碼 | 無線除錯臨時生成的一般為 6 位的數字；不是鎖屏密碼，也不是 Wi-Fi 密碼 |
| 授權 | 在 Shizuku 已執行之後，允許“三月七小助手”使用它 |
| ADB / adb | 電腦與 Android 手機通訊的小工具，電腦路線會教你下載和使用 |
| 後臺 | 你切到別的應用時，原來那款應用繼續工作的狀態 |

可以把整個流程記成：**先把工具裝好 → 讓工具開始工作 → 允許小助手使用工具。**

### 2.2 第一次操作前準備好這些

1. 給手機留足電量，操作期間保持解鎖。
2. 記得這部手機的鎖屏密碼。有些系統開啟開發者選項時會驗證它。
3. 無線方案先準備一個 Wi-Fi。家裡的路由器可以，另一部手機開的熱點也可以；**是這部手機去連線另一部手機的熱點**。
4. 電腦方案准備一條能傳輸資料的 USB 線。能充電的線不一定能傳資料。
5. 給自己留幾分鐘，先按順序做完一條路線，不用同時修改其他設定。

無線除錯使用本地網路。下載軟體需要聯網；配對本身不靠購買流量、掃碼付費或遠端客服。用家庭 Wi-Fi 最容易操作。

### 2.3 優先用小助手內建的安裝包

小助手自帶 Shizuku 官方安裝包，不用另外去找：

1. 開啟“三月七小助手”。
2. 在首頁找到“先完成授權”，點選“去完成授權”。
3. 進入“許可權引導”後，選擇 **Shizuku**。
4. 在“安裝 Shizuku”這一步，點選“離線安裝”。
5. 如果系統提示需要授權，進入系統的許可權頁面，只允許**三月七小助手**安裝未知應用，然後返回小助手，再點一次“離線安裝”。
6. 在系統的安裝介面點選“安裝”，等到安裝完成。
7. 開啟 Shizuku。第一次首頁顯示尚未執行是正常的，下一章才開始啟用。

已經裝有官方 Shizuku 的使用者，可以直接開啟它繼續。

### 2.4 也可以從 Shizuku 官方下載

離線安裝失敗，或者想自己下載時，可以點許可權引導裡的“官方釋出頁”，或者用下面的官方入口：

- [Shizuku 官方網站][S5]
- [Shizuku 官方 GitHub 釋出頁][S6]

手機操作方法：

1. 用瀏覽器開啟上面的官方入口。
2. 在下載入口選擇 GitHub；進入釋出頁後找到 **Assets**，點開它。
3. 下載檔名以 **`.apk`** 結尾的 Shizuku 安裝包。
4. 不要選“Source code (zip)”或“Source code (tar.gz)”，那是給開發者看的原始碼。
5. 下載完成後點安裝包。找不到時，開啟瀏覽器的“下載”記錄，或手機“檔案管理 → 下載”。
6. 如果系統提示不允許安裝未知應用，只允許當前用於安裝的瀏覽器或檔案管理器，然後返回繼續。
7. 完成後開啟 Shizuku。

**版本選擇：** 使用三月七內建包，或 Shizuku 官方釋出頁提供的版本。已有能正常工作的版本，可以先按本文完成設定；不要因為別人的舊教程寫了某個版本，就先解除安裝重灌。電腦啟動指令必須以**你當前安裝的 Shizuku**顯示的為準，詳見 [5.6 節](#_56-在自己手機裡取得這臺手機專用的啟動指令)。

## 3. 按品牌開啟開發者選項

**這一章只讀自己的品牌。** 做完後，按提示跳到方法 A 或方法 B。

下面的“連點 7 次”是指：對著**同一行版本文字**連續點幾下，看到“已開啟開發者模式”“您已處於開發者模式”等提示就停。部分系統需要的次數略有不同，以螢幕提示為準。

如果系統問密碼，輸入平時解鎖這部手機的密碼。不是讓你新註冊開發者賬號。

### 3.1 小米 / Redmi / POCO：HyperOS、MIUI

#### 第一步：把開發者選項顯示出來

1. 開啟“設定”。
2. 點選“我的裝置”或“關於手機”。
3. 如果頁面直接有“OS 版本”，連續點選這一行；如果沒有，先進入“全部引數與資訊”。
4. 找到 **“OS 版本”**，連續點選直到出現已進入開發者模式的提示。
5. 舊 MIUI 的對應位置可能叫“全部引數 → MIUI 版本”，點選的是 **MIUI 版本**。
6. 返回設定最外層。
7. 點選“更多設定”。
8. 向下找到“開發者選項”，點選進入。
9. 如果頂部總開關關閉，把它開啟。

找不到時，在設定頂部搜尋“開發者選項”。如果仍沒有結果，回去確認剛才點的是 **OS / MIUI 版本**；“Android 版本”那一行可能只會打開彩蛋。

路徑依據 [小米官方開發者選項說明][S7]，也可對照 [影片教程 02:23～02:32][V2]。

#### 第二步：開啟除錯開關

1. 在開發者選項裡向下找到“除錯”一組。
2. 開啟 **“USB 除錯”**。
3. 出現警告倒計時，就等倒計時結束，閱讀後確認。
4. 三月七需要模擬點按：繼續檢查 **“USB 除錯（安全設定）”**，本機有這一項時將它開啟，並完成系統要求的確認。
5. 如果系統要求登入小米賬號、聯網驗證或插入 SIM 卡，按這臺裝置實際顯示的要求完成；並不是每個版本的驗證條件都一樣。
6. Android 11 或以上繼續找“無線除錯”。找到了就進入 [方法 A](#_4-方法-a：只用手機，通過無線除錯啟用)；Android 10 或找不到該入口，進入 [方法 B](#_5-方法-b：通過電腦和-usb-資料線啟用)。

**“USB 除錯”和“USB 除錯（安全設定）”是兩個開關。** 前一個已開啟，並不等於後一個也打開了。額外安全設定與模擬點按的關係見 [Shizuku 手冊][S1] 和安卓版使用教程的[執行期間的注意事項](/assets/docs/Android.md#執行期間的注意事項)。

#### 小米使用者最容易遇到的兩個問題

- **Shizuku 一直搜尋不到配對服務：** 按 [後臺設定](#_73-只有切到後臺就失敗、搜尋不到服務或經常掉線時，再檢查這些設定) 把 Shizuku 的省電策略改為“無限制”，再試。
- **一點通知裡的“輸入配對碼”就失敗：** 老 MIUI 可檢查“通知管理 → 通知顯示設定 → 原生樣式”。有這項就切換後重新配對；沒有這項的 HyperOS 跳過，改用電腦路線即可。見 [Shizuku 手冊][S1]。

啟用 Shizuku 不需要解鎖 Bootloader（引導載入程式，也稱 BL 鎖），也不需要開啟“OEM 解鎖”。**操作時仍需正常解開手機鎖屏。** 不要把其他品牌的“停用系統最佳化”方法照搬到小米。

### 3.2 vivo / iQOO：OriginOS、Funtouch OS

#### 第一步：開啟開發者選項

1. 開啟“設定”。
2. 點“關於手機”。平板可能叫“關於平板電腦”。
3. 進入“版本資訊”。
4. 找 **“軟體版本號”**，連續點選約 7 次，直到出現開發者模式已開啟的提示。
5. 返回設定主頁。
6. 進入“系統管理與升級”，找到“開發者選項”。
7. 部分舊系統把這一組放在“系統管理”或“更多設定”；也可以在設定搜尋“開發者選項”。
8. 保持頂部總開關開啟，找到並開啟“USB 除錯”。

上面較新的入口依據 [vivo X200 官方使用手冊][S8]。舊機如果沒有“關於手機 → 版本資訊”，再檢查“我的裝置 → 更多引數 → 軟體版本號”。

國際版 Funtouch OS 的英文介面常見對應名稱是：

**Settings → About phone → Software information → Build number**；開發者選項在 **System → Developer options**。具體以本機選單為準。見 [vivo 國際版使用手冊][S9]。

#### 第二步：選擇啟動方法

1. 在開發者選項裡找“無線除錯”。
2. 找到了，先連線 Wi-Fi，再進入 [方法 A](#_4-方法-a：只用手機，通過無線除錯啟用)。
3. Android 10 或沒有該入口，進入 [方法 B](#_5-方法-b：通過電腦和-usb-資料線啟用)。

#### vivo 使用者需要額外留意

- 配對時切去設定後一直搜不到服務，優先給 Shizuku 開“允許後臺高耗電 / 允許後臺執行”，具體操作見 [後臺設定](#_73-只有切到後臺就失敗、搜尋不到服務或經常掉線時，再檢查這些設定)。
- **“USB 模擬點選”解決的是之後的點選許可權問題。** 只有 Shizuku 已執行、小助手已授權，但仍提示無法模擬點按時，再檢查開發者選項裡是否有它；有則開啟並重試。這個選項只在部分 vivo 裝置上有，見 [網易 Airtest 官方問題說明][S11]。
- 沒有“USB 模擬點選”就跳過，不必為尋找它去改安全鍵盤、支付保護等無關設定。

### 3.3 OPPO / 一加 / 真我：ColorOS、OxygenOS、realme UI

#### 第一步：開啟開發者選項

1. 開啟“設定”。
2. 點“關於本機”或“關於手機”。
3. 進入“版本資訊”或“版本”。
4. 找 **“版本號”**，對著這一行連續點約 7 次。
5. 英文介面可能寫 **Build number、Version number 或 Version No.**，通常旁邊是一長串數字、字母。
6. 按提示輸入鎖屏密碼，等到出現開發者模式開啟的提示。
7. 返回設定主頁，進入“系統與更新 → 開發者選項”。
8. 舊版可能在“其他設定”或“系統設定”裡。找不到時，直接搜尋“開發者選項”。
9. 保持頂部總開關開啟，開啟“USB 除錯”。

OPPO 官方對新舊系統給了不同入口，見 [開發者選項說明][S12] 和 [USB 除錯說明][S13]；真我對應入口見 [realme 官方支援][S14]。

#### 第二步：先按通用流程配對、啟動

在開發者選項裡找到“無線除錯”，按 [方法 A](#_4-方法-a：只用手機，通過無線除錯啟用) 做。沒有“無線除錯”就走 [方法 B](#_5-方法-b：通過電腦和-usb-資料線啟用)。

**如果已經顯示正在執行，也沒有 ADB 許可權受限等警告，先去給小助手授權，不用為了湊齊教程開關而繼續改系統。**

#### 第三步：遇到“ADB 許可權受限 / 製造商限制了許可權”時，按開關全名處理

ColorOS 系最容易在這一步看反。請看手機顯示的**完整名稱**：

| 你看到的名字 | 應該怎樣設 |
| --- | --- |
| 許可權監控 / Permission monitoring | **關閉** |
| 禁止許可權監控 / 停用許可權監控 / Disable permission monitoring | **開啟** |
| 停用系統最佳化 / Disable system optimization / Disable system optimisation | **開啟**，只用於出現對應許可權問題、並提供此選項的韌體 |

“禁止許可權監控”前面已經帶了“禁止”二字，所以要把這個開關**開啟**，才能停止額外的許可權攔截。不是看見“監控”兩個字就一律關掉。

舊介面可對照 [MAA 官方的實機演示影片 02:10～02:19][M1]；新介面和改名情況有 [Shizuku 原始問題記錄 #2149][S16] 交叉支援。

#### 找不到“禁止許可權監控”，怎麼辦

按這個順序檢查：

1. 先在開發者選項裡找“停用系統最佳化”或相近的完整名稱。
2. 找到了，就按上表處理，不必換語言。
3. **確實找不到，而且 Shizuku 正在提示相關許可權錯誤**，才嘗試臨時切換英文。
4. 切換前，先在設定搜尋“語言”，找到當前的“語言與地區”頁面，記住如何回來。
5. 將系統顯示語言改為 **English**。有些系統要先“新增語言”，再把英語設為系統語言或移到第一位。
6. 返回 **Settings**，搜尋 **Developer options**。也可能在 **System & update**、**System & updates** 或 **Additional settings** 下。
7. 向下找 **Disable system optimization / Disable system optimisation**，將其開啟。
8. 系統可能顯示影響耗電、功能和安全保護的提示。閱讀後確認；找不到準確名稱就停止這一分支，保留報錯資訊，不去開啟名字相似的其他開關。
9. 回到語言頁面 **Language & region** 或 **Languages & region**，把顯示語言改回“簡體中文”。
10. 回 Shizuku 重試啟動；如果服務原來已執行但許可權仍舊，按 [7.5 節](#_75-教程讓你重新啟動-shizuku-服務時，具體怎麼點)“停止 Shizuku → 重新啟動”，然後回小助手重新檢查授權。

此方法在一加 Ace 6 / ColorOS 16.0.7 等具體韌體的原始報告中出現，MAA 官方的實機演示影片裡也有切英文的操作。較新 ColorOS 的部分版本已能直接顯示對應選項，因此**不要求所有人都切英文**。見 [Shizuku 問題 #2149][S16]、[#374][S17] 和 [MAA 演示影片 03:08～03:53][M2]。

這個系統級開關與“只給 Shizuku 取消電池最佳化”是不同的東西。能正常啟動時，優先保留原設定。

### 3.4 榮耀：MagicOS、Magic UI

1. 開啟“設定”。
2. 進入“關於手機”；平板進入“關於平板電腦”。
3. 找到“版本號”，連續點選約 7 次。
4. 按提示輸入鎖屏密碼，看到開發者模式已開啟的提示後返回。
5. 進入“系統和更新”。
6. 點選 **“開發人員選項”**。榮耀常用“開發人員”這幾個字，和“開發者選項”是同類入口。
7. 保持總開關開啟，開啟“USB 除錯”。
8. 在頁面中找“無線除錯”：有則按 [方法 A](#_4-方法-a：只用手機，通過無線除錯啟用)；沒有則按 [方法 B](#_5-方法-b：通過電腦和-usb-資料線啟用)。

以上開發者入口依據 [榮耀官方支援][S18]。

**需要區分的兩個名字：**

- 本文使用的是 **USB 除錯 / 無線除錯 / ADB**。
- **HDB** 是手機助理使用的另一種連線功能。開啟 HDB 不等於 Shizuku 已啟動，也不用專門為了無線配對去裝榮耀手機助理。

如果 Shizuku 配對時經常消失，或切到設定就搜不到服務，按 [後臺設定](#_73-只有切到後臺就失敗、搜尋不到服務或經常掉線時，再檢查這些設定) 為它關閉“自動管理”、允許後臺活動。

如果 USB 方式下除錯開關會關閉、僅充電時連線不上，檢查本機是否提供“‘僅充電’模式下允許 ADB 除錯”。存在且符合這個症狀時再開啟；無線配對不必為了尋找它卡住。參考 [榮耀社群答覆][S19]。

### 3.5 華為：先分清 HarmonyOS / EMUI 的兩種情況

#### 情況一：HarmonyOS 2～4.3 / 支援原生 Android 應用的 EMUI

[華為官方說明][S15]指出：這些系統沒有無線除錯設定項，建議使用有線 USB 除錯。

所以，找不到“無線除錯”時，**直接走電腦 USB 路線**，不用一直搜尋這個不存在的選單。

1. 開啟“設定 → 關於手機 / 關於平板”。
2. 連續點選“版本號”；HarmonyOS 的部分介面顯示為“HarmonyOS 版本 / HarmonyOS 版本號”，看到開發者模式開啟提示就停。
3. 如需密碼驗證，輸入本機鎖屏密碼。
4. 返回設定，進入“系統和更新 → 開發人員選項”。
5. 開啟“USB 除錯”。
6. 找到 **“‘僅充電’模式下允許 ADB 除錯”**，本機有這一項時開啟。它有助於避免充電模式下除錯被關閉。
7. 進入 [方法 B：電腦 USB](#_5-方法-b：通過電腦和-usb-資料線啟用)。

如果 USB 除錯開關不能開啟，先確認當前是機主的主空間，再檢查資料線和連線模式。廠商管理模式限制應由裝置所有者或管理員處理，不用跟著不明教程繞開管理。見 [華為 USB 除錯排障][S20]、[開發者選項入口][S21]。

#### 情況二：HarmonyOS NEXT / HarmonyOS 5 及以上原生系統

**本教程的原版 Shizuku + Android ADB 路線不適用於它的原生環境。**

部分系統現在能通過“卓易通”等相容環境執行某些 APK，但這是另一層執行環境；裝進相容環境的 Android 應用，不等於已經給原生手機系統取得了 Shizuku 許可權。見 [華為官方說明][S22]。

目前沒有已核實、可供新手照做的原生 Shizuku 啟用方法，小助手安卓版也暫時無法在這類系統上使用。請改用滿足[安卓版要求](/assets/docs/Android.md#使用前準備)的其他裝置，或者使用[電腦版](/assets/docs/Tutorial.md)；不要為了本教程去降級、刷機。

## 4. 方法 A：只用手機，通過無線除錯啟用

**適用：Android 11 或更新，且本機提供“無線除錯”。**

先完成自己品牌的開發者選項準備。下面所有操作，都在**要執行小助手的同一部手機**上完成。

本章把官方配對流程和當前原版中文介面拆成小步驟；相關入口可對照 [Shizuku 中文介面原始碼][S27]、[官方手冊][S1]，整段流程也可以看 [影片教程 03:28～05:23][V1]。

### 4.1 確認手機已經連上 Wi-Fi

1. 開啟“設定 → WLAN / Wi-Fi”。
2. 點自己要用的網路，輸入 Wi-Fi 密碼連線。
3. 等網路名稱旁出現“已連線”。
4. 暫時不要在配對期間換網路。

狀態列只有“4G / 5G”不算連了 Wi-Fi。家裡沒有路由器，可以讓另一部手機開熱點，再讓當前手機去連線。

### 4.2 先在 Shizuku 裡點“配對”

1. 開啟 **Shizuku**。可以從手機桌面開啟，也可以點小助手許可權引導裡的“開啟 Shizuku”。
2. 找到標題為“通過無線除錯啟動”的卡片。
3. 點選卡片裡的 **“配對”**。
4. 如果系統詢問是否允許 Shizuku 傳送通知，選“允許”。
5. 如果頁面提示通知被停用，點選“通知設定”，開啟“允許通知”，然後返回配對引導頁。

**通知許可權要開。** 普通手機上的原版 Shizuku，是通過通知裡的輸入框接收配對碼。不是給它“讀取全部通知”的許可權，也不是去開啟“通知使用權”。

### 4.3 進入手機系統的“無線除錯”

1. 在 Shizuku 配對引導裡點“開發者選項”；也可以手動回到自己的系統設定入口。
2. 確認“USB 除錯”處於開啟狀態。
3. 向下找到 **“無線除錯”**。
4. 開啟它右邊的開關。
5. 如果問“要允許通過此網路進行無線除錯嗎？”，點選“允許”。這是你熟悉的家庭 Wi-Fi 時，可以勾選“始終允許通過此網路進行除錯”。
6. **再點“無線除錯”這四個字所在的那一行，進入詳情頁。**

這一步有兩個不同動作：**右邊的小開關負責開啟功能，左邊的文字負責進入下一頁。** 如果你只看到了一個開關，沒有看到配對按鈕，通常是還沒點進去。

### 4.4 開啟六位配對碼視窗

1. 在無線除錯詳情頁找到 **“使用配對碼配對裝置”**，點選。
2. 不選“使用二維碼配對裝置”。
3. 螢幕會彈出一個視窗，顯示“Wi-Fi 配對碼 / WLAN 配對碼”等字樣，下面一般是 **6 位數字**。
4. 記住這 6 位數字，或者先抄在紙上。
5. **保持這個視窗開著。現在不要按返回，不要點取消，也不要回桌面。**

窗口裡還可能顯示 IP 地址和埠，例如 `192.168.x.x:12345`。普通通知配對這一步用的是**六位配對碼**，不是冒號後面的埠數字。

配對碼只對當前這一輪有效。不要輸入影片裡的數字，也不要輸入上次截圖上的舊碼。

### 4.5 保持配對視窗開著，下拉通知輸入數字

1. 手指放在螢幕**最上邊緣**，向下滑，拉出通知欄。
2. 如果拉出來的只有 Wi-Fi、藍牙、亮度等按鈕，沒有通知，先收回，再從螢幕另一側的頂部下拉。有些系統把控制中心和通知分在兩邊。
3. 找到來自 **Shizuku** 的通知。
4. 它可能先顯示“正在搜尋配對服務”；找到後會出現 **“輸入配對碼”**。
5. 如果通知只顯示一行，點右側的小箭頭或展開按鈕。
6. 點選“輸入配對碼”，輸入剛剛記下的 6 位數字。
7. 點輸入框旁邊的傳送箭頭 / 確認按鈕。
8. 等通知顯示“配對成功”。

**不要為了填碼，先切回 Shizuku 首頁找輸入框。** 留在系統的配對碼視窗上方，下拉通知輸入，最不容易中途丟掉這一輪配對。

如果點開輸入框就失敗，或者通知一直找不到配對服務，跳到 [配對問題排查](#_82-沒有-shizuku-配對通知、找不到輸入框)，不需要重灌軟體。

### 4.6 配對成功後，還要真正啟動

1. 看到“配對成功”後，現在可以關閉配對碼視窗。
2. 返回 Shizuku 首頁。
3. 在 **“通過無線除錯啟動”** 卡片裡點選 **“啟動”**。
4. 螢幕可能出現很多英文和數字，那是啟動日誌。先等它完成，不用輸入任何東西。
5. 回到首頁，確認頂部顯示 **“Shizuku 正在執行”** 或相近的執行狀態。

“已配對裝置”列表中出現 `shizuku`，只表示配對關係已經建立。**首頁顯示執行中，才表示服務啟動成功。**

### 4.7 現在去給小助手授權

Shizuku 顯示執行中後，直接進入 [第 6 章：給三月七小助手授權](#_6-最後一步：允許三月七小助手使用-shizuku)。

不用再做下面的電腦路線。

## 5. 方法 B：通過電腦和 USB 資料線啟用

**適用：Android 10、沒有無線除錯的裝置、無線方案反覆失敗的裝置。**

這條路線用電腦幫手機啟動一次 Shizuku。完成後，小助手仍然在手機上執行；不是讓電腦版小助手一直控制手機。

準備：

- 你自己的或可信任的 Windows / Mac / Linux 電腦。
- 一條支援資料傳輸的 USB 線。
- 手機上的 Shizuku 已安裝。
- 本機開發者選項和 USB 除錯已開啟。

### 5.1 Windows：下載並解壓工具

1. **在電腦瀏覽器**開啟 [Google 官方 SDK Platform-Tools 下載頁][S28]。
2. 點選“下載適用於 Windows 的 SDK Platform-Tools”（英文頁面寫作 **Download SDK Platform-Tools for Windows**）。
3. 如出現條款視窗，閱讀並確認後下載。
4. 找到下載好的 ZIP 檔案。瀏覽器下載記錄旁通常有“在資料夾中顯示”。
5. 右鍵 ZIP，選擇“全部解壓縮”，再點選“解壓縮”。
6. 開啟解壓出來的資料夾，繼續進入 **`platform-tools`**。
7. 確認裡面能看到 **`adb.exe`**。如果系統隱藏了副檔名，可能只顯示 `adb`，型別是應用程式。

**不需要下載整套 Android Studio，也不需要雙擊 adb.exe。** 雙擊它可能只會閃一下黑視窗，本教程接下來會在命令視窗中執行它。

### 5.2 Windows：在正確的資料夾開啟 PowerShell

1. 保持剛才含有 `adb.exe` 的資料夾開啟。
2. 點選檔案管理器**上方顯示資料夾路徑的位址列**，不是右邊的搜尋框。
3. 把位址列裡原來的內容刪掉，輸入 `powershell`。
4. 按鍵盤 **Enter（回車）**。
5. 一個命令視窗會開啟。後文說的“電腦視窗”，就是它，暫時不要關。
6. 複製下面一行，貼上到窗口裡，再按 Enter：

```powershell
.\adb.exe version
```

看到 **Android Debug Bridge version** 及版本號，說明位置正確，工具也能執行。

如果提示“找不到 `.\adb.exe`”，回上一節檢查：要在真正包含 `adb.exe` 的那層資料夾裡開啟視窗，而不是外面的 ZIP 或下載目錄。

### 5.3 Mac：下載工具並開啟終端

Windows 使用者直接跳到 [5.4 節](#_54-連線手機，讓電腦認出它)。

1. 在 Mac 上開啟 [官方 Platform-Tools 下載頁][S28]，選擇 Mac 版本。
2. 下載後雙擊 ZIP，解壓出 `platform-tools` 資料夾。
3. 按 **Command + 空格**，搜尋“終端”，開啟。
4. 在終端輸入 `cd `，注意字母后面有**一個空格**，先不要回車。
5. 把 Finder 裡的 `platform-tools` 資料夾拖進終端。窗口裡會自動補全資料夾路徑。
6. 按 Enter，進入這個資料夾。
7. 輸入下面一行，按 Enter：

```bash
./adb version
```

看到 **Android Debug Bridge version** 就可以繼續。

後文 Windows 命令開頭的 `.\adb.exe`，在 Mac 中對應 **`./adb`**。

Linux 使用者同樣下載官方 Linux 版、解壓，在 `platform-tools` 裡開啟終端，使用 `./adb`。若出現 `no permissions`，看 [Linux USB 許可權排查](#_87-linux-提示-no-permissions)。

### 5.4 連線手機，讓電腦認出它

1. 手機保持解鎖。
2. 確認“開發者選項”和“USB 除錯”已經開啟。
3. 用資料線把手機連到電腦。
4. 手機上如果出現“USB 用途”選單，先保持當前模式；若後面電腦認不出，嘗試“檔案傳輸 / 傳輸檔案”。
5. 在電腦剛才的視窗執行對應命令：

Windows：

```powershell
.\adb.exe devices
```

Mac / Linux：

```bash
./adb devices
```

6. **馬上看手機螢幕。** 第一次通常會出現“允許 USB 除錯嗎？”的視窗。
7. 確認是你剛接上的電腦，點選“允許 / 確定”。這是自己的可信電腦時，可以勾選“一律允許使用這臺計算機進行除錯”。
8. 再在電腦執行一次同樣的 `devices` 命令。

成功時，輸出類似：

```text
List of devices attached
示例裝置編號    device
```

前面那串裝置編號每臺手機不同，不用和示例一樣。**關鍵看後面是 `device`。**

### 5.5 先確認裝置狀態，不要跳過

| 電腦輸出 | 意思 | 接下來怎麼做 |
| --- | --- | --- |
| 編號後面是 `device` | 連線已經可用 | 繼續下一節啟動 Shizuku |
| `unauthorized` | 手機還沒有允許這臺電腦除錯 | 看手機彈窗，允許後再次執行 `devices` |
| `offline` | 發現了裝置，但連線還沒有正常工作 | 解鎖手機、重新插拔資料線，再試 |
| 只有標題，下面空白 | 電腦還沒認出手機 | 換資料線 / USB 介面，確認 USB 除錯；必要時看驅動排查 |
| `more than one device/emulator` | 同時連線了多個裝置或模擬器 | 先退出模擬器、拔掉其他裝置，只保留當前手機 |

`device` 只說明電腦已經能與手機通訊，**還不是 Shizuku 已啟動**。下一節才是啟動動作。

連線確認與授權機制依據 [Google ADB 文件][S2]。

### 5.6 在自己手機裡取得“這臺手機專用”的啟動指令

1. 手機開啟 **Shizuku**。
2. 找到 **“通過連線電腦啟動”**，有的版本後面還寫著“使用 adb”。
3. 點選 **“檢視指令”**。
4. 點選“複製”或“傳送”，取得視窗中顯示的**完整一行指令**。
5. 把這行文字傳到自己的電腦。可以用自己的檔案傳輸助手、同步筆記等方式，電腦端再複製。
6. 不要複製別人截圖上的路徑；裡面有些目錄與**這臺手機的這次安裝**有關。
7. 電腦上只修改開頭：

| 電腦系統 | 手機指令最前面的 `adb` 改成 |
| --- | --- |
| Windows PowerShell | `.\adb.exe` |
| Mac / Linux 終端 | `./adb` |

**其餘部分原樣保留，包括空格、斜槓、大小寫。**

例如，較早版本手機顯示這一行時：

```text
adb shell sh /sdcard/Android/data/moe.shizuku.privileged.api/start.sh
```

Windows 中對應：

```powershell
.\adb.exe shell sh /sdcard/Android/data/moe.shizuku.privileged.api/start.sh
```

**上面只是較早版本的示例。手機實際顯示不同指令，就用手機顯示的。**

Shizuku 13.6.0 已改用安裝目錄中的 `libshizuku.so`，與舊版 `start.sh` 不同。官方舊網頁仍保留舊指令，所以“自己手機 → 檢視指令”比照抄網上固定的一行更可靠。[13.6.0 釋出說明][S3] [13.6.0 啟動原始碼][S29] [13.5.4 啟動原始碼][S30]

### 5.7 執行指令，檢查手機

1. 把改好開頭的完整指令，貼上到電腦的同一個視窗。
2. 按 Enter。
3. 等輸出結束，期間保持手機連線。
4. 看手機的 Shizuku 首頁。
5. 顯示 **“Shizuku 正在執行”** 就成功了。
6. 這時可以嘗試拔掉資料線，再看一次是否仍顯示執行中。
7. 正常執行就進入 [給三月七授權](#_6-最後一步：允許三月七小助手使用-shizuku)。

如果拔線後立即停止，檢視華為 / 榮耀的“僅充電”除錯開關，以及 [服務停止排查](#_74-服務啟動後很快停止)。不需要重新安裝小助手。

**Android 10 普通無 Root 裝置：每次重啟手機後，需要再連線電腦啟動一次；不用重新下載工具。**

## 6. 最後一步：允許三月七小助手使用 Shizuku

前提：Shizuku 首頁已經顯示正在執行。

1. 回到“三月七小助手”。
2. 首頁點選“去完成授權”。
3. 在許可權引導中，確認選的是 **Shizuku**。
4. 安裝和服務兩項已經就緒後，在允許小助手使用 Shizuku 這一步點選 **“授權”**。
5. 彈出 Shizuku 授權視窗時，確認請求的應用是“三月七小助手”。
6. 點選 **“始終允許”**。
7. 回到小助手，看到 **“許可權已就緒”**。
8. 點選“回到首頁”。

如果沒有彈窗：

1. 開啟 Shizuku。
2. 點選首頁顯示“已授權 X 個應用”的那一欄，進入“應用管理”。
3. 找到“三月七小助手”，開啟它旁邊的開關。
4. 回小助手重新檢視許可權狀態。
5. 列表裡沒有三月七時，先回三月七點選一次“授權”，讓它發起請求，再檢查列表。

### 完成檢查

- Shizuku 首頁顯示正在執行。
- Shizuku 裡三月七小助手已經獲得授權。
- 三月七的許可權引導顯示“許可權已就緒”。

這三項都完成，**Shizuku 啟用與授權部分就做完了**。

如果此後遊戲沒登入、遊戲版本不對、虛擬屏卡住，繼續看三月七自己的執行說明或日誌；這些問題要按具體報錯處理，不用返回開頭重複配對。

## 7. 以後再用、重啟手機、避免後臺失效

### 7.1 第二次使用，到底要不要從頭再來

先開啟 Shizuku 看首頁，再決定怎麼做。

| 你現在看到的情況 | 該做什麼 |
| --- | --- |
| Shizuku 仍在執行，三月七也已授權 | 直接使用小助手 |
| Shizuku 沒在執行，之前用無線除錯啟動過 | 連線 Wi-Fi，確認無線除錯已開啟，回 Shizuku 點“啟動” |
| Shizuku 沒在執行，之前用電腦 USB 啟動 | 連線電腦，確認 `devices` 是 `device`，重新執行本機 Shizuku 的啟動指令 |
| 點選無線啟動後要求重新配對，或配對記錄已經被刪除 | 再做一次 [4.2～4.6 節的配對步驟](#_4-方法-a：只用手機，通過無線除錯啟用) |
| Shizuku 在執行，三月七仍提示未授權 | 去 [第 6 章](#_6-最後一步：允許三月七小助手使用-shizuku)，檢查三月七的授權開關 |

**重新啟動服務、重新配對、重新安裝，是三件不同的事。** 普通重啟手機後，通常不需要重灌 Shizuku，也不必先刪掉原有配對。

#### 為什麼有人重啟後會自動恢復，有人不會

Shizuku v13.6.0 的釋出說明加入了 **Android 13 及以上，在受信任 Wi-Fi 環境下無 Root 自動啟動**的支援；實際能否恢復，還受此前的啟動方式、系統許可權、機主使用者和廠商後臺行為影響。因此，本文統一採用“**重啟後先看首頁；沒執行再啟動**”的做法。[版本說明][S3] [啟動邏輯][S39]

不要把設定裡的“允許後臺自啟動”理解成“一定能永久自動啟用 Shizuku”。它們解決的問題不同。使用舊版 Shizuku 的普通無 Root 裝置、Android 10 的普通無 Root 裝置，以及未滿足新版條件的裝置，仍需手動啟動。

### 7.2 用完能不能拔線、換網路、關除錯

- **電腦 USB 啟動成功後，一般可以拔線。** 以拔線後 Shizuku 首頁仍顯示執行中為準。
- **換 Wi-Fi 或離開 Wi-Fi 後，系統可能關閉無線除錯。** 再次需要無線啟動時，重新連線 Wi-Fi，並檢查開關。
- **無線除錯連線結束，不必然等於 Shizuku 服務已經停止。** 判斷依據仍然是 Shizuku 首頁；不要只看系統通知就重新安裝。
- **需要繼續使用 Shizuku 時，保留開發者選項與 USB 除錯。** 某些系統關閉這些開關會導致服務停止。
- **如果以後不再使用，** 可以在 Shizuku 首頁點“已授權 X 個應用”，在“應用管理”裡撤銷三月七授權，再關閉不需要的除錯開關。

除錯連線、網路變化和服務停止的區別依據 [Shizuku 使用手冊][S1] 與 [當前介面提示][S27]。

### 7.3 只有切到後臺就失敗、搜尋不到服務或經常掉線時，再檢查這些設定

以下操作的目的，是讓手機不要在你切換到設定頁面時，立刻限制 Shizuku。已經能穩定使用，可以跳過。

**先學會開啟“應用資訊”：**

1. 回到手機桌面，找到 Shizuku 圖示。
2. 手指按住圖示，先別鬆開。
3. 出現小選單後，點“應用資訊”“應用詳情”，或圓圈裡的 `i`。
4. 如果這個選單沒有入口，開啟“設定 → 應用 / 應用管理”，在列表中找到 Shizuku。

後面提到應用電池設定、通知設定，很多都能從這裡進入。

#### 小米 / Redmi：取消 Shizuku 的後臺省電限制

1. 在設定搜尋“電池”，進入 Shizuku 對應的應用耗電設定；部分機型可從 Shizuku 的應用資訊進入。
2. 在“省電策略 / 電池使用”中，選擇 **“無限制”**，英文可能顯示 `No restrictions`。
3. 在設定搜尋“自啟動”或“後臺自啟動”。
4. 在應用列表中，只給 Shizuku 開啟允許自啟動。
5. 回到 Shizuku，重新進行剛才失敗的配對或啟動。

常見自啟動路徑是“設定 → 應用 / 應用設定 → 許可權 / 許可權管理 → 後臺自啟動”。選單隨機型變化。參考 [小米後臺自啟動說明][S31]、[小米後臺網路與省電說明][S32]。

#### vivo / iQOO：允許 Shizuku 後臺執行

1. 開啟“設定 → 電池”。
2. 找到“後臺耗電管理”或“後臺高耗電”。
3. 找到 Shizuku，選擇 **“允許後臺高耗電 / 允許後臺執行”**。
4. 如果設定裡有“應用與許可權 → 許可權管理 → 許可權 → 自啟動”，給 Shizuku 開啟；也可以直接搜尋“自啟動”。
5. 回 Shizuku 重試。

“允許後臺高耗電”這個名字是在問是否允許它留在後臺工作，不是要求你把手機電量耗光。這組路徑來自 vivo 官方客服的後臺管理說明，較新系統可能改名；找不到時從應用資訊檢視電池管理。[vivo 官方說明][S10]

#### OPPO / 一加 / 真我：允許後臺活動

1. 進入 Shizuku 的“應用資訊”。
2. 找“耗電管理 / 電池使用情況”。
3. 開啟 **“允許後臺活動”**；部分版本可能使用其他“允許後臺執行”的表述。
4. 如果同頁有“允許自啟動 / 允許自動啟動”，也為 Shizuku 開啟。
5. 若應用資訊裡沒有，在設定搜尋“應用耗電管理”，找到 Shizuku 後設置。

部分真我機型的路徑是“設定 → 電池 → 應用耗電管理”。參考 [realme 官方後臺管理說明][S34] 與 [OPPO 應用後臺設定示例][S38]；後者是華為為其應用提供的 OPPO 適配文件，本文只借用系統選單路徑，選擇的應用仍是 Shizuku。

#### 榮耀：關閉 Shizuku 的“自動管理”，改為手動允許

1. 在設定頂部搜尋 **“應用啟動管理”**。
2. 進入後找到 Shizuku。
3. 關閉 Shizuku 旁邊的 **“自動管理”**。
4. 在隨後出現的手動管理窗口裡，開啟 **“允許後臺活動”**。
5. 如同一視窗有“允許自啟動”“允許關聯啟動”，也開啟，再點“確定”。

這裡關閉“自動管理”，是讓你自己決定它能否執行，**不是關閉 Shizuku**。

如果仍被省電策略限制：

1. 在設定搜尋“電池最佳化”。
2. 將列表篩選切換為“所有應用”，再找 Shizuku。
3. 進入後選擇 **“不允許”**。

請看清標題：這裡的“不允許”是 **不允許系統對 Shizuku 進行電池最佳化**，不是不允許 Shizuku 工作。參考 [榮耀後臺執行說明][S33]、[榮耀啟動管理說明][S40]。

#### 其他品牌

先從 Shizuku 的應用資訊尋找“電池”“後臺執行”“不受限制”等選項。如果手機支援多工卡片加鎖，可把 Shizuku 卡片鎖住，避免“一鍵清理”誤關；不同系統可能通過長按卡片、卡片選單或向下滑動實現。

**後臺鎖不是保證永遠執行的開關。** 仍需通過首頁狀態確認。

三月七自身執行任務時，也可能需要後臺許可權。可以進入小助手“設定”中的“後臺執行與省電”，按應用內說明處理；如果是遊戲被清理，再針對該遊戲檢查，不用把手機所有應用都改成無限制。見安卓版使用教程的[執行期間的注意事項](/assets/docs/Android.md#執行期間的注意事項)。

### 7.4 服務啟動後很快停止

按這個順序檢查：

1. 先確認沒有誤關“開發者選項”總開關或“USB 除錯”。
2. 看看停止是否總髮生在鎖屏、切後臺或一鍵清理之後。如果是，按 [7.3 節](#_73-只有切到後臺就失敗、搜尋不到服務或經常掉線時，再檢查這些設定)處理 Shizuku 的後臺限制。
3. 如果是華為 / 榮耀拔掉資料線後停止，回對應品牌章節檢查“僅充電模式下允許 ADB 除錯”這類開關；只在本機存在時設定。
4. 如果是長時間不用後除錯授權反覆失效，在開發者選項裡查詢 **“停用 ADB 授權超時功能 / 停用 adb 授權超時”**。存在這個選項時，可開啟後再觀察。它影響已信任除錯連線的授權有效期，不是每臺裝置首次啟用的必做項。
5. 重複啟動一次 Shizuku，返回小助手檢查授權是否恢復。

如果 Shizuku 一直顯示執行中，只有三月七任務停止，則繼續看小助手的日誌與後臺設定；這與 Shizuku 服務被停止是兩個排查方向。[Shizuku 排障說明][S1]

### 7.5 教程讓你“重新啟動 Shizuku 服務”時，具體怎麼點

這是重新啟動 Shizuku 自己的服務，不是讓你重啟整部手機。

1. 如果小助手正在執行任務，先停止任務。
2. 開啟 **Shizuku 首頁**。
3. 點選右上角 **`⋮`（三個點 / 更多選單）**。
4. 點選 **“停止 Shizuku”**。
5. 出現“Shizuku 服務將被停止”等確認提示時，點“確定”。
6. 確認首頁變為未執行，再按原來的方法啟動：無線使用者回到無線除錯卡片點“啟動”；電腦使用者重新連線電腦執行本機啟動指令。
7. 看到正在執行後，回三月七檢查授權狀態。

如果首頁本來就顯示未執行，直接做第 6 步即可。不用清除應用資料，也不用解除安裝 Shizuku。

“停止 Shizuku”的選單位置和確認動作已經對照原版介面與原始碼核對。[選單定義][S42] [首頁動作][S41] [中文名稱][S27]

## 8. 遇到問題：按現象查

**先找你螢幕上的現象，不用把下面全部做一遍。** 一次只改一個相關設定，再重試剛才失敗的步驟。

### 8.1 找不到開發者選項，或沒有無線除錯

| 現象 | 先做什麼 |
| --- | --- |
| 連點後出現 Android 圖案或彩蛋 | 點錯了位置；回品牌章節，點選 OS / 軟體 / 編譯版本號 |
| 顯示“您已處於開發者模式” | 已經開啟；返回設定搜尋“開發者選項”，不用繼續連點 |
| 無線除錯開關是灰色 | 先連線 Wi-Fi，檢查開發者選項總開關是否開啟 |
| Android 10 找不到無線除錯 | 屬於正常情況，走 [電腦 USB 方法](#_5-方法-b：通過電腦和-usb-資料線啟用) |
| 華為 HarmonyOS 2～4.3 / EMUI 沒有無線除錯 | 走 [華為專章](#_35-華為：先分清-harmonyos-emui-的兩種情況)與電腦 USB 方法 |
| Android 11 以上仍沒有無線除錯 | 系統版本號滿足條件，也不代表廠商一定提供入口；搜尋確認後走電腦 USB |
| 開關顯示由管理員限制 | 檢查是否在工作資料、兒童模式、訪客或非機主空間；使用有許可權管理的機主空間，受單位管理的裝置聯絡管理者 |

無線除錯的系統前提及廠商差異參考 [Android 官方文件][S2]、[華為官方說明][S15]。華為開發者選項還可能受機主 / 主空間狀態影響。[華為 USB 除錯排障][S20]

### 8.2 沒有 Shizuku 配對通知、找不到輸入框

#### 情況 A：通知欄裡完全沒有 Shizuku

1. 回到 Shizuku，在“通過無線除錯啟動”區域點一次“配對”。
2. 如果出現“通知設定 / 允許通知”提示，點選進入並允許。
3. 沒有彈窗時，進入 Shizuku 的“應用資訊 → 通知管理”，開啟“允許通知”；如果有單獨的“無線除錯配對”通知類別，也開啟。
4. 回 Shizuku，再點“配對”。
5. 切到開發者選項，重新開啟“使用配對碼配對裝置”視窗。
6. 保持六位碼視窗不關閉，再從螢幕頂部下拉檢視通知。

這裡需要的是 **允許 Shizuku 發通知**。不需要去開啟“讀取全部通知 / 通知使用權”這種特殊許可權。[當前配對介面文案][S27]

#### 情況 B：看到了通知，但不能輸入數字

1. 如果通知只有一行，點選右側小箭頭，把整張通知展開。
2. 點選“輸入配對碼”按鈕或輸入區域。
3. 輸入當前六位數字，再點發送箭頭 / 提交。
4. 如果下拉後只看到 Wi-Fi、藍牙等大按鈕，當前開啟的是控制中心；收回後從螢幕頂部另一側下拉，找到通知中心。
5. 舊 MIUI 若仍不能輸入，按 [小米章節](#_31-小米-redmi-poco：hyperos、miui)檢查原生通知樣式。

不要退出配對碼視窗，跑到 Shizuku 首頁尋找一個通用“IP + 埠”輸入框。本文采用官方原版常規手機介面的 **通知配對方式**。

#### 情況 C：一直顯示“正在搜尋配對服務”

1. 確認手機已連線 Wi-Fi。
2. 確認系統的 **“使用配對碼配對裝置”** 小視窗仍在螢幕上。只有開啟“無線除錯”大頁面，通常還不夠。
3. 允許 Shizuku 後臺執行，尤其是從它切換到設定時會被限制的手機，見 [7.3 節](#_73-只有切到後臺就失敗、搜尋不到服務或經常掉線時，再檢查這些設定)。
4. 仍無結果，關閉六位碼視窗，關閉再開啟“無線除錯”，然後重新開啟六位碼視窗。
5. 回到通知，使用這一輪的新配對碼；不要繼續輸入上一次記下來的舊碼。
6. 如果在公司、校園等受限網路，換成自己的家庭 Wi-Fi 或另一部手機的熱點再試。
7. 仍失敗就使用 [電腦 USB 方法](#_5-方法-b：通過電腦和-usb-資料線啟用)。這一方法不需要先把無線配對做成功。

以上順序結合 Shizuku 對後臺發現服務的說明，以及 Android 對無線網路發現限制的說明。[Shizuku 手冊][S1] [Android 無線除錯][S2]

#### 情況 D：輸入後立刻“配對失敗”，或者輸入鍵盤一彈出視窗就消失

1. 確認輸的是本次 **六位配對碼**，不是埠號。
2. 關閉舊配對視窗，再重新生成一次；新舊配對碼不能混用。
3. 保持系統配對視窗存在，用通知直接輸入，不在中間開啟別的全屏應用。
4. 小米舊版系統檢查通知樣式；其他系統先檢查通知和後臺許可權。
5. 某些系統可用小窗讓配對視窗留在螢幕上；參考影片的 ColorOS 段演示了小窗輔助。但小窗入口隨系統變化，這不是所有手機必須操作的一步。
6. 如果系統始終讓輸入與配對視窗互相打斷，直接走電腦 USB，避免在同一步無限重試。

### 8.3 已經顯示“配對成功”，Shizuku 為什麼還是沒執行

“配對成功”只說明它獲得了建立除錯連線的資格。接下來還要：

1. 關閉系統的配對碼小視窗。
2. 回到 Shizuku 首頁。
3. 在“通過無線除錯啟動”區域點選 **“啟動”**。
4. 等待啟動日誌完成。
5. 返回首頁，看是否出現“正在執行”。

如果啟動階段一直搜尋：

1. 此時去檢查的是 **無線除錯總開關**是否仍開啟、手機是否仍連線 Wi-Fi。
2. 已配對裝置還在時，可以先直接再點“啟動”；不必先刪配對。
3. 只有連線明確報配對 / 認證失敗，或配對記錄丟失，再重新配對。
4. 持續無法啟動可改用電腦 USB。

配對後的下一步也寫在原版 Shizuku 自己的成功提示中。[介面文案][S27]

### 8.4 已執行卻提示許可權受限，或小助手不能點選螢幕

先分兩層檢查：

1. 在 Shizuku 首頁點“已授權 X 個應用”，在“應用管理”裡確認三月七的開關已開啟。
2. 再按品牌檢查與報錯相符的額外除錯許可權：

| 品牌 | 要檢查的開關 |
| --- | --- |
| 小米 / Redmi / POCO | “USB 除錯”之外，還有 **“USB 除錯（安全設定）”** |
| OPPO / 一加 / 真我 | 按 [3.3 節的開關對照表](#第三步：遇到adb-許可權受限-製造商限制了許可權時，按開關全名處理)，識別“許可權監控”與“禁止許可權監控”的相反方向 |
| 新版 ColorOS 系 | 僅在對應許可權限制仍存在時，檢查“停用系統最佳化 / Disable system optimization”；需要時按正文切換語言查詢 |
| vivo / iQOO | 本機有 **“USB 模擬點選”**時，按 [vivo 專章](#_32-vivo-iqoo：originos、funtouch-os)處理；不是所有機型都有 |

調整後按 [7.5 節](#_75-教程讓你重新啟動-shizuku-服務時，具體怎麼點)重新啟動 Shizuku，再回小助手重試。同樣一句“不能用”，可能是授權、除錯許可權、遊戲狀態或應用相容性問題，**請保留完整報錯**，不要只憑手機品牌把所有安全開關都改一遍。[Shizuku 廠商限制][S1] [Airtest 輸入限制說明][S11] [ColorOS 原始反饋][S16]

### 8.5 電腦 USB 方法失敗

#### “adb 不是內部或外部命令” / “無法將 adb 識別為命令”

1. Windows 按 [5.2 節](#_5-方法-b：通過電腦和-usb-資料線啟用)重新從 **包含 `adb.exe` 的 platform-tools 資料夾**開啟 PowerShell。
2. 輸入的是 `.\adb.exe devices`，不要漏掉開頭的 `.\`。
3. Mac / Linux 輸入 `./adb devices`，並確認終端已進入解壓後的 platform-tools 資料夾。
4. 先讓“查詢裝置”這一步能執行，再貼上 Shizuku 啟動指令。

#### 只有“List of devices attached”，下面是空白

1. 解鎖手機螢幕，確認“USB 除錯”已開。
2. 拔掉資料線，重新插上。
3. 留意手機上的 USB 除錯授權彈窗，出現後點允許。
4. 換一條確定能傳輸檔案的資料線，再換電腦上的 USB 插口；優先直接連電腦，先不經過擴充套件塢。
5. 如果手機只有充電提示，可點 USB 通知，試著切到“傳輸檔案 / 檔案傳輸”模式。這是排查連線的辦法，不代表 ADB 永遠必須使用這個模式。
6. Windows 仍識別不到時，在開始按鈕上點滑鼠右鍵，開啟“裝置管理器”，看看是否有帶黃色歎號的 Android 或未知裝置。
7. 需要驅動時，從手機廠商官方支援渠道或 [Google 的 OEM 驅動索引][S36]找該品牌驅動。安裝後重新連線，執行 `devices`。

不要把 Google USB Driver 當成所有手機通用的驅動；它與各品牌自己的驅動不是一回事。Mac 通常不需要廠商 USB 驅動，Linux 的 USB 許可權問題見下方專節。[官方 USB 連線說明][S37] [OEM 驅動說明][S36]

#### 裝置後面顯示 unauthorized

1. 保持手機亮屏解鎖。
2. 檢視“允許 USB 除錯？”視窗，確認連線的是自己的電腦，點選允許。
3. 沒有視窗時，拔插一次線，再觀察。
4. 仍然不出現，可以在手機開發者選項點選“撤銷 USB 除錯授權”，再重新連線並允許。注意：這會讓此前信任的電腦也需要重新確認；無線配對也可能需要重新做。
5. 電腦再執行一次 `devices`，直到裝置後面變成 `device`。

#### 裝置後面顯示 offline

先解鎖、拔插、重新開啟 USB 除錯。仍不行時，在原來的終端中一行一行執行：

Windows：

```powershell
.\adb.exe kill-server
.\adb.exe start-server
.\adb.exe devices
```

Mac / Linux：

```bash
./adb kill-server
./adb start-server
./adb devices
```

每輸入一行按一次回車。這裡重啟的是電腦上的 ADB 連線服務，不會刪除手機內容；其他正在使用這個 ADB 服務的工具會暫時斷開。

#### 提示 more than one device/emulator

電腦同時連著多個手機、模擬器，或者同一手機還連著另一條除錯連線。先關閉模擬器、拔掉其他手機，再查詢。

如果列表仍有同一手機的無線連線，想讓本次啟動明確走 USB，可以在執行啟動指令時加 `-d`。例如 Windows 將指令開頭的 `.\adb.exe shell` 改成 `.\adb.exe -d shell`，Mac / Linux 將 `./adb shell` 改成 `./adb -d shell`；後面仍保留手機自己顯示的完整內容。`-d` 表示選擇 USB 連線。它用於選擇執行命令的目標，`devices` 列表裡仍可能顯示其他連線。

#### 提示找不到 start.sh / libshizuku.so / No such file or directory

1. 回到手機當前安裝的 Shizuku。
2. 再點一次“通過電腦連線啟動 → 檢視指令”。
3. 重新完整複製，尤其是中間很長的路徑。
4. 按電腦系統只替換開頭的 `adb`；不要手工改路徑。
5. 如果你剛更新、重灌 Shizuku，舊路徑可能已經變化，舊筆記裡的指令就不能繼續用。

不要從別人手機上覆制 `/data/app/…` 的路徑。它不是每個人都一樣。[當前版本生成指令的原始碼][S29]

### 8.6 三星提示“自動攔截器”阻止安裝或 USB 操作

只在你明確遇到這個提示時處理：

1. 確認安裝包來自 Shizuku 官方或三月七內建入口，電腦也是自己的。
2. 開啟“設定 → 安全和隱私”。
3. 找到“自動攔截器 / Auto Blocker”。
4. 檢視頁面說明；如果確認就是它阻止了當前安裝或 USB 除錯操作，按系統提示暫時關閉，再重試。
5. 之後若重新開啟，某些安裝或 USB 命令可能再次受限；不能承諾“開回去以後所有除錯都完全不受影響”。

三星官方明確列出了該功能對未知來源應用安裝與 USB 命令的限制；並不是所有三星裝置都需要改這個選項。[三星官方說明][S35]

### 8.7 Linux 提示 no permissions

這表示電腦已經發現 USB 裝置，但當前 Linux 使用者沒有訪問它的許可權。不是 Shizuku 配對碼錯誤。

**Ubuntu / 使用 apt 的相近系統**可參考 Android 官方要求，檢查 `plugdev` 使用者組與 Android 裝置的 `udev` 規則。以下命令只用於這類系統：

```bash
sudo usermod -aG plugdev "$LOGNAME"
sudo apt-get install android-sdk-platform-tools-common
```

1. 按順序執行。提示密碼時輸入 Linux 電腦的登入密碼；終端輸入密碼時可能不顯示星號，這是正常的。
2. 安裝詢問是否繼續時，閱讀包名並確認。
3. 退出 Linux 當前登入會話，再重新登入，讓使用者組變化生效；僅關閉終端通常不夠。
4. 拔插手機，重新進入 platform-tools 資料夾執行 `./adb devices`。

其他發行版使用自己的 Android USB / udev 配置方式，不要照抄 Ubuntu 的包管理命令。也不要為了繞過裝置許可權，把日常所有 ADB 操作都改成 `sudo adb`。[Android 官方 Linux 配置說明][S37]

### 8.8 還是失敗，怎樣把問題說清楚

到 [GitHub Issues](https://github.com/moesnow/March7thAssistant/issues) 反饋時，把下面這段複製到求助訊息中，能填多少填多少：

```text
手機品牌和型號：
系統名稱和完整版本號：
Android 版本：
Shizuku 版本：
三月七小助手版本：
使用的方法：無線 / Windows USB / Mac USB / Linux USB / 已有 Root
卡住的階段：安裝 / 開發者選項 / 配對 / 啟動 / 小助手授權 / 任務執行
Shizuku 首頁當前顯示：
完整報錯文字：
我已經試過：
```

最好附“Shizuku 首頁”和“報錯視窗”兩張截圖。只寫“不能用”或“我的也是某某品牌”，很難判斷是哪一步。問題出在小助手執行任務時，再到小助手“日誌”頁點“匯出”，把日誌檔案一起附上。

截圖中可以遮住手機號、賬號、裝置序列號和與問題無關的通知內容；求助不需要提供鎖屏密碼或當次配對碼。

## 9. 已經 Root 的手機

**這一章只給已經完成 Root 的使用者。** 不知道 Root 是什麼，就繼續使用前面的無線或電腦方法。

已經 Root 的手機可以在小助手許可權引導的頂部直接選 **Root**，不需要 Shizuku，步驟見安卓版使用教程的[方式二：Root](/assets/docs/Android.md#方式二：root)。Root 方式遇到問題、想改用 Shizuku 時，可以用 Root 啟動 Shizuku：

1. 開啟 Shizuku。
2. 找到“啟動（針對已 root 裝置）”這一欄，點選“啟動”。
3. 手機現有的 Root 管理器彈出授權視窗時，確認請求者是 Shizuku，然後允許。
4. 等 Shizuku 首頁顯示正在執行。
5. 繼續 [第 6 章](#_6-最後一步：允許三月七小助手使用-shizuku)，給三月七授權。

原版 Shizuku 的設定裡還有“開機啟動（root）”選項。它面向已有 Root 的裝置；不要把這個選項誤認為普通無 Root 手機的萬能開機啟用按鈕。[官方使用手冊][S1] [當前設定文案][S27]
