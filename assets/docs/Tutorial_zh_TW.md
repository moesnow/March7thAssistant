# 使用教程

> 本文件由簡體中文版經 OpenCC 簡繁轉換產生，用語以台灣習慣為準；內容如有差異，請以簡體中文版為準。

## 執行前準備

| 平臺 | 本地遊戲 | 雲遊戲 |
|------|---------|--------|
| Windows | ✅ | ✅ |
| macOS | ❌ | ✅ |
| Linux | ❌ | ✅ |
| Docker | ❌ | ✅ |
| Android (Termux) | ❌ | ✅ |

本地遊戲模式僅支援 Windows，必須使用 PC 客戶端，以 1920×1080 解析度視窗運行遊戲；如果視窗模式不可用，再選擇全屏。

遊戲內語言必須設定為簡體中文，並關閉幀率監控 HUD、微星小飛機、遊戲加加、HDR、N 卡遊戲濾鏡等可能遮擋或改變畫面的軟體。

雲遊戲模式支援 Windows、macOS、Linux、Android。macOS / Linux 使用者可通過原始碼執行使用雲遊戲模式，也可以使用 [Docker 部署](/assets/docs/Docker.md)；Android 使用者可參考 [Termux 安卓部署](/assets/docs/Termux.md)。

> 開啟 `雲·星穹鐵道` 後，清體力、每日實訓、差分宇宙等任務不再要求固定視窗，
>
> 支援後臺執行；鋤大地和模擬宇宙仍需要保持前臺全屏。
>
> 如果有後臺執行或多開桌面的需求，也可以使用 [遠端本地多使用者桌面](/assets/docs/Background.md)。

## 下載安裝

點選 [Releases](https://github.com/moesnow/March7thAssistant/releases/latest) 開啟下載頁面，滾動到底部。

下載名稱類似 `March7thAssistant_full.zip` 或 `March7thAssistant_full.7z` 的完整包。

> March7thAssistant 接入了第三方服務 [Mirror醬](https://mirrorchyan.com/?source=m7a-tutorial)。
>
> 如果中國大陸下載緩慢，可以嘗試 [點我前往 Mirror醬 高速下載](https://mirrorchyan.com/zh/download?rid=March7thAssistant&os=&arch=&channel=stable&source=m7a-tutorial)。

下載完成後，右鍵選擇 “全部解壓縮” 或使用 [第三方壓縮軟體](https://yasuo.360.cn/) 解壓。

解壓後的目錄中通常至少包含以下檔案（夾）：

- `March7th Launcher.exe`
- `March7th Assistant.exe`
- `March7th Updater.exe`
- `assets`
- `libraries`
- `3rdparty`

雙擊 `March7th Launcher.exe` 開啟圖形介面，並同意《免責宣告》。

如果你需要配合系統任務計劃程式定時執行，或希望直接執行完整執行，也可以使用 `March7th Assistant.exe`。

### 命令列啟動

`March7th Launcher.exe` 支援命令列引數，可以在啟動圖形介面的同時自動開始指定任務。

通過終端執行時，請使用 `管理員模式` 開啟的 PowerShell、Windows Terminal 或 CMD；

如果你使用的是支援 `Sudo for Windows` 的系統，也可以用 `sudo` 來執行命令。

根據微軟文件，`Sudo for Windows` 僅在 Windows 11 版本 24H2 或更高版本中可用，

使用前還需要先在系統設定中啟用。詳情請參考：[Sudo for Windows](https://learn.microsoft.com/zh-cn/windows/advanced-settings/sudo/)

常用示例：

March7th Launcher.exe -h （檢視幫助）

March7th Launcher.exe daily （啟動圖形介面並執行每日實訓）

March7th Launcher.exe main -e （任務正常完成後自動退出程式）

常見任務名稱包括：`main`（完整執行）、`routine`（日常）、`daily`（每日實訓）、`power`（清體力）、`currencywars`（貨幣戰爭）等。

如果你只記得要執行某個任務，但忘了引數名，直接執行 `March7th Launcher.exe -l` 檢視最新列表即可。

> 此程式為免費開源專案，如果你付了錢請立刻退款。
>
> 本專案已經因倒賣行為受到嚴重威脅，請幫助我們舉報倒賣行為。

## 首頁任務

### 完整執行

`完整執行` 是最推薦的入口，適合日常無人值守。

程式會根據你當前的設定，只執行 `已啟用` 且 `已重新整理` 的內容。當前版本中，完整執行通常會序列處理以下內容：

兌換碼領取、每日實訓、活動、歷戰餘響、清體力、貨幣戰爭積分獎勵、差分宇宙積分獎勵、

鋤大地、模擬宇宙 / 差分宇宙、混沌回憶、虛構敘事、末日幻影，以及最後的領取獎勵。

沒有開啟的任務會自動跳過；已經判斷為完成、尚未重新整理到下一週期的任務也不會重複執行。

預設重新整理時間為每天凌晨 4 點；周常內容一般在每週一凌晨 4 點重新整理。

### 日常

首頁 `日常` 選單包含 `日常`、`每日實訓` 和 `清體力`。

`日常` 會忽略這組內容的重新整理狀態，按當前設定依次處理兌換碼、培養目標初始化、活動檢測、歷戰餘響、清體力和每日實訓，並在最後領取可領取的獎勵；只有未開啟的內容會自動跳過。

`每日實訓` 會先識別尚未完成的實訓任務，再嘗試自動完成；如果你只想單獨刷本耗體力，直接使用 `清體力` 即可。

`清體力` 會根據你在設定中選擇的副本型別和副本名稱自動計算挑戰次數，

也會配合後備開拓力、燃料、支援角色、培養目標等選項一起生效。

如果你在體力設定裡關閉了 `啟用清體力`，`完整執行` 和 `日常` 會一併跳過歷戰餘響與清體力；單獨執行 `清體力` 任務不受這個開關影響。

### 貨幣戰爭

當前版本已經支援 `貨幣戰爭·零和博弈`。首頁入口提供 `執行一次` 和 `迴圈執行` 兩種方式。

如果你在設定裡開啟了 `貨幣戰爭積分獎勵`，完整執行會按周常邏輯檢查積分獎勵是否已經完成；

如果沒有完成，就會自動進入貨幣戰爭處理本週積分。

設定頁中可以進一步配置 `標準博弈 / 超頻博弈`、快捷配置、職級難度、策略、速通模式，

以及領取積分獎勵後是否自動執行位面飾品快速提取。

### 差分宇宙 / 模擬宇宙

當前版本已經支援 `差分宇宙·樂園漫記`。首頁入口提供 `執行一次` 、 `迴圈執行` 和 `中途接管` 三種方式。

如果你在設定裡開啟了 `差分宇宙積分獎勵`，完整執行會按周常邏輯檢查積分獎勵是否已經完成；

如果沒有完成，就會自動進入差分宇宙處理本週積分。

設定頁中可以進一步配置 `常規演算 / 週期演算`、難度等級、站點優先順序、低效能相容模式，以及領取積分獎勵後是否自動執行飾品提取。

> `啟用模擬宇宙 / 差分宇宙` 配置頁通常用於反覆刷取遺器經驗和靈之珠淚（代替敵方掉落素材）直到每週上限（100只精英怪）。
> 
> 其中模擬宇宙部分呼叫的是 [Auto_Simulated_Universe](https://github.com/CHNZYX/Auto_Simulated_Universe) 專案，目前處於維護停滯的狀態，如遇到問題建議改用差分宇宙。

### 鋤大地

鋤大地呼叫的是 [Fhoe-Rail](https://github.com/linruowuyin/Fhoe-Rail) 專案。首頁選單提供 `快速啟動`、`原版執行`、`更新鋤大地`、`重置配置檔案`、`開啟程式目錄`、`開啟專案主頁`。

如果需要從中斷的地圖繼續執行，可以使用 `原版執行` 開啟鋤大地自身介面，再在原專案裡選擇對應模式繼續。

使用前請先開完需要的錨點，並清掉會干擾傳送或尋路的任務。

成年女性遠端無位移模型通常更穩定，例如艾絲妲、三月七；黃泉等角色可以配合專用地圖版本使用。

> 幀數要求 60 幀，其餘畫質設定一般影響不大。
> 
> 鋤大地跑圖路線均為人工公益錄製，若您有興趣的話歡迎上傳一些最佳化後的路線/新版本地圖路線，減輕一下維護人員的負擔~

### 逐光撿金

當前版本中的 `逐光撿金` 分為三類挑戰：

- `混沌回憶`
- `虛構敘事`
- `末日幻影`

這三項都可以單獨啟用，並分別配置關卡範圍和兩隊陣容。完整執行會在周常重新整理後按你的開關與配置依次處理；

如果只想單獨打其中一種，也可以直接從首頁進入對應任務。

### 工具箱

左側導航欄的 `工具箱` 提供一些常用輔助功能：

- `遊戲截圖`：檢查程式是否正確獲取遊戲畫面，也支援框選 OCR 識別文字。
- `自動對話`：進入劇情介面後自動開始執行，不支援雲·星穹鐵道。
- `兌換碼`：執行當前配置中的兌換碼。
- `解鎖幀率`：在支援的平臺上切換 60 / 120 幀。
- `觸屏模式`：按雲遊戲移動端 UI 方式啟動遊戲，依賴 [第三方專案](https://github.com/winTEuser/Genshin_StarRail_fps_unlocker) 實現。

如果你遇到畫面識別異常，最先應該開啟 `工具箱 → 遊戲截圖` 檢查採集到的畫面是否正確。

## 流程編排

左側導航欄中的 `流程編排` 適合製作自定義自動化流程。

它支援把圖片點選、文字點選、座標點選、等待、按鍵、介面切換、訊息推送等步驟拼接起來，

也支援 `if`、`for`、`while`、`break`、`continue` 這類控制邏輯。

如果你的需求已經能被首頁現成任務覆蓋，優先使用首頁任務即可；

如果你需要補充自己的個性化邏輯，例如某個固定介面的重複點選、簡單分支判斷或迴圈檢測，再使用流程編排會更合適。

首次使用建議先從一個很短的小流程開始，例如：識別按鈕、點選按鈕、等待 1 秒；

除錯時優先使用“執行選中步驟”，確認單個節點穩定後，再逐步擴充套件完整流程。

詳細說明請檢視 [流程編排使用教程](/assets/docs/Workflow.md)。

## 配置說明

點選左下角的 `設定` 進入小助手設定介面。

### 程式設定

#### 日誌等級

一般保持預設 `簡潔` 即可；如果遇到異常，請切換為 `詳細` 方便排查問題。

#### 遊戲路徑 / 啟動器路徑

啟動過遊戲後再開啟小助手，通常會自動配置 `遊戲路徑`。如果手動選擇，

注意不要誤選啟動器 `miHoYo Launcher\launcher.exe`，真正的遊戲本體是 `Star Rail Game\StarRail.exe`。

如果你希望通過米哈遊啟動器更新或預下載遊戲，還需要額外配置 `米哈遊啟動器路徑`。

#### 任務完成後

當前版本支援 `無`、`退出`、`關機`、`睡眠`、`休眠`、`重啟`、`登出`、`關閉顯示器`、`執行指令碼`、`迴圈` 等完成後操作。

其中 `退出` 指退出遊戲；`執行指令碼` 需要額外填寫路徑；`關機`、`睡眠`等操作會先提示並等待一段時間，方便你取消。

#### 定時執行

`迴圈模式` 仍然保留用於相容舊配置，但新版更推薦直接在 `日誌` 頁面配置 `定時任務`。

定時任務支援：

- 啟動內建任務，例如 `完整執行`、`清體力`、`貨幣戰爭`。
- 啟動外部程式或指令碼。
- 為單條任務設定超時強制停止。
- 配置完成後推送通知。
- 配置任務完成後的操作。
- 配置完成後自動終止指定程序。

如果你是 7×24 小時掛機使用者，優先考慮 `日誌頁定時任務`，不要再依賴舊的迴圈模式。

### 體力與日常設定

#### 副本型別 / 副本名稱

清體力時刷什麼副本，由這兩項共同決定。程式會根據開拓力自動計算次數；

如果檢測到例如 `位面分裂` 等雙倍活動，也會優先使用這裡配置的副本去完成。

#### 使用後備開拓力 / 使用燃料

這兩個選項用於清體力時額外消耗後備開拓力或燃料。單次存在上限。

#### 支援角色

開啟 `啟用使用支援角色` 後，程式會在需要時嘗試使用支援；開啟 `強制使用支援角色` 後，每次打本都會優先嚐試使用支援角色。

#### 培養目標

開啟 `培養目標` 後，程式會根據目標自動匹配行跡或遺器副本；如果識別不到培養目標，才會回退到你手動配置的預設副本。

#### 歷戰餘響

開啟後，完整執行會優先完成每週三次 `歷戰餘響`，並支援配置從周幾開始執行。

### 貨幣戰爭設定

如果你只想每週自動拿滿貨幣戰爭積分獎勵，開啟 `啟用「貨幣戰爭」積分獎勵` 即可。

常用配置項包括：

- `類別`：標準博弈 / 超頻博弈
- `快捷配置`
- `職級難度`
- `貨幣戰爭策略`
- `遇到特定詞條時接受重開`
- `啟用速通模式`

### 差分宇宙 / 模擬宇宙設定

如果你只想每週自動拿滿差分宇宙積分獎勵，開啟 `啟用「差分宇宙」積分獎勵` 即可。

`差分宇宙` 頁面主要負責每週積分獎勵、開圖鑑、提升等級，

包括常規演算 / 週期演算、難度、低效能相容模式、獎勵後自動飾品提取、站點優先順序等。

`模擬宇宙 / 差分宇宙` 頁面則負責刷取遺器經驗和靈之珠淚直到週上限（100精英怪），配置項包括：

- `執行模式`：整合 / 原始碼（僅模擬宇宙生效）
- `類別`：差分宇宙 / 模擬宇宙
- `執行頻率`：每週 / 每天
- `執行次數`
- `自動領取模擬宇宙沉浸獎勵`
- `命途`（僅模擬宇宙生效）
- `難度`（僅模擬宇宙生效）
- `啟用模擬宇宙 GPU 加速`（僅模擬宇宙生效）

如果你選擇 `原始碼` 模式，需要保證本機 Python 環境可用。

### 鋤大地設定

鋤大地頁除了啟用開關外，還可以配置：

- `執行模式`：整合 / 原始碼
- `自動切換隊伍`
- `地圖版本`
- `優先星球`
- `購買秘技零食併合成零食`
- `購買代幣與過期郵包`

如果你選擇 `原始碼` 模式，需要保證本機 Python 環境可用。

### 逐光撿金設定

`混沌回憶`、`虛構敘事`、`末日幻影` 都支援分別配置：

- 是否啟用
- 關卡範圍
- 兩隊陣容
- 上次執行時間

建議先把隊伍配置好，再用完整執行接管周常。

### 雲·星穹鐵道

開啟 `使用“雲·星穹鐵道”` 後，小助手會改用瀏覽器控制雲遊戲來執行清體力等自動化任務。

常用配置包括：

- `全屏執行`
- `最大排隊等待時間`
- `瀏覽器型別`
- `使用國內映象下載瀏覽器和驅動`
- `儲存瀏覽器資料`
- `瀏覽器畫面縮放（DPI）`
- `啟用無視窗模式（後臺執行）`
- `未登入時自動切換為有視窗模式`

其中 `無視窗模式` 不支援模擬宇宙（不包含差分宇宙）和鋤大地；如果你需要後臺掛機日常和清體力，這一組配置非常關鍵。

### 雜項設定

`雜項` 頁主要是一些增強穩定性和自動化體驗的輔助開關，常用的有：

- `啟用自動戰鬥和二倍速檢測`：在遊戲啟動前嘗試開啟自動戰鬥和二倍速，並在清體力、貨幣戰爭等內建戰鬥場景中維持狀態。
- `啟用自動修改解析度並關閉自動 HDR`：通過小助手啟動遊戲時自動切到 1920×1080 並關閉自動 HDR，適合本地模式使用者。
- `啟用自動配置遊戲路徑`：會嘗試從快捷方式、官方啟動器或正在執行的遊戲程序中自動識別路徑。
- `優先使用後臺截圖`：預設建議開啟，可以減少懸浮窗、覆蓋層等對截圖識別的干擾。
- `在使用者登入時啟動`：通過任務計劃程式在登入後自動啟動；如果想完全無人值守，通常還需要你自己配置系統自動登入。

關於 `OCR 加速模式`：建議先保持 `自動`。各模式說明如下：

- `自動`（預設）：Windows 10 18362 及以上優先使用 ONNXRuntime(DirectML) GPU 加速；
- 否則若檢測到 OpenVINO 則使用 OpenVINO CPU；都不滿足則回退到 ONNXRuntime CPU。
- `GPU (ONNXRuntime DirectML)`：強制使用 DirectML GPU 加速，環境不支援時自動回退。
- `CPU (OpenVINO)`：強制使用 OpenVINO CPU 推理。OpenVINO 在純 CPU 場景下通常比 ONNXRuntime CPU 更快，
- 當前版本已針對 OpenVINO CPU runtime cache 問題應用臨時規避方案；若可用實體記憶體低於 1GB，會自動降級到 ONNXRuntime CPU。
- `CPU (ONNXRuntime)`：強制使用 ONNXRuntime CPU 推理，相容性最好、記憶體行為最穩定。
- 如果遇到識別異常、閃退或記憶體佔用過高，可手動切換為 `CPU (ONNXRuntime)`。

### 按鍵設定

按鍵設定位於 `雜項` 頁，只對小助手內建功能生效，可用於配置秘技、地圖、躍遷、停止任務等快捷鍵。

其中 `秘技` 按鍵主要作用於清體力和逐光撿金等內建任務。

如果你需要修改模擬宇宙或鋤大地的按鍵，請檢視對應第三方專案自己的文件和配置檔案。

### 賬號管理（僅 Windows）

`賬號` 頁只在 Windows 下顯示，主要用於本地遊戲模式的多賬號匯出與切換，不支援 `雲·星穹鐵道`。

使用時建議按這個順序：

1. 先完整進入遊戲，直到看見角色站在大世界中，再進行匯出。
2. 點選 `匯出當前遊戲賬戶`，把當前賬號儲存到本地列表。
3. 以後需要切換時，在列表中選中目標賬號，點選 `匯入選中的賬戶`。

賬號頁還支援這些操作：

- `賬戶更名`：給本地儲存的賬號改一個更容易識別的名字。
- `刪除賬戶`：刪除本地儲存的賬號資料。
- `重新整理`：重新讀取本地賬號列表。
- `清除登錄檔`：清理當前機器上保留的相關賬戶資訊，適合排查切號異常。

`自動登入` 會額外儲存你為該賬號輸入的使用者名稱和密碼，並在登入過期時嘗試自動回填。

這個功能有一定風險，只建議在你明確知道自己在做什麼時使用。

> 重要：如果你在還沒完全進入遊戲時就匯出賬號，可能會讀取到上一個賬號的 UID，導致儲存的檔案和實際賬號不對應。

## 更新

出現新版本彈窗後，點選下載即可；你也可以在設定頁最底部點選 `檢查更新`，或者手動雙擊 `March7th Updater.exe`。

如果你手動更新，請下載名稱類似 `March7thAssistant.zip` 或 `March7thAssistant.7z` 的完整包，

解壓後將全部檔案覆蓋到舊版本目錄即可。
