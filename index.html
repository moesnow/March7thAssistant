帮我安装三月七小助手，说明见 https://m7a.top/assets/agent/skills/march7th-assistant/SKILL.md

首次打开时的免责声明需要你本人阅读并确认，AI 助手不会代你点击。

在小助手里复制一段提示词，粘贴给 AI 助手即可。提示词里已经带上了本机的安装目录和版本：

设置关于AI 助手复制提示词

支持 Skill 的 AI 助手会把说明保存到自己的技能目录（如 ~/.claude/skills/），之后直接说「帮我清体力」就行。

AI 助手使用的是随程序发布的命令行入口 m7a.exe：不需要管理员权限，运行任务时弹出一次 UAC，输出和退出码直接返回终端。你也可以在脚本里用它：

.\m7a.exe --status                    # 安装、配置与运行状态（JSON）
.\m7a.exe --list --json               # 全部任务
.\m7a.exe daily --after-finish None   # 运行每日实训
.\m7a.exe --follow latest             # 查看最近一次运行
  • 安装与更新下载官方版本并校验 SHA-256，已有安装会直接复用
  • 运行任务完整运行、每日实训、清体力、差分宇宙……实时回传输出
  • 修改设置按配置说明改体力计划、定时任务与消息推送
  • 排查问题读取运行记录、日志与失败截图，对照常见问题处理

该由你决定的，仍然由你决定

  • 免责声明必须由你本人阅读并确认，不会被代为点击或绕过
  • 每次运行任务都要你在 UAC 弹窗中点「是」
  • 默认不执行关机等完成后操作，CDK、推送令牌等不会出现在对话里

常见问题

下载之前，你可能想知道

真的免费吗？Mirror酱 为什么要收费？

三月七小助手完全免费，基于 GPL-3.0 协议开源。Mirror酱 是为开源项目提供有偿分发的第三方平台，收取的是国内高速下载服务的费用，并与开发者分成；不购买也可以从 GitHub 免费下载和更新，功能完全一样。

使用自动化工具有风险吗？

有。《崩坏：星穹铁道》的公平游戏宣言禁止使用脚本等第三方工具，违规可能导致扣除收益乃至封禁账号。小助手主要通过识别游戏画面、模拟键鼠操作来完成任务，但这不代表没有风险。

首次启动时的免责声明有完整说明，请了解后自行决定是否使用。

电脑和游戏需要怎么设置？

需要 Windows 10 / 11 和 PC 版游戏客户端。游戏以 1920×1080 分辨率窗口化运行（不可用时再选全屏），语言设为简体中文，并关闭帧率监控、HDR、N 卡游戏滤镜等会遮挡或改变画面的软件。macOS / Linux 用户可以使用云·星穹铁道模式。

运行的时候还能用电脑吗？

可以。本地游戏默认使用前台模式，运行期间请不要动电脑；在「设置 → 杂项 → 本地操作模式」切换为后台后，游戏窗口留在其他窗口后面也能运行（点击时会短暂借用鼠标，游戏窗口不能最小化）。也可以开启云·星穹铁道的无窗口模式（锄大地、模拟宇宙除外），或者使用远程本地多用户桌面。详见 后台运行。

以后怎么更新？

有新版本时小助手会弹窗提示，点击即可下载更新；也可以在设置页最底部手动检查更新。默认从 GitHub 免费下载更新，填写 Mirror酱 CDK 后可以在国内高速增量更新。

被杀毒软件拦截或删除了怎么办？

自动化工具容易被误报。请把小助手所在的文件夹加入杀毒软件的排除项（信任区），然后重新解压一次。具体步骤见 常见问题文档。
